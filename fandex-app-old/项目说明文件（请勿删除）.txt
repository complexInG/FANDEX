二、内容独立性与特色重写声明

	FANDEX-App 的所有文档均为本仓库特色重写，针对移动端速查场景重新组织语法格式与代码示例，
	不适合从其他 FANDEX 仓库（如 FANDEX-web、FANDEX-exe）的数据源同步或直接复用。
	本仓库内容编写遵循以下原则：
	1. 以"语法速查"为核心目标，剔除教学讲解、环境配置、项目实战、理论知识等非速查内容
	2. 公式化呈现语法签名与代码示例，保持跨模块查阅体验一致
	3. 文档格式严格遵循 FANDEXAPP文档格式模板（不可删除）.md 中定义的速查模板
	4. 所有模块文档由人工与 AI 协同在本仓库内独立编撰，不从他处抓取或转换

三、FANDEX-App 项目定位

	定位：离线移动速查应用
	用处：移动场景下的编程语法即时查阅，实践中的语法签名与代码示例速查
	特色：Android 原生应用，完全离线，Kotlin + Jetpack Compose 原生渲染，
	      简繁中文双语界面，公式化语法速查，不依赖任何 WebView

四、FANDEX-App 内容规则

	1. 定位：纯粹的代码语法和语法格式查看阅览工具
	2. 仅收录编程语言/查询语言/标记语言的语法格式文档
	3. 不收录以下类型文档：
	   - 教学讲解（概述、概念阐述、发展历史）
	   - 环境配置（安装指南、环境搭建、工具配置）
	   - 项目实战（项目示例、实战案例、综合应用）
	   - 理论知识（算法理论、数学推导、设计原理）
	   - 最佳实践（性能优化、调试技巧、工程规范）
	   - Vue 组件型文件（无法在 App 原生渲染器中显示）
	4. 当前收录模块（17 个）：
	   编程语言：C、C++、C#、Go、Java、JavaScript、Kotlin、Lua、Python、TypeScript
	   前端技术：CSS
	   数据库：MySQL、PostgreSQL、Redis、SQL
	   工具链：Git
	   标记语言：Markdown
	5. 文档格式遵循 FANDEXAPP文档格式模板（不可删除）.md 中定义的语法速查模板

五、视觉风格与功能特性

	FANDEX-App 具备完全离线查阅能力，聚焦纯粹的代码语法速查体验，
	支持简繁中文双语界面切换，深色与浅色双主题，字号 0.8x-1.4x 可调，
	几何背景装饰基于 Compose Canvas 原生绘制，所有用户偏好通过 DataStore 持久化。

六、项目更新日志规则

	FANDEX-App 更新日志规则：
		1. 新模块、新功能、新页面的增加以及重构（前端布局、前端排版）属于大版本更新，版本号由 1.x.x 升至 2.x.x，须详细说明更新内容
		2. 小 BUG 修复（文档纠错、功能按钮位置调整、颜色优化不改变 UI 风格、按钮颜色图形优化）属于小更新，版本号由 1.0.x 升至 1.1.x，更新日志简要书写
		3. 同一问题或其所属范围内的多次修复，版本号由 1.x.0 升至 1.x.1，更新日志写：修复了一些 BUG
		4. 版本留存规则：仅留存每个大版本（1.0.0、1.1.0、2.0.0、3.0.0 等）的最终安装包（如 1.0.3、2.2.4、3.0.8）；大版本初始安装包（1.0.0、2.0.0、3.0.0 等）须单独留存，与最终安装包分开存放
		5. 大版本初始版本的更新日志单独存在，该大版本后续更新写在另一条更新日志下
