#### 1. 英译汉的基本原则

##### 1.1 翻译的三大标准

严复提出的"信、达、雅"至今仍是翻译的黄金标准：

| 标准 | 含义 | 要求                             |
| ---- | ---- | -------------------------------- |
| 信   | 忠实 | 准确传达原文内容，不歪曲、不遗漏 |
| 达   | 通顺 | 译文符合中文表达习惯，流畅自然   |
| 雅   | 优美 | 译文语言优美，风格得体           |

##### 1.2 英汉语言差异

| 差异 | 英语               | 汉语               |
| ---- | ------------------ | ------------------ |
| 句式 | 形合（靠连词连接） | 意合（靠逻辑连接） |
| 主语 | 常用物称主语       | 常用人称主语       |
| 被动 | 被动语态多         | 主动语态多         |
| 修饰 | 定语后置           | 定语前置           |
| 词序 | 灵活               | 相对固定           |
| 重复 | 避免重复           | 允许重复           |
| 长句 | 多从句嵌套         | 多短句并列         |

#### 2. 直译与意译

##### 2.1 直译 (Literal Translation)

直译尽量保持原文的形式和内容：

> **原文：** Knowledge is power.
> **直译：** 知识就是力量。

**适用场景：**

- 科技文献
- 法律文件
- 需要精确传达原文含义的场合

##### 2.2 意译 (Free Translation)

意译注重传达原文的意义，不拘泥于形式：

> **原文：** It rains cats and dogs.
> **意译：** 倾盆大雨。（而非"下猫下狗"）

**适用场景：**

- 习语和俚语
- 文学作品
- 文化差异大的表达

##### 2.3 直译与意译的选择

| 原文类型   | 推荐方法  | 示例                                |
| ---------- | --------- | ----------------------------------- |
| 科技术语   | 直译      | machine learning → 机器学习         |
| 习语       | 意译      | break the ice → 打破僵局            |
| 文化负载词 | 意译+注释 | Thanksgiving → 感恩节               |
| 双关语     | 意译      | Time flies like an arrow → 光阴似箭 |

#### 3. 词性转换

英汉翻译中，词性转换是最常用的技巧之一：

##### 3.1 名词 → 动词

英语中大量使用名词，中文更倾向使用动词：

| 原文                    | 译文   | 转换                           |
| ----------------------- | ------ | ------------------------------ |
| make a decision         | 做决定 | decision (n.) → 决定 (v.)      |
| take into consideration | 考虑   | consideration (n.) → 考虑 (v.) |
| give an explanation     | 解释   | explanation (n.) → 解释 (v.)   |
| have a discussion       | 讨论   | discussion (n.) → 讨论 (v.)    |
| make an adjustment      | 调整   | adjustment (n.) → 调整 (v.)    |

**实例：**

> The **implementation** of the new policy requires careful planning.
> **实施**新政策需要周密的计划。

##### 3.2 介词 → 动词

| 原文                   | 译文         | 转换           |
| ---------------------- | ------------ | -------------- |
| go **into** the room   | **进入**房间 | into → 进入    |
| **without** permission | **未经**许可 | without → 未经 |
| **for** the purpose of | **为了**     | for → 为了     |
| **by** means of        | **借助**     | by → 借助      |

##### 3.3 形容词 → 动词

| 原文               | 译文       | 转换              |
| ------------------ | ---------- | ----------------- |
| be **aware** of    | **意识到** | aware → 意识到    |
| be **sure** about  | **确信**   | sure → 确信       |
| be **ignorant** of | **不知道** | ignorant → 不知道 |
| be **afraid** of   | **害怕**   | afraid → 害怕     |

##### 3.4 动词 → 名词

| 原文                 | 译文             | 转换          |
| -------------------- | ---------------- | ------------- |
| **behave** well      | **表现**良好     | behave → 表现 |
| **serve** the people | 为人民**服务**   | serve → 服务  |
| **weigh** 50 kg      | **重量**为50公斤 | weigh → 重量  |

#### 4. 增词与减词

##### 4.1 增词法

增词不是随意添加，而是补充中文表达所需的内容：

| 增词类型 | 原文                | 译文                   | 说明         |
| -------- | ------------------- | ---------------------- | ------------ |
| 增加动词 | after the meeting   | 会议**结束**后         | 补充隐含动词 |
| 增加名词 | to wash             | **洗**衣服             | 补充宾语     |
| 增加量词 | a computer          | **一台**电脑           | 中文需要量词 |
| 增加连词 | He left, she stayed | 他走了，**而**她留下了 | 补充逻辑关系 |
| 增加解释 | Brexit              | 英国脱欧（Brexit）     | 补充背景信息 |

##### 4.2 减词法

减词是省略中文中不需要的冗余信息：

| 减词类型 | 原文                            | 译文           | 说明               |
| -------- | ------------------------------- | -------------- | ------------------ |
| 省代词   | He put his hands in his pockets | 他把手插进口袋 | 中文无需重复"他的" |
| 省冠词   | The sun rises in the east       | 太阳从东方升起 | 中文无冠词         |
| 省连词   | If you come, I will go          | 你来我就去     | 中文可省"如果"     |
| 省介词   | in the year 2026                | 2026年         | 中文无需"在"       |
| 省冗余   | completely eliminate            | 消除           | "完全消除"冗余     |

#### 5. 语序调整

##### 5.1 定语语序

英语定语可前置可后置，中文定语通常前置：

| 英语                           | 中文               |
| ------------------------------ | ------------------ |
| the book **on the table**      | **桌上的**书       |
| the man **who came yesterday** | **昨天来的**那个人 |
| the possibility **of success** | **成功的**可能性   |

**多重定语的语序：**

> the beautiful old Chinese wooden desk
> 美丽的中国旧木桌

##### 5.2 状语语序

| 英语                     | 中文           | 规则             |
| ------------------------ | -------------- | ---------------- |
| She works **hard**       | 她**努力**工作 | 方式状语前置     |
| I will go **tomorrow**   | 我**明天**去   | 时间状语前置     |
| She is **in the office** | 她**在办公室** | 地点状语位置灵活 |

##### 5.3 倒装句还原

> **Never before** has the world faced such a challenge.
> 世界以前从未面临过这样的挑战。

##### 5.4 长句拆分

英语长句常需拆分为中文短句：

> The research, which was conducted by a team of scientists from three different countries over a period of five years, revealed that the new drug was effective in treating the disease.

**拆分翻译：**

> 这项研究由来自三个不同国家的科学家团队历时五年完成。研究结果表明，这种新药在治疗该疾病方面是有效的。

#### 6. 被动语态的翻译

##### 6.1 译为主动句

| 原文                         | 译文           | 方法       |
| ---------------------------- | -------------- | ---------- |
| The problem was solved.      | 问题解决了。   | 省略"被"   |
| The book was written by him. | 他写了这本书。 | 转换主语   |
| It is reported that...       | 据报道……       | 译为无主句 |

##### 6.2 保留被动

| 原文                       | 译文             | 说明         |
| -------------------------- | ---------------- | ------------ |
| He was criticized.         | 他受到了批评。   | "受到"表被动 |
| The project was approved.  | 项目获得了批准。 | "获得"表被动 |
| She was elected president. | 她被选为总统。   | 保留"被"     |

##### 6.3 常见被动句式翻译

| 英语                           | 中文       |
| ------------------------------ | ---------- |
| It is said that...             | 据说……     |
| It is reported that...         | 据报道……   |
| It is believed that...         | 人们认为…… |
| It is well known that...       | 众所周知…… |
| It must be pointed out that... | 必须指出…… |
| It should be noted that...     | 应当注意…… |

#### 7. 特殊句式翻译

##### 7.1 否定转移

> I don't think she is right.
> 我认为她不对。（而非"我不认为她是对的"）

##### 7.2 双重否定

> It is not impossible.
> 这不是不可能的。/ 这是可能的。

##### 7.3 形式主语

> It is important to back up your data regularly.
> 定期备份数据很重要。

##### 7.4 强调句

> It was the algorithm that the team optimized.
> 团队优化的是算法。

#### 8. 翻译质量自检

##### 8.1 自检清单

| 检查项 | 问题                         |
| ------ | ---------------------------- |
| 忠实性 | 译文是否准确传达了原文含义？ |
| 通顺性 | 译文是否符合中文表达习惯？   |
| 完整性 | 是否有遗漏或多余的内容？     |
| 一致性 | 术语翻译是否前后一致？       |
| 格式   | 数字、标点、格式是否正确？   |

##### 8.2 常见翻译问题

| 问题       | 示例                   | 改进             |
| ---------- | ---------------------- | ---------------- |
| 翻译腔     | 他做了一个决定         | 他决定了         |
| 过度直译   | 打开灯的光             | 开灯             |

| 逻辑不通   | 虽然下雨，但他没去     | 因为下雨，他没去 |
