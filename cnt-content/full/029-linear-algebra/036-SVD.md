## 0. 从生活场景说起：照片压缩的魔法

一张 1000 × 1000 的灰度照片，本质就是一个 100 万个数字的矩阵。可手机发图时，照片被压缩到很小却依然"看得出是谁"——为什么能丢掉 90% 的数据还不糊？

答案是：**照片里的大部分信息是"重复的、低效的"**。天空一整片都是相似的灰，只有人脸边缘、建筑轮廓这些地方信息量巨大。聪明的压缩算法只保留"信息量大的部分"，丢掉"平淡重复的部分"。

奇异值分解（SVD）就是这个原理的数学化：**任何矩阵都能拆成"按重要性排序的一组零件"**，排名靠前的零件携带绝大部分信息，靠后的零件只是细节与噪声。

$$A = \sigma_1\boldsymbol{u}_1\boldsymbol{v}_1^T + \sigma_2\boldsymbol{u}_2\boldsymbol{v}_2^T + \cdots + \sigma_r\boldsymbol{u}_r\boldsymbol{v}_r^T$$

$\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r$ 是**奇异值**，它度量每个零件的重要程度。丢掉小奇异值对应的零件，就是"压缩"——这就是 SVD 被称为"线性代数的基本定理"、数据科学界的"瑞士军刀"的原因。

## 1. SVD 定理

### 1.1 定理表述

**SVD 定理**：设 $A$ 为 $m \times n$ 实矩阵，$r = r(A)$，则存在 $m \times m$ 正交矩阵 $U$ 和 $n \times n$ 正交矩阵 $V$，使得

$$A = U\Sigma V^T$$

其中 $\Sigma = \begin{pmatrix} D & O \\ O & O \end{pmatrix}$，$D = \text{diag}(\sigma_1, \sigma_2, \ldots, \sigma_r)$，且 $\sigma_1 \geq \sigma_2 \geq \cdots \geq \sigma_r > 0$。

$\sigma_1, \ldots, \sigma_r$ 称为 $A$ 的**奇异值**；$U$ 的列 $\boldsymbol{u}_i$ 称为**左奇异向量**，$V$ 的列 $\boldsymbol{v}_i$ 称为**右奇异向量**。

**核心威力**：特征值分解只对可对角化的方阵有意义，而 SVD 对**任意形状、任意秩**的矩阵都成立——这就是它"万能"的来源。

### 1.2 三种形态

| 形态 | 公式 | 形状 |
| ---- | ---- | ---- |
| 完全 SVD | $A = U\Sigma V^T$ | $U$：$m \times m$，$\Sigma$：$m \times n$，$V$：$n \times n$ |
| 瘦型 SVD | $A = U_r\Sigma_r V_r^T$ | $U_r$：$m \times r$，$\Sigma_r$：$r \times r$，$V_r$：$n \times r$ |
| 截断 SVD | $A_k = U_k\Sigma_k V_k^T$ | 只保留前 $k$ 个奇异值（用于压缩） |

### 1.3 证明思路（理解为主）

1. $A^TA$ 是 $n$ 阶实对称**半正定**矩阵（$(A\boldsymbol{x})^T(A\boldsymbol{x}) = \|A\boldsymbol{x}\|^2 \geq 0$），可正交对角化：$A^TA = V\Lambda^2V^T$，其中 $\Lambda = \text{diag}(\sigma_1, \ldots, \sigma_r, 0, \ldots, 0)$；
2. 令 $U_r = AV_r\Sigma_r^{-1}$，验证 $U_r^TU_r = I_r$（利用特征向量正交性）；
3. 把 $U_r$ 扩充为正交矩阵 $U$，即得 $A = U\Sigma V^T$。

**直观理解**：$V$ 和奇异值来自 $A^TA$（"平方"掉符号信息），$U$ 由 $A\boldsymbol{v}_i = \sigma_i\boldsymbol{u}_i$ 再"还原"出来。

## 2. 奇异值与特征值的关系

- $A^TA$ 的特征值 = $\sigma_1^2, \ldots, \sigma_r^2, 0, \ldots, 0$（奇异值是非零特征值的平方根）；
- $AA^T$ 的非零特征值与 $A^TA$ 完全相同；
- 若 $A$ 为实对称矩阵，奇异值 = 特征值的**绝对值**；
- 奇异值的个数（非零）= 矩阵的秩 $r$。

**选择用哪个？** 当 $m > n$（"高瘦"矩阵）时算 $A^TA$（$n$ 阶，更小）；当 $n > m$（"矮胖"矩阵）时算 $AA^T$。实际数值软件并不直接算 $A^TA$（会平方条件数），而是用双对角化 + QR 迭代，但**理解原理用 $A^TA$ 就够了**。

## 4. SVD 的几何意义

### 4.1 任意线性变换 = 旋转 × 伸缩 × 旋转

$$A = U\Sigma V^T$$

作用一个向量 $\boldsymbol{x}$ 等价于三步：

1. **$V^T$**：在输入空间旋转/反射（换到"奇异方向"坐标系）；
2. **$\Sigma$**：沿坐标轴方向独立伸缩（奇异值就是各方向的伸缩倍数）；
3. **$U$**：在输出空间旋转/反射（换回标准坐标系）。

### 4.2 单位球变成椭球

$A$ 把单位球 $\{\boldsymbol{x} \mid \|\boldsymbol{x}\| = 1\}$ 映射为椭球面，**椭球半轴的长度正是奇异值** $\sigma_1, \ldots, \sigma_r$，半轴方向是左奇异向量 $\boldsymbol{u}_i$。最大的奇异值告诉你"变换在哪个方向拉得最长"——这正是 PCA（主成分分析）的几何直觉。

### 4.3 四个基本子空间的标准正交基

| 矩阵块 | 张成的子空间 |
| ------ | ------------ |
| $V$ 的前 $r$ 列 | 行空间 $R(A^T)$ |
| $V$ 的后 $n - r$ 列 | 零空间 $N(A)$ |
| $U$ 的前 $r$ 列 | 列空间 $R(A)$ |
| $U$ 的后 $m - r$ 列 | 左零空间 $N(A^T)$ |

**意义**：一次 SVD 同时给出四个基本子空间的标准正交基——这是特征值分解做不到的（非方阵根本没有特征值）。

## 5. Eckart-Young 定理：最优低秩近似

### 5.1 定理

**Eckart-Young 定理**（Eckart 与 Young 于 1936 年发表于 Psychometrika）：在所有秩不超过 $k$ 的 $m \times n$ 矩阵 $B$ 中，**截断 SVD**

$$A_k = \sum_{i=1}^{k} \sigma_i \boldsymbol{u}_i \boldsymbol{v}_i^T$$

是最接近 $A$ 的，即在谱范数和 Frobenius 范数下都有 $\|A - B\| \geq \|A - A_k\|$。

**用生活语言翻译**：如果必须用"k 个零件"拼出最像原图的照片，SVD 告诉你怎么选——选奇异值最大的前 k 个零件，任何其他选法都不如它。

### 5.2 误差公式

$$\|A - A_k\|_F = \sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}, \qquad \|A - A_k\|_2 = \sigma_{k+1}$$

**用生活语言翻译**：丢掉的是"排名第 k+1 名以后的零件"，它们的总能量就是压缩误差。

## 6. SVD 的应用

### 6.1 矩阵的伪逆（广义逆）

对不可逆甚至长方矩阵，SVD 给出"最接近逆"的伪逆：

$$A^+ = V\Sigma^+ U^T$$

其中 $\Sigma^+$ 是把 $\Sigma$ 中非零奇异值取倒数（零元素不变）再转置。**性质**：$\min\|A\boldsymbol{x} - \boldsymbol{b}\|$ 的最小范数解恰为 $\boldsymbol{x} = A^+\boldsymbol{b}$——伪逆统一了"满秩方阵求逆"与"最小二乘"两个世界。

### 6.2 图像压缩

把图像矩阵 $A$ 做截断 SVD 保留前 $k$ 个奇异值：

- 存储量：$k(m + n + 1)$ 个数（$k$ 个 $\sigma_i$ + $k$ 个 $\boldsymbol{u}_i$ + $k$ 个 $\boldsymbol{v}_i$）；
- 压缩比：$\dfrac{mn}{k(m+n+1)}$；
- 对 $256 \times 256$ 图像取 $k = 50$：原始 $65536$ 个数 vs 压缩后 $50 \times 513 = 25650$ 个数，约 $2.55:1$，而视觉差异通常很小。

### 6.3 降噪

真实信号的大奇异值携带"信息"，噪声对应**小奇异值**。截掉小奇异值再重建，噪声被"洗掉"——这是信号处理中经典的 SVD 降噪流程。

### 6.4 其他重要应用

- **PCA**：$X = U\Sigma V^T$ 中 $V$ 的列就是主成分方向，方差为 $\sigma_i^2/(m-1)$；
- **条件数**：$\kappa(A) = \sigma_{\max}/\sigma_{\min}$——判断方程组求解是否"病态"；
- **推荐系统**：评分矩阵的低秩近似 $R \approx U_k\Sigma_k V_k^T$；
- **LoRA 大模型微调**：权重增量 $\Delta W$ 用低秩近似，正是 Eckart-Young 定理在深度学习中的体现。

## 7. 常见错误与对策

| 错误示例 | 错误类型 | 出错原因 | 纠正方法 |
| -------- | -------- | -------- | -------- |
| 对非方阵说"特征值" | 概念越界 | 特征值只定义于方阵 | 非方阵用奇异值；特征值=奇异值只对实对称矩阵成立（且需取绝对值） |
| 忘排序：奇异值必须降序 | 约定错误 | 没注意 $\sigma_1 \geq \cdots \geq \sigma_r$ | SVD 默认按降序排列，截断时取前 k 个最大者 |
| 用 $A^TA$ 的特征向量当 $\boldsymbol{u}$ | 左右混淆 | 分不清左右奇异向量 | $V$ 来自 $A^TA$，$U$ 来自 $AA^T$ 或 $A\boldsymbol{v}_i/\sigma_i$ |
| 截断后忘记 $A_k$ 是"近似" | 概念错误 | 把 $A_k$ 当成精确分解 | $A_k$ 是最优 $k$ 秩近似，误差 $\sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}$ |
| 压缩时把 $m+n$ 项写错 | 公式记错 | 存储量应为 $k(m+n+1)$ | 每个奇异值额外占 1 个位置，共 $k$ 个 $\sigma$ 加 $k$ 个向量 |
| 认为 SVD 与特征分解等价 | 理解偏差 | 只记了对称矩阵的特例 | SVD 适用于一切矩阵，特征分解仅适用于可对角化方阵 |
| 伪逆直接把零奇异值取倒数 | 运算错误 | $\Sigma^+$ 的规则记反 | 非零奇异值取倒数，**零奇异值保持为 0** |

## 9. 一句话记忆

> **SVD = 把任意矩阵拆成"按重要性排序的零件" $A = \sum \sigma_i\boldsymbol{u}_i\boldsymbol{v}_i^T$：奇异值度量每个方向被拉伸多少，最大的几个奇异值装下几乎全部能量（Eckart-Young 保证截断最优），于是压缩、伪逆、降噪、PCA 全靠它——任何形状的矩阵都适用，所以叫"线性代数的基本定理"。**
