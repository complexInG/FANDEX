## 1. 从"地图上色"说起

### 1.1 图论进阶讲什么

图论基础讲的是"图和树的基本结构"；图论进阶则深入几个"应用级"专题——它们都来自真实问题：

- **平面图**：地图怎么画才能让边不相交？
- **着色**：给地图上色，相邻国家颜色不同，最少用几种颜色？（四色问题）
- **网络流**：水管网络最多能送多少水？
- **最短路径**：地图导航怎么找最短路线？

**这些专题是算法设计的直接基础**——Dijkstra、Floyd、Ford-Fulkerson 都是图论进阶的"产品"。

## 2. 平面图与 Euler 公式

### 2.1 平面图

**平面图**：可以在平面上画出且边不相交的图。

**面**：平面图将平面划分的区域。

- **外部面**（无限面）：无界的区域
- **内部面**：有界的区域

**理解**：像地图一样——几个"封闭区域"加上最外面的一大片"外部面"。

### 2.2 Euler 公式（核心定理）

设连通平面图 $G$ 有 $n$ 个顶点、$m$ 条边、$f$ 个面，则

$$n - m + f = 2$$

**验证一个简单例子**：三角形有 $n=3, m=3, f=2$（内部 1 个面 + 外部 1 个面），$3-3+2=2$ ✓

**理解**：顶点数 - 边数 + 面数 = 2，对任何连通平面图都成立——这是平面图的"守恒律"。

### 2.3 三个重要推论

**推论1**：简单连通平面图（$n \geq 3$）满足 $m \leq 3n - 6$。

**推论2**：$K_5$ 不是平面图（$n=5, m=10 > 3\times5-6=9$，矛盾）。

**推论3**：$K_{3,3}$ 不是平面图（无三角形，每个面至少 4 条边，$m \leq 2n-4 = 8 < 9$，矛盾）。

**实践价值**：用这些推论能快速判断"某个图能否画在平面上不交叉"——如电路布线、芯片设计。

### 2.4 Kuratowski 定理（平面图判定的"终极标准"）

**定理**：图 $G$ 是平面图 $\iff$ $G$ **不含与 $K_5$ 或 $K_{3,3}$ 同胚的子图**。

**同胚**：两个图通过在边上插入或删除 2 度顶点后同构。

**理解**：$K_5$ 和 $K_{3,3}$ 是"非平面图的两个最小元"——任何非平面图都"包含"它们之一。

### 2.5 对偶图

平面图 $G$ 的**对偶图** $G^*$：

- $G$ 的每个**面**对应 $G^*$ 的一个**顶点**
- $G$ 的每条**边**对应 $G^*$ 的一条**边**（连接相邻面对应的顶点）

**理解**：把"地图"变成"国家关系图"——每个国家是一个点，相邻的国家连一条线。

## 3. 图的着色

### 3.1 基本概念

**正常着色**：相邻顶点颜色不同。

**色数** $\chi(G)$：正常着色所需的最少颜色数。

**理解**：地图着色问题——相邻国家颜色不同，最少用几种颜色？

### 3.2 色数的界

**上界**：

- $\chi(G) \leq \Delta(G) + 1$（$\Delta$ 为最大度）
- **Brooks 定理**：若 $G$ 不是完全图也不是奇圈，则 $\chi(G) \leq \Delta(G)$

**下界**：

- $\chi(G) \geq \omega(G)$（$\omega$ 为最大团的大小——完全子图的顶点数）

### 3.3 特殊图的色数

| 图 | 色数 |
| :--- | :--- |
| 二部图 | 2 |
| 偶圈 $C_{2k}$ | 2 |
| 奇圈 $C_{2k+1}$ | 3 |
| $K_n$ | $n$ |
| 树 | 2（非平凡） |

**理解**：色数 2 的图就是二部图（这是二部图的另一种定义！）。

### 3.4 四色定理（著名难题）

**四色定理**：任何平面图都可以用**4 种颜色**正常着色。

- 1852 年被提出
- 1976 年由 Appel 和 Haken 借助计算机证明（**第一个依靠计算机证明的著名数学定理**）
- 至今没有找到简洁的人工证明

**理解**：任何地图（不管多复杂），最多 4 种颜色就能让相邻国家颜色不同。这看似简单的问题，困扰了数学家一百多年。

### 3.5 着色应用

- **排课表**：课程是顶点，冲突课程连边，色数 = 最少考场数
- **寄存器分配**：变量是顶点，同时活跃的变量连边，色数 = 最少寄存器数

## 4. 匹配与覆盖

### 4.1 匹配

**匹配**：边集 $M \subseteq E$，$M$ 中任意两条边不共享端点。

**最大匹配**：边数最多的匹配。

**完美匹配**：覆盖所有顶点的匹配。

### 4.2 匹配与覆盖的关系

**点覆盖**：顶点集 $V' \subseteq V$，使每条边至少有一个端点在 $V'$ 中。

**König 定理**：二部图中，**最大匹配的边数 = 最小点覆盖的顶点数**。

**理解**：在二部图中，一个"最大配对"和一个"最小守卫"数量相等——这是二部图最漂亮的性质之一。

### 4.3 最大匹配算法

- **增广路径算法（匈牙利算法）**：反复寻找"增广路径"（起点和终点都未匹配、交替经过匹配/非匹配边的路径），找到就扩大匹配。$O(|V||E|)$。

## 5. 网络流

### 5.1 基本概念

**网络**：有向图 + 源点 $s$ + 汇点 $t$ + 每条边有容量 $c(e)$。

**流**：$s$ 到 $t$ 的流量分配 $f(e)$，满足：

- 容量约束：$0 \leq f(e) \leq c(e)$
- 流量守恒：每个中间节点"流入 = 流出"

**最大流**：从 $s$ 到 $t$ 能传输的最大流量。

### 5.2 Ford-Fulkerson 算法

**核心思想**：反复寻找从 $s$ 到 $t$ 的**增广路径**（还有剩余容量的路径），增加流量，直到找不到为止。

**关键概念：残量网络**——每条边记录"还能加多少"（剩余容量）。

**例**：水管网络——每个水管有最大流量，求源点到汇点最多能送多少水。

### 5.3 最大流最小割定理

**割**：把顶点分成 $S$ 和 $T$（$s \in S, t \in T$）的划分，割的容量 = 从 $S$ 到 $T$ 的所有边的容量和。

**定理**：**最大流 = 最小割**。

**理解**：网络最多能送的流量，等于"最窄的瓶颈处"能通过的流量。这像"木桶效应"——最大流量由最窄的切口决定。

## 6. 最短路径算法

### 6.1 Dijkstra 算法（单源最短路径）

**适用**：边权**非负**的图。

**思想**：贪心——每次从未确定最短距离的顶点中选"距离最小"的，松弛其邻居。

```
1. dist[s] = 0，其余 = ∞
2. 从未访问顶点中选 dist 最小的 u
3. 对 u 的所有邻居 v：dist[v] = min(dist[v], dist[u] + w(u,v))
4. 标记 u 已访问，重复 2-4 直到全部访问
```

复杂度：$O(|V|^2)$（朴素）/ $O(|E|\log|V|)$（堆优化）。

**理解**：像"从起点逐层向外扩散"，每次都确定一个"当前最近的点"。

### 6.2 Bellman-Ford 算法

**适用**：边权可**为负**的图（Dijkstra 不能处理负权）。

**思想**：对所有边做 $|V|-1$ 轮"松弛"，每轮保证"最多经过 k 条边的最短路径"。

复杂度：$O(|V||E|)$。

**附加能力**：第 $|V|$ 轮还能松弛 → 存在负环。

### 6.3 Floyd-Warshall 算法（全源最短路径）

**适用**：任意两点之间的最短路径。

**思想**：动态规划——$d[i][j] = \min(d[i][j], d[i][k] + d[k][j])$，三重循环枚举中间点 $k$。

复杂度：$O(|V|^3)$。

## 7. 拓扑排序

### 7.1 定义

**拓扑排序**：有向无环图（DAG）的顶点线性排序，使每条边 $u \to v$ 都满足 $u$ 排在 $v$ 前面。

**适用**：有向无环图（DAG）——有环则无拓扑排序。

**理解**：像"课程安排"——先修课程必须在后修课程之前。

### 7.2 Kahn 算法

```
1. 计算所有顶点的入度
2. 入度为 0 的顶点入队列
3. 弹出顶点 u，删除其所有出边（邻接入度 -1）
4. 若邻居入度变为 0，入队列
5. 重复直到队列空
6. 若排出的顶点数 < 总顶点数 → 存在环
```

复杂度：$O(|V| + |E|)$。

**应用**：任务调度、编译依赖排序、`make` 工具。

## 8. 常见误区

**误区一：所有图都能拓扑排序。** → 只有**有向无环图（DAG）**能拓扑排序。有环则无解（Kahn 算法会在最后发现"排不完"）。

**误区二：Dijkstra 能处理负权边。** → 不能！负权边会破坏 Dijkstra 的贪心正确性，必须用 Bellman-Ford。

**误区三：四色定理很简单。** → 它是最著名的数学难题之一，1976 年才靠计算机证明，至今无简洁人工证明。

**误区四：Kruskal 和 Prim 求"最短路径"。** → 它们求的是**最小生成树**（连通所有点的最小总代价），不是两点间的最短路径（Dijkstra 才是）。
