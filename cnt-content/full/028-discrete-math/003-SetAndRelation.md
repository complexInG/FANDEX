## 1. 从"收纳盒"说起

### 1.1 集合是什么

想象你有一堆物品要收纳：把"苹果、香蕉、橙子"放进一个盒子，贴上标签"水果"。这个"盒子"就是**集合**，里面的"物品"就是**元素**。

**集合**是具有某种特定性质的事物的总体。用大写字母 $A, B, C, \ldots$ 表示集合，小写字母 $a, b, c, \ldots$ 表示元素。

- $a \in A$：$a$ 属于 $A$（苹果在水果盒里）
- $a \notin A$：$a$ 不属于 $A$（石头不在水果盒里）

### 1.2 集合的表示

- **列举法**：$A = \{1, 2, 3\}$（把元素逐个列出来）
- **描述法**：$B = \{x \mid x > 0\}$（描述元素的共同性质）

### 1.3 集合间的关系

- $A \subseteq B$（$A$ 是 $B$ 的子集）：$\forall x(x \in A \to x \in B)$（水果盒里全是零食盒里的东西）
- $A = B$：$A \subseteq B \land B \subseteq A$（互为子集）
- $A \subset B$（真子集）：$A \subseteq B \land A \neq B$

## 2. 集合运算：盒子们的"组合"

### 2.1 五种基本运算

| 运算 | 定义 | 生活类比 |
| :--- | :--- | :--- |
| 并 $A \cup B$ | $\{x \mid x \in A \lor x \in B\}$ | 两个盒子倒在一起 |
| 交 $A \cap B$ | $\{x \mid x \in A \land x \in B\}$ | 两个盒子共有的东西 |
| 差 $A - B$ | $\{x \mid x \in A \land x \notin B\}$ | 从 A 里拿走 B 里的 |
| 补 $\bar{A}$ | $U - A$（$U$ 为全集） | 全集里不属于 A 的 |
| 对称差 $A \oplus B$ | $(A \cup B) - (A \cap B)$ | 只在一个盒子里出现的 |

### 2.2 运算律（与命题逻辑对应）

集合运算的规律和命题逻辑的联结词规律**一一对应**（$\cup$ 对应 $\lor$，$\cap$ 对应 $\land$）：

| 运算律 | 公式 |
| :--- | :--- |
| 交换律 | $A \cup B = B \cup A$，$A \cap B = B \cap A$ |
| 结合律 | $(A \cup B) \cup C = A \cup (B \cup C)$ |
| 分配律 | $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ |
| 德摩根律 | $\overline{A \cup B} = \bar{A} \cap \bar{B}$，$\overline{A \cap B} = \bar{A} \cup \bar{B}$ |
| 吸收律 | $A \cup (A \cap B) = A$，$A \cap (A \cup B) = A$ |
| 补律 | $A \cup \bar{A} = U$，$A \cap \bar{A} = \emptyset$ |

**记忆技巧**：德摩根律就是"把并变交、交变并，上面加横杠"——和命题逻辑的 $\neg(p \lor q) \Leftrightarrow \neg p \land \neg q$ 完全对应。

## 3. 幂集与笛卡尔积

### 3.1 幂集

集合 $A$ 的**幂集**是 $A$ 的所有子集的集合：

$$\mathcal{P}(A) = \{X \mid X \subseteq A\}$$

若 $|A| = n$，则 $|\mathcal{P}(A)| = 2^n$。

**例**：$A = \{1, 2\}$，$\mathcal{P}(A) = \{\emptyset, \{1\}, \{2\}, \{1,2\}\}$，$|\mathcal{P}(A)| = 4 = 2^2$。

**理解**：每个元素"在子集里/不在子集里"二选一，$n$ 个元素就有 $2^n$ 种选择。

### 3.2 笛卡尔积

$$A \times B = \{(a, b) \mid a \in A, b \in B\}$$

**性质**：

- $|A \times B| = |A| \cdot |B|$
- 笛卡尔积**不满足交换律**：$A \times B \neq B \times A$（一般情况，因为 $(a,b) \neq (b,a)$）
- $A \times (B \cup C) = (A \times B) \cup (A \times C)$（分配律）

**理解**：笛卡尔积就是"有序对"的集合——像"所有可能的配对"。比如"衣服 × 颜色" = 所有"衣服+颜色"的组合。

## 4. 二元关系：元素之间的"连线"

### 4.1 定义

$A \times B$ 的任意子集 $R$ 称为从 $A$ 到 $B$ 的**二元关系**。当 $A = B$ 时，$R$ 称为 $A$ 上的二元关系。

若 $(a, b) \in R$，记作 $aRb$。

**特殊关系**：

- **空关系**：$\emptyset$（谁和谁都没有关系）
- **全关系**：$A \times A$（谁和谁都有关系）
- **恒等关系**：$I_A = \{(a,a) \mid a \in A\}$（只和自己有关系）

### 4.2 关系的三种表示

| 表示法 | 说明 |
| :--- | :--- |
| 集合表示 | $R = \{(1,2), (2,3), (1,3)\}$ |
| 关系矩阵 | $M_R = (m_{ij})$，$m_{ij} = 1$ 若 $(a_i, b_j) \in R$，否则为 $0$ |
| 关系图 | 用有向图表示（$a \to b$ 表示 $aRb$） |

### 4.3 关系的五种性质（重点）

设 $R$ 是 $A$ 上的关系：

| 性质 | 定义 | 矩阵特征 | 图特征 |
| :--- | :--- | :--- | :--- |
| 自反性 | $\forall a, aRa$ | 主对角线全 1 | 每点有环 |
| 反自反性 | $\forall a, \neg(aRa)$ | 主对角线全 0 | 每点无环 |
| 对称性 | $aRb \Rightarrow bRa$ | 对称矩阵 | 边双向 |
| 反对称性 | $aRb \land bRa \Rightarrow a=b$ | — | 无双向边（除环） |
| 传递性 | $aRb \land bRc \Rightarrow aRc$ | $M_R^2 \leq M_R$ | 有捷径 |

**例**：$A = \{1,2,3\}$，$R = \{(1,1),(2,2),(3,3),(1,2),(2,1)\}$。

> - 自反：是（每点有环）
> - 对称：是（$(1,2)$ 和 $(2,1)$ 都在）
> - 传递：是（检查所有路径）
> - 反对称：否（$1R2$ 且 $2R1$ 但 $1 \neq 2$）

### 4.4 关系的运算

**逆关系**：$R^{-1} = \{(b,a) \mid (a,b) \in R\}$（箭头反过来）

**复合关系**：$R \circ S = \{(a,c) \mid \exists b, (a,b) \in S \land (b,c) \in R\}$

**注意**：$R \circ S$ 中 **$S$ 先作用，$R$ 后作用**（像函数复合 $f \circ g$：先 $g$ 后 $f$）。

**矩阵运算**：$M_{R \circ S} = M_S \cdot M_R$（布尔矩阵乘法）

**幂运算**：$R^n = R^{n-1} \circ R$，$R^0 = I_A$

## 5. 等价关系与划分：给元素"分组"

### 5.1 等价关系

若 $R$ 满足**自反性、对称性和传递性**，则 $R$ 为**等价关系**。

**等价类**：$[a]_R = \{x \in A \mid xRa\}$（和 $a$ 有关系的所有元素）

**性质**：

- $aRb \iff [a] = [b]$（有关系 → 属于同一类）
- $[a] \cap [b] = \emptyset$ 或 $[a] = [b]$（两类要么相同要么不相交）
- $\bigcup_{a \in A} [a] = A$（所有类拼起来是全集）

### 5.2 划分

集合 $A$ 的**划分**是 $A$ 的非空子集族 $\pi = \{A_1, A_2, \ldots, A_k\}$，满足：

1. $A_i \neq \emptyset$（每块非空）
2. $A_i \cap A_j = \emptyset$（$i \neq j$）（两两不相交）
3. $\bigcup A_i = A$（拼起来是全集）

**定理（核心结论）**：**$A$ 上的等价关系与 $A$ 的划分一一对应。**

**例**：$A = \{1,2,3,4,5\}$，$R = \{(a,b) \mid a \equiv b \pmod{2}\}$（同奇偶）。

> 等价类：$[1] = \{1,3,5\}$，$[2] = \{2,4\}$
> 划分：$\{\{1,3,5\}, \{2,4\}\}$

**理解**：等价关系就是"把元素按某种标准分组"——"同奇偶"把数字分成"奇数一组、偶数一组"。

### 5.3 商集

$A$ 关于等价关系 $R$ 的**商集**：$A/R = \{[a]_R \mid a \in A\}$（所有等价类的集合）

## 6. 偏序关系与 Hasse 图

### 6.1 偏序关系

若 $R$ 满足**自反性、反对称性和传递性**，则 $R$ 为**偏序关系**，记作 $\leq$。$(A, \leq)$ 称为**偏序集**。

**全序（线序）**：偏序集中任意两个元素都可比较。

**例**：整除关系、集合包含关系、字典序都是偏序。

### 6.2 特殊元素

设 $(A, \leq)$ 为偏序集，$S \subseteq A$：

| 元素 | 定义 |
| :--- | :--- |
| 极大元 | $a \in S$，不存在 $b \in S$ 使 $a < b$ |
| 极小元 | $a \in S$，不存在 $b \in S$ 使 $b < a$ |
| 最大元 | $a \in S$，$\forall b \in S, b \leq a$（若存在则唯一） |
| 最小元 | $a \in S$，$\forall b \in S, a \leq b$（若存在则唯一） |
| 上界 | $u \in A$，$\forall b \in S, b \leq u$ |
| 下界 | $l \in A$，$\forall b \in S, l \leq b$ |
| 上确界 | $\sup S$，上界中的最小元 |
| 下确界 | $\inf S$，下界中的最大元 |

**易错点**：**极大元 ≠ 最大元**。极大元是"没有比它更大的"，最大元是"比所有都大"。极大元可以有多个，最大元至多一个。

### 6.3 Hasse 图：简化后的偏序图

绘制规则：

1. 省去自环（自反性）
2. 省去由传递性可推出的边
3. 若 $a < b$，则 $b$ 画在 $a$ 上方

**例**：$A = \{1,2,3,6\}$，偏序关系为整除关系 $|$。

```
     6
    / \
   2   3
    \ /
     1
```

> 极大元：6（也是最大元）
> 极小元：1（也是最小元）

### 6.4 格

若偏序集中任意两个元素都有上确界和下确界，则称为**格**（Lattice）。

- $a \vee b = \sup\{a,b\}$（并运算）
- $a \wedge b = \inf\{a,b\}$（交运算）

**例**：整除关系下，$a \vee b = \text{lcm}(a,b)$（最小公倍数），$a \wedge b = \gcd(a,b)$（最大公约数）。

## 7. 闭包运算

### 7.1 定义

关系 $R$ 的**闭包**是**包含 $R$ 且具有某种性质的最小关系**。

- **自反闭包**：$r(R) = R \cup I_A$（加上所有自环）
- **对称闭包**：$s(R) = R \cup R^{-1}$（加上所有反向边）
- **传递闭包**：$t(R) = \bigcup_{i=1}^{\infty} R^i = R \cup R^2 \cup R^3 \cup \cdots$（加上所有"捷径"）

### 7.2 传递闭包的计算

**有限集上**：若 $|A| = n$，则 $t(R) = \bigcup_{i=1}^{n} R^i$（最多 $n$ 步就能到达任意点）。

**Warshall 算法**（求传递闭包的关系矩阵，$O(n^3)$）：

```
W = M_R（关系矩阵的副本）
for k = 1 to n:
    for i = 1 to n:
        for j = 1 to n:
            W[i][j] = W[i][j] OR (W[i][k] AND W[k][j])
```

**例**：$A = \{1,2,3\}$，$R = \{(1,2),(2,3)\}$，求 $t(R)$。

> $R^2 = \{(1,3)\}$，$R^3 = \emptyset$
> $t(R) = R \cup R^2 \cup R^3 = \{(1,2),(2,3),(1,3)\}$

**理解**：传递闭包回答"我能通过几步到达谁"——像"朋友的朋友"关系。这在图论（可达性）和数据库（传递依赖）中有重要应用。

### 7.3 闭包的性质

$$rs(R) = sr(R)$$（自反和对称闭包可交换）

$$rt(R) = tr(R)$$（自反和传递闭包可交换）

$$st(R) \subseteq ts(R)$$（对称和传递闭包只保证包含关系）

## 8. 常见误区

**误区一：极大元就是最大元。** → 极大元可能有多个，最大元至多一个。判断时先分清"没有更大的"（极大）和"比所有都大"（最大）。

**误区二：笛卡尔积满足交换律。** → 不满足！$(a,b) \neq (b,a)$（有序对）。$A \times B$ 和 $B \times A$ 一般不同。

**误区三：幂集大小记不清。** → $|\mathcal{P}(A)| = 2^n$。每个元素"选或不选"两种可能。

**误区四：传递闭包需要无限并。** → 有限集 $n$ 个元素时，$t(R) = \bigcup_{i=1}^{n} R^i$（最多 $n$ 步），用 Warshall 算法 $O(n^3)$ 计算。
