## 0. 比较两个班级的成绩波动

两个平行班期末数学成绩的平均分一样（都是 75 分），但甲班最高 98、最低 52，乙班集中在 70-80 之间。作为年级组长，你会问：**两个班的成绩波动（方差）有显著差异吗？**

这就是 **$F$ 检验**的用武之地：**比较两个正态总体的方差是否相等**（方差齐性检验）。它也是 $t$ 检验的前置检查——做双总体 $t$ 检验前，通常先确认方差是否相等（相等用合并方差，不等用 Welch）。

$F$ 检验的思想极其简单：方差比！

$$F = \frac{S_1^2}{S_2^2} \sim F(n_1-1, n_2-1)$$

如果两个方差真相等，比值应接近 1；比值过大或过小，说明"波动有差异"。

本文用**比较驱动**的方式组织：先讲 $F$ 统计量与两方差比检验，再扩展到一个更强大的"比较工具"——**单因素方差分析（ANOVA）**（比较多个总体的均值），最后说明 $F$ 检验在 $t$ 检验中的作用与前提条件。

## 1. 两总体方差比的 F 检验

### 1.1 适用条件

两个正态总体 $N(\mu_1, \sigma_1^2)$ 和 $N(\mu_2, \sigma_2^2)$，两样本独立，检验方差是否相等（**方差齐性检验**）。

### 1.2 检验步骤

**假设**：

- 双侧：$H_0: \sigma_1^2 = \sigma_2^2$，$H_1: \sigma_1^2 \neq \sigma_2^2$
- 右侧：$H_0: \sigma_1^2 \leq \sigma_2^2$，$H_1: \sigma_1^2 > \sigma_2^2$
- 左侧：$H_0: \sigma_1^2 \geq \sigma_2^2$，$H_1: \sigma_1^2 < \sigma_2^2$

**检验统计量**（抽样分布定理七，$\sigma_1^2 = \sigma_2^2$ 时）：

$$F = \frac{S_1^2}{S_2^2} \sim F(n_1 - 1, n_2 - 1)$$

**拒绝域**：

| 检验类型 | 拒绝域 |
| --- | --- |
| 双侧 | $F > F_{\alpha/2}(n_1-1, n_2-1)$ 或 $F < F_{1-\alpha/2}(n_1-1, n_2-1)$ |
| 右侧 | $F > F_\alpha(n_1-1, n_2-1)$ |
| 左侧 | $F < F_{1-\alpha}(n_1-1, n_2-1) = \dfrac{1}{F_\alpha(n_2-1, n_1-1)}$ |

> **实用约定**：双侧检验时，习惯把**较大的样本方差放分子**，使 $F \geq 1$，只查上侧分位数 $F_{\alpha/2}$ 即可——这简化了查表。

### 1.4 F 检验在 t 检验中的作用

做双总体 $t$ 检验前，标准流程是：

1. 先用 $F$ 检验判断 $\sigma_1^2$ 是否等于 $\sigma_2^2$；
2. 若相等 → 用合并方差（Student）$t$ 检验；
3. 若不等 → 用 Welch $t$ 检验。

这就是"先比波动（$F$），再比位置（$t$）"的流水线。

## 2. 单因素方差分析（ANOVA）

### 2.1 问题

$F$ 检验能比较**两个**方差；而**方差分析**把比较扩展到**多个总体**：$k$ 个正态总体的均值是否全相等？比如三种饲料、四种教学方法、五种材料的比较。

**为什么叫"方差分析"**：虽然问的是均值，方法却从"方差的分解"入手——把总波动拆成"组间波动"与"组内波动"两部分，用比值做检验。

### 2.2 模型

设 $k$ 个正态总体 $N(\mu_i, \sigma^2)$（$i = 1, 2, \cdots, k$），方差相等（方差齐性），从第 $i$ 个总体抽取 $n_i$ 个样本。

$$H_0: \mu_1 = \mu_2 = \cdots = \mu_k, \quad H_1: \mu_i \text{ 不全相等}$$

### 2.3 平方和的分解

记总均值 $\bar{X} = \dfrac{1}{n}\sum_{i,j} X_{ij}$，第 $i$ 组均值 $\bar{X}_i$，$n = \sum n_i$。

**总平方和**：

$$S_T = \sum_{i=1}^k \sum_{j=1}^{n_i} (X_{ij} - \bar{X})^2$$

**组间平方和**（各组均值与总均值的偏离，反映"处理效应"）：

$$S_A = \sum_{i=1}^k n_i(\bar{X}_i - \bar{X})^2$$

**组内平方和**（各组内部波动，反映"随机误差"）：

$$S_E = S_T - S_A = \sum_{i=1}^k \sum_{j=1}^{n_i} (X_{ij} - \bar{X}_i)^2$$

核心恒等式：$S_T = S_A + S_E$——总波动 = 处理效应 + 随机误差。

### 2.4 方差分析表

| 来源 | 平方和 | 自由度 | 均方 | F 值 |
| --- | --- | --- | --- | --- |
| 组间（因素） | $S_A$ | $k-1$ | $\bar{S}_A = \dfrac{S_A}{k-1}$ | $F = \dfrac{\bar{S}_A}{\bar{S}_E}$ |
| 组内（误差） | $S_E$ | $n-k$ | $\bar{S}_E = \dfrac{S_E}{n-k}$ | |
| 总和 | $S_T$ | $n-1$ | | |

$H_0$ 下 $F = \dfrac{\bar{S}_A}{\bar{S}_E} \sim F(k-1, n-k)$。

**拒绝域**：$F > F_\alpha(k-1, n-k)$。

**直觉**：若 $H_0$ 成立，组间波动与组内波动都只是随机误差，比值应接近 1；组间波动明显大于组内波动（$F$ 很大），说明"分组确实造成了差异"。

## 3. F 检验与方差分析的前提条件

1. **正态性**：各总体服从正态分布（或近似）；
2. **方差齐性**：各总体方差相等（可用 $F$ 检验或 Levene 检验验证）；
3. **独立性**：各样本相互独立。

当方差齐性不满足时：

- 两组比较 → Welch $t$ 检验；
- 多组比较 → Welch 方差分析或非参数方法（如 Kruskal-Wallis 检验）。

### 3.4 F 分布与其他分布的关系

回顾《三大分布》的图谱，$F$ 分布并非孤立存在：

- 若 $T \sim t(n)$，则 $T^2 \sim F(1, n)$——均值检验的 $t$ 统计量平方后就是 $F$ 统计量；
- $\chi^2(n)/n$ 是 $F(n, \infty)$ 的极限情形（分母自由度趋于无穷）；
- $F$ 分布与 $\chi^2$ 分布同源于"平方和之比"，只是 $\chi^2$ 看"一个平方和"，$F$ 看"两个平方和的比值"。

**应用提示**：当组数 $k = 2$ 时，单因素方差分析的 $F$ 检验与双总体等方差 $t$ 检验**完全等价**，且统计量满足 $F = T^2$（对应自由度 $F(1, n_1+n_2-2)$ 与 $t(n_1+n_2-2)$）。这意味着"两个班比较"（$t$ 检验）与"多个班比较"（ANOVA）在数学上是统一的——ANOVA 是 $t$ 检验对多组的自然推广。

## 4. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 自由度颠倒 | $F$ 检验把 $F(n_1-1, n_2-1)$ 写成 $F(n_2-1, n_1-1)$ | 分子分母弄反 | 第一自由度 = 分子样本量减 1，第二自由度 = 分母样本量减 1 |
| 双侧只查上侧 | 双侧检验不把大方差放分子就只查上侧 | 查表不便 | 约定：大方差放分子，$F \geq 1$，只查 $F_{\alpha/2}(n_1-1, n_2-1)$ |
| 方差分析混淆平方和 | $S_A$ 与 $S_E$ 算反 | 不知分解定义 | $S_A$ = 组间（组均值对总均值），$S_E$ = 组内（组内对组均值），$S_T = S_A + S_E$ 用于校验 |
| 自由度配错 | ANOVA 组内自由度写成 $n-1$ | 不知分解 | 组间 $k-1$，组内 $n-k$，总和 $n-1$；三者相加校验 |
| 忘记方差齐性前提 | 方差悬殊仍做标准 ANOVA | 忽略前提 | 先做方差齐性检验；不满足改用 Welch 或非参数法 |
| 显著即两两都不同 | ANOVA 拒绝后直接断言"各组两两都不同" | 混淆整体与两两 | 拒绝只说明"不全相等"，需事后多重比较找差异组 |

## 6. 一句话记忆

**F 检验是"波动比较器"：两个方差比 $F = \frac{S_1^2}{S_2^2} \sim F(n_1-1, n_2-1)$，大方差放分子查上侧；方差分析把 $S_T = S_A + S_E$ 分解后算 $F = \frac{\bar{S}_A}{\bar{S}_E} \sim F(k-1, n-k)$，先比波动（$F$）再比均值（$t$）。**
