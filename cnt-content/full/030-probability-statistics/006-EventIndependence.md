## 0. 掷两次硬币的对照实验

请做两个实验：

- **实验甲**：掷一枚硬币，记录结果；再掷一枚，记录结果。问：第二次掷出正面，会影响第一次掷出正面的概率吗？显然不会。
- **实验乙**：从不透明的袋子里摸球，摸出一个不放回，再摸一个。问：第一次摸到红球，会影响第二次摸到红球的概率吗？会——袋子里红球少了。

**两件互不影响的事**，就是"独立"的直觉：一个事件的发生，不改变另一个事件发生的概率。掷硬币两次独立；不放回摸球不独立。

但直觉有时会骗人。本讲要教你的，不是"凭感觉判断独立"，而是用**数学定义**严格判定独立性——因为在复杂问题里，两个看似"有关系"的事件可能独立，看似"没关系"的事件反而相关。独立性与条件概率（004 讲）互为镜像：$P(A \mid B) = P(A)$ 即独立；独立是概率计算中"相乘"的合法依据。

## 1. 两个事件的独立性

### 1.1 定义

设 $A, B$ 是两个事件，若

$$P(AB) = P(A) \cdot P(B)$$

则称事件 $A$ 与 $B$ **相互独立**，简称**独立**。

**为什么用乘积定义？** 对照条件概率：

$$P(A \mid B) = \frac{P(AB)}{P(B)} = \frac{P(A)P(B)}{P(B)} = P(A)$$

即 $B$ 的发生**没有改变** $A$ 的概率——这正是"互不影响"的精确表达。反过来，若 $P(A \mid B) = P(A)$ 且 $P(B) > 0$，也推出 $P(AB) = P(A)P(B)$。所以两条路等价：

> $A, B$ 独立 $\iff$ $P(AB) = P(A)P(B)$ $\iff$（当 $P(B) > 0$ 时）$P(A \mid B) = P(A)$

### 1.2 独立性的判定方法

| 方法         | 适用场景                                       | 做法                                     |
| ------------ | ---------------------------------------------- | ---------------------------------------- |
| 定义法       | 已知概率，最可靠                               | 验证 $P(AB) \stackrel{?}{=} P(A)P(B)$   |
| 条件概率法   | 已知条件概率                                   | 验证 $P(A \mid B) \stackrel{?}{=} P(A)$ |
| 直观判断     | 试验机制本身清楚（如独立重复试验）             | 依据物理/逻辑机制判断，并注明依据        |

> **原则**：能算就算（定义法），算不了才用直观。用直观判断时必须给出机制理由（如"两次掷骰互不影响"），不能因为"看起来没关系"就断言独立。

### 1.3 独立性的重要性质

**性质 1**：若 $A$ 与 $B$ 独立，则 $A$ 与 $\bar{B}$、$\bar{A}$ 与 $B$、$\bar{A}$ 与 $\bar{B}$ 也分别独立。

**证明**（以 $A$ 与 $\bar{B}$ 为例）：

$$P(A\bar{B}) = P(A) - P(AB) = P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)P(\bar{B})$$

**性质 2**：$\varnothing$ 与任何事件独立；$\Omega$ 与任何事件独立。

**性质 3**：若 $P(A) = 0$ 或 $P(A) = 1$，则 $A$ 与任何事件独立。

### 1.4 独立与互斥：最容易混淆的一对

| 特征       | 互斥（不相容）                     | 独立                                 |
| ---------- | ---------------------------------- | ------------------------------------ |
| 定义       | $AB = \varnothing$                 | $P(AB) = P(A)P(B)$                   |
| 含义       | 不能同时发生                       | 互不影响                             |
| $P(AB)$    | $= 0$                              | $= P(A)P(B)$                         |
| 典型关系   | 若 $P(A), P(B) > 0$，互斥则必不独立 | 若 $P(A), P(B) > 0$，独立则必不互斥 |

**重要结论**：若 $P(A) > 0$ 且 $P(B) > 0$，则 $A$ 与 $B$ **互斥和独立不能同时成立**。

**直觉**：互斥意味着"一个发生，另一个必不发生"——一个事件的发生**强烈影响**了另一个，怎么可能独立？这个"正概率互斥必相关"的结论，几乎每年都有新手栽跟头，务必记住。

## 2. 实验驱动的判定训练：掷两次硬币

**实验**：掷两枚硬币，定义 $A$ = "第一枚正面"，$B$ = "第二枚正面"。

$$P(A) = P(B) = \frac{1}{2}, \quad P(AB) = P(\{HH\}) = \frac{1}{4} = P(A)P(B)$$

$A, B$ 独立——因为两枚硬币的物理机制互不影响。

**对照**：同一次掷一枚硬币，定义 $A$ = "正面"，$B$ = "反面"。$AB = \varnothing$，$P(AB) = 0 \neq \dfrac{1}{2} \times \dfrac{1}{2}$，不独立——它们是同一试验的两个互斥结果，天然相关。

**关键区分**：两个事件属于**同一次试验**还是**两次试验**，是判断独立性的第一线索。分属两次互不影响试验的事件通常独立；同一次试验的互斥事件必然相关。

## 3. 多个事件的独立性：三个及以上

### 3.1 三个事件的相互独立

设 $A, B, C$ 是三个事件，若同时满足四个等式：

1. $P(AB) = P(A)P(B)$
2. $P(AC) = P(A)P(C)$
3. $P(BC) = P(B)P(C)$
4. $P(ABC) = P(A)P(B)P(C)$

则称 $A, B, C$ **相互独立**。若只满足前三条，称**两两独立**。

> **注意**：两两独立 $\not\Rightarrow$ 相互独立。第三条（三事件同时发生的乘积公式）不能省。

### 3.2 反例：两两独立但不相互独立

掷两枚硬币，设 $A$ = "第一枚正面"，$B$ = "第二枚正面"，$C$ = "两次结果相同"。样本空间 $\Omega = \{HH, HT, TH, TT\}$，$A = \{HH, HT\}$，$B = \{HH, TH\}$，$C = \{HH, TT\}$。

$$P(A) = P(B) = P(C) = \frac{1}{2}$$

$$P(AB) = P(\{HH\}) = \frac{1}{4} = P(A)P(B) \quad \checkmark$$

$$P(AC) = P(\{HH\}) = \frac{1}{4} = P(A)P(C) \quad \checkmark$$

$$P(BC) = P(\{HH\}) = \frac{1}{4} = P(B)P(C) \quad \checkmark$$

$$P(ABC) = P(\{HH\}) = \frac{1}{4} \neq \frac{1}{8} = P(A)P(B)P(C) \quad \times$$

$A, B, C$ 两两独立但不相互独立。直觉解释：$C$ = "两次相同"被 $A$ 与 $B$ 的组合"牵制"——知道 $A$ 和 $B$ 都发生，就能推出 $C$ 必然发生（$HH$），三者并不真正独立。

### 3.3 $n$ 个事件的独立性

$A_1, A_2, \cdots, A_n$ **相互独立**：对其中任意 $k$ 个（$2 \leq k \leq n$）事件 $A_{i_1}, \cdots, A_{i_k}$，都有

$$P(A_{i_1} A_{i_2} \cdots A_{i_k}) = P(A_{i_1}) P(A_{i_2}) \cdots P(A_{i_k})$$

需要验证 $\dbinom{n}{2} + \cdots + \dbinom{n}{n} = 2^n - n - 1$ 个等式。

**重要性质**：若 $A_1, \cdots, A_n$ 相互独立，则：

1. 其中任意多个事件换成对立事件后仍相互独立；
2. **至少一个发生**的概率：

$$P\left(\bigcup_{i=1}^{n} A_i\right) = 1 - \prod_{i=1}^{n} P(\bar{A}_i) = 1 - \prod_{i=1}^{n}(1 - P(A_i))$$

性质 2 是"至少型"问题在独立条件下的黄金公式——把"并"变成"对立事件之交的乘积"。

## 4. 独立重复试验与伯努利试验

### 4.1 独立重复试验

若 $n$ 次试验的结果互不影响（每次试验在相同条件下独立进行），则称 $n$ 次试验为**独立重复试验**。

### 4.2 $n$ 重伯努利试验

每次试验只有两个结果（$A$ 与 $\bar{A}$），且 $P(A) = p$ 保持不变，独立重复 $n$ 次，称为 **$n$ 重伯努利试验**。$n$ 次中 $A$ 发生 $k$ 次的概率：

$$P(\text{恰好 } k \text{ 次}) = \binom{n}{k} p^k (1-p)^{n-k}$$

这正是**二项分布**（本模块 008 讲）的来历。$k$ 次成功需要：选哪 $k$ 次成功（$\dbinom{n}{k}$ 种），每次成功概率 $p^k$，其余 $n-k$ 次失败概率 $(1-p)^{n-k}$。

## 5. 应用：系统可靠性与密码破译

### 5.1 串联系统

$n$ 个元件串联，各元件独立工作、可靠度 $p_i$。系统正常 $\iff$ 全部元件正常：

$$R = \prod_{i=1}^{n} p_i$$

串联的可靠度随元件增多而**急剧下降**（乘法衰减）。

### 5.2 并联系统

$n$ 个元件并联，系统失效 $\iff$ 全部失效：

$$R = 1 - \prod_{i=1}^{n}(1 - p_i)$$

并联的可靠度随元件增多而**趋近 1**（冗余提升可靠性）——这是"备份"策略的概率论依据。

### 5.3 完整例题：密码破译

甲、乙、丙三人独立破译密码，能破译的概率分别为 $\dfrac{1}{5}, \dfrac{1}{4}, \dfrac{1}{3}$，求密码被破译的概率。

**解**：设 $A, B, C$ 分别为三人破译成功（独立）。"密码被破译" = $A \cup B \cup C$：

$$P(A \cup B \cup C) = 1 - P(\bar{A})P(\bar{B})P(\bar{C}) = 1 - \frac{4}{5} \times \frac{3}{4} \times \frac{2}{3} = 1 - \frac{2}{5} = \frac{3}{5}$$

若直接展开加法公式会很繁琐，独立性 + 对立事件一举解决。

**Python 模拟验证**：

```python
import random

def crack_prob(trials=100000):
    hit = 0
    for _ in range(trials):
        if (random.random() < 0.2 or      # 甲
            random.random() < 0.25 or     # 乙
            random.random() < 1/3):       # 丙
            hit += 1
    return hit / trials

print(f"模拟破译概率: {crack_prob():.4f}")   # 理论值 3/5 = 0.6
```

## 6. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 把"互斥"当成"独立"，或反之 | 概念混淆 | 混淆"不能同时发生"与"互不影响" | 互斥是集合关系（$AB=\varnothing$），独立是概率关系（$P(AB)=P(A)P(B)$）；正概率下两者互斥 |
| 2 | 未验证独立性就把 $P(AB)$ 写成 $P(A)P(B)$ | 概念错误 | 把相乘当默认 | 独立必须验证或由机制保证；否则用乘法公式 $P(A)P(B\mid A)$ |
| 3 | 认为"两两独立"就是"相互独立" | 概念错误 | 忽略第三个条件 | 三个事件相互独立必须四个等式全成立；记住两枚硬币 $A, B, C$ 反例 |
| 4 | 独立事件求"至少一个发生"时用 $P(A)+P(B)$ | 公式错误 | 忘记非互斥要减交集 | 用 $1 - \prod(1 - P(A_i))$；独立≠互斥，加法公式不适用 |
| 5 | 同一次试验的互斥事件误判为独立 | 概念错误 | 凭"感觉无关"判断 | 看机制：同一次试验的两个不同结果天然相关；分属独立试验才可能独立 |
| 6 | 串联系统用加法、并联系统用乘法 | 公式错误 | 记反可靠度公式 | 串联"全好才行"用连乘；并联"全坏才坏"用 $1 - $ 连乘 |

## 7. 实战练习

### 练习 1（入门）：判定独立

掷一颗骰子，设 $A$ = "掷出偶数"，$B$ = "掷出不小于 4"。判断 $A$ 与 $B$ 是否独立。

**提示**：用定义法逐一计算三个概率。

**参考答案要点**：$P(A) = \dfrac{1}{2}$，$P(B) = \dfrac{1}{2}$，$AB = \{4, 6\}$，$P(AB) = \dfrac{1}{3} \neq \dfrac{1}{4}$，故不独立。注意它们也不互斥（$\{4,6\}$ 非空）——既不互斥也不独立是常见的第三态。

### 练习 2（入门）：独立事件求并

$P(A) = 0.3$，$P(B) = 0.4$，$A$ 与 $B$ 独立，求 $P(A \cup B)$。

**提示**：独立事件的加法公式。

**参考答案要点**：$P(A \cup B) = 0.3 + 0.4 - 0.3 \times 0.4 = 0.7 - 0.12 = 0.58$。

### 练习 3（进阶）：至少一个发生

甲、乙两台机器独立运转，出故障概率分别为 0.1 和 0.2，求至少有一台出故障的概率。

**提示**：$1 - $ 两台都不出故障的概率。

**参考答案要点**：$P = 1 - 0.9 \times 0.8 = 1 - 0.72 = 0.28$。

### 练习 4（进阶）：伯努利试验

某射手每次命中概率 0.6，独立射击 4 次，求恰好命中 2 次的概率。

**提示**：$n$ 重伯努利，$P = \dbinom{4}{2} \times 0.6^2 \times 0.4^2$。

**参考答案要点**：$P = 6 \times 0.36 \times 0.16 = 0.3456$。

### 练习 5（挑战）：系统可靠性

某系统由三个独立元件构成：元件 1、2 串联后与元件 3 并联，可靠度分别为 $p_1 = 0.9$，$p_2 = 0.8$，$p_3 = 0.7$，求系统可靠度。

**提示**：先算串联部分 $p_{12} = p_1 p_2 = 0.72$，再把它与 $p_3$ 并联：$R = 1 - (1 - 0.72)(1 - 0.7)$。

**参考答案要点**：$R = 1 - 0.28 \times 0.3 = 1 - 0.084 = 0.916$。串联部分拖低可靠度，并联冗余把它拉回 91.6%。

## 8. 一句话记忆

> **独立 = 互不影响 = $P(AB) = P(A)P(B)$；它和"互斥"在正概率下水火不容；"至少一个发生"用 $1 - \prod(1-p_i)$；$n$ 重伯努利试验引出二项分布。**

## 深度专题扩展

### 13.1 独立性与相关性的度量

独立性是"零相关"的强版本：独立 $\Rightarrow$ 不相关，但不相关 $\not\Rightarrow$ 独立（对非正态分布）。协方差与相关系数（本模块 022、023 讲）度量线性相关性，而独立性要求"所有依赖关系都不存在"。对二维正态分布，独立 $\iff$ 不相关（$\rho = 0$）。

### 13.2 条件独立

在机器学习（朴素贝叶斯、马尔可夫模型）中，"给定 $Z$ 时 $A$ 与 $B$ 独立"（条件独立）比无条件独立更常用：$P(AB \mid Z) = P(A \mid Z)P(B \mid Z)$。条件独立不蕴含独立，反之亦然——这是贝叶斯网络建模的核心概念。
