## 0. 身高换算单位：一个函数的故事

你的身高是 175 cm。换算成英尺：$175 \div 30.48 \approx 5.74$ ft。这是一次**单位换算**——把厘米数 $X$ 变成 $Y = g(X) = X / 30.48$。

现在把 $X$ 换成一个**随机变量**（比如"随机抽一位成年人的身高"），问题就来了：**$Y = g(X)$ 还是随机变量，那么 $Y$ 服从什么分布？** 身高原本近似正态，换算成英尺后还是正态吗？方差会变吗？平均值会变吗？

这个"随机变量套上一个函数后，求新随机变量的分布"的问题，就是本讲的**变换驱动**主题。它在工程中无处不在：仪表读数换算、温度的摄氏/华氏互换、平方/开方处理（$X^2$、$\sqrt{X}$）、对数压缩（$\ln X$）、以及后面抽样分布里的 $\dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}}$ 标准化——全都是"随机变量的函数"。

**核心武器只有两件**：对连续型，要么用**分布函数法**（万能，从定义出发），要么用**公式法**（单调函数的快捷方式）；对离散型，直接**合并同类取值**。

## 1. 问题的提出与总览

设 $X$ 的分布已知，$g$ 是一个实值函数，求 $Y = g(X)$ 的分布。按 $X$ 的类型分两条路线：

| $X$ 的类型 | 方法                     | 特点                     |
| ---------- | ------------------------ | ------------------------ |
| 离散型     | 合并取值法               | 把 $g(x_k)$ 相同的 $x_k$ 的概率相加 |
| 连续型（$g$ 单调） | 公式法            | 快，但要求严格单调可导   |
| 连续型（$g$ 不单调） | 分布函数法（分段处理） | 万能，任何函数都适用     |

## 2. 分布函数法：万能工具

### 2.1 四步流程

1. 写 $Y$ 的分布函数：$F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$；
2. 解不等式 $g(X) \leq y$，转化为关于 $X$ 的不等式；
3. 用 $X$ 的分布函数/密度求该概率；
4. 若是连续型，对 $F_Y(y)$ 求导得 $f_Y(y)$。

**为什么万能**：它只依赖"概率 = 分布函数"这个定义，任何 $g$ 都能走通，只是第 2 步解不等式的难度不同。

### 2.2 单调函数的特例

若 $g$ 严格单调递增且可导：

$$F_Y(y) = P(g(X) \leq y) = P(X \leq g^{-1}(y)) = F_X(g^{-1}(y))$$

若 $g$ 严格单调递减：

$$F_Y(y) = P(g(X) \leq y) = P(X \geq g^{-1}(y)) = 1 - F_X(g^{-1}(y))$$

### 2.3 完整例题：正态的平方（卡方分布雏形）

**例题**：设 $X \sim N(0, 1)$，求 $Y = X^2$ 的分布。

**解**：$y \leq 0$ 时 $F_Y(y) = 0$。当 $y > 0$：

$$F_Y(y) = P(X^2 \leq y) = P(-\sqrt{y} \leq X \leq \sqrt{y}) = \Phi(\sqrt{y}) - \Phi(-\sqrt{y}) = 2\Phi(\sqrt{y}) - 1$$

求导（$g$ 不单调，用分布函数法而非公式法）：

$$f_Y(y) = 2\varphi(\sqrt{y}) \cdot \frac{1}{2\sqrt{y}} = \frac{1}{\sqrt{y}} \cdot \frac{1}{\sqrt{2\pi}} e^{-y/2} = \frac{1}{\sqrt{2\pi y}} e^{-y/2}, \quad y > 0$$

即 $Y \sim \chi^2(1)$——这是后续卡方分布（032 讲）的种子。**要点**：$x \mapsto x^2$ 不单调，必须用分布函数法把 $\{X^2 \leq y\}$ 拆成 $\{-\sqrt{y} \leq X \leq \sqrt{y}\}$。

## 3. 公式法：单调函数的快捷方式

### 3.1 公式

若 $g$ 严格单调可导，$h = g^{-1}$，则 $Y = g(X)$ 的密度为：

$$f_Y(y) = \begin{cases} f_X(h(y)) \cdot |h'(y)|, & y \in g \text{ 的值域} \\ 0, & \text{其他} \end{cases}$$

**推导直觉**：密度在变换下要"守恒"——$f_Y(y) \, dy = f_X(x) \, dx$，即 $f_Y(y) = f_X(x)\left|\dfrac{dx}{dy}\right|$。取绝对值是因为 $g$ 递减时 $dx/dy < 0$，概率密度必须是正的。

### 3.2 常见变换公式表

| 变换             | 公式                                                     | 结论                         |
| ---------------- | -------------------------------------------------------- | ---------------------------- |
| 线性 $Y = aX + b$ | $f_Y(y) = \dfrac{1}{|a|} f_X\left(\dfrac{y-b}{a}\right)$ | 正态仍正态、均匀仍均匀       |
| 幂 $Y = X^2$（$X > 0$） | $f_Y(y) = \dfrac{1}{2\sqrt{y}} f_X(\sqrt{y})$     | —                            |
| 指数 $Y = e^X$   | $f_Y(y) = \dfrac{1}{y} f_X(\ln y)$（$y > 0$）            | 正态的对数 → 对数正态        |
| 对数 $Y = \ln X$（$X > 0$） | $f_Y(y) = e^y f_X(e^y)$                        | —                            |

### 3.3 完整例题：正态的标准化

**例题**：设 $X \sim N(\mu, \sigma^2)$，求 $Y = \dfrac{X - \mu}{\sigma}$ 的分布。

**解**：$y = \dfrac{x - \mu}{\sigma}$ 严格递增，反函数 $x = \sigma y + \mu$，$|x'(y)| = \sigma$：

$$f_Y(y) = f_X(\sigma y + \mu) \cdot \sigma = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(\sigma y)^2}{2\sigma^2}} \cdot \sigma = \frac{1}{\sqrt{2\pi}} e^{-\frac{y^2}{2}} = \varphi(y)$$

故 $Y \sim N(0, 1)$。**这就是标准化公式的来源**——一切 $N(\mu, \sigma^2)$ 的概率计算都能化为标准正态查表（009 讲）。

### 3.4 完整例题：均匀到指数

**例题**：设 $X \sim U(0, 1)$，求 $Y = -\ln X$ 的分布。

**解**：$y = -\ln x$ 严格递减，反函数 $x = e^{-y}$，$|x'(y)| = e^{-y}$。当 $0 < y < +\infty$：

$$f_Y(y) = f_X(e^{-y}) \cdot e^{-y} = 1 \cdot e^{-y} = e^{-y}, \quad y > 0$$

即 $Y \sim \text{Exp}(1)$。若换成 $Y = -\dfrac{1}{\lambda}\ln X$，则 $Y \sim \text{Exp}(\lambda)$——这是逆变换法（010 讲）生成指数随机数的来源。

## 4. 非单调函数的处理：分段单调

### 4.1 思路

$g$ 不单调时，公式法失效。正确姿势：

1. 把 $g$ 的定义域分成若干单调区间；
2. 在每个区间上用分布函数法（或公式法）求 $F_Y$ 的贡献；
3. 合并（注意值域可能重叠，需分段讨论 $y$）。

### 4.2 完整例题：绝对值变换

**例题**：设 $X \sim N(0, 1)$，求 $Y = |X|$ 的分布。

**解**：$y > 0$ 时：

$$F_Y(y) = P(|X| \leq y) = P(-y \leq X \leq y) = \Phi(y) - \Phi(-y) = 2\Phi(y) - 1$$

$$f_Y(y) = 2\varphi(y) = \frac{2}{\sqrt{2\pi}} e^{-y^2/2}, \quad y > 0$$

这是"半正态分布"。绝对值把负半轴的密度"折叠"到正半轴，密度加倍。

### 4.3 完整例题：$U(-\pi/2, \pi/2)$ 的反正切

**例题**：设 $X \sim U\left(-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right)$，求 $Y = \tan X$ 的密度。

**解**：$y = \tan x$ 严格递增，$x = \arctan y$，$x'(y) = \dfrac{1}{1 + y^2}$：

$$f_Y(y) = \frac{1}{\pi} \cdot \frac{1}{1 + y^2}, \quad -\infty < y < +\infty$$

这是**柯西分布**（其期望不存在，是"肥尾"分布的代表）。注意 $X$ 的取值范围决定了 $Y$ 的值域为整个实数轴。

## 5. 离散型随机变量函数的分布

### 5.1 方法：合并取值

设 $X$ 分布律 $P(X = x_k) = p_k$，$Y = g(X)$：

1. 列出 $Y$ 的所有可能取值 $y_1, y_2, \cdots$；
2. 对每个 $y_j$：$P(Y = y_j) = \sum_{g(x_k) = y_j} p_k$（把映射到同一 $y_j$ 的所有 $x_k$ 的概率相加）。

### 5.2 完整例题

**例题**：设 $X$ 的分布律为

| $X$ | $-1$ | $0$ | $1$ | $2$ |
| --- | ---- | ---- | ---- | ---- |
| $P$ | 0.2  | 0.3  | 0.1  | 0.4  |

求 $Y = X^2$ 的分布律。

**解**：$Y$ 的可能取值 $0, 1, 4$：

$$P(Y = 0) = P(X = 0) = 0.3$$

$$P(Y = 1) = P(X = -1) + P(X = 1) = 0.2 + 0.1 = 0.3$$

$$P(Y = 4) = P(X = 2) = 0.4$$

| $Y$ | 0   | 1   | 4   |
| --- | --- | --- | --- |
| $P$ | 0.3 | 0.3 | 0.4 |

**要点**：$g(x_k) = g(x_l)$ 时（$x_k \neq x_l$）必须**合并概率**，这是离散变换最容易漏的一步。

## 6. 常见变换的分布结论表

| 变换                        | $X$ 的分布            | $Y$ 的分布                 | 应用             |
| --------------------------- | --------------------- | -------------------------- | ---------------- |
| $Y = aX + b$                | $N(\mu, \sigma^2)$    | $N(a\mu + b, a^2\sigma^2)$ | 标准化           |
| $Y = X^2$                   | $N(0, 1)$             | $\chi^2(1)$                | 卡方分布         |
| $Y = \dfrac{X - \mu}{\sigma}$ | $N(\mu, \sigma^2)$  | $N(0, 1)$                  | 查表计算         |
| $Y = e^X$                   | $N(\mu, \sigma^2)$    | 对数正态                    | 金融资产价格     |
| $Y = aX + b$                | $U(0, 1)$             | $U(b, a + b)$              | 区间平移伸缩     |
| $Y = -\dfrac{1}{\lambda}\ln X$ | $U(0, 1)$         | $\text{Exp}(\lambda)$      | 指数随机数       |
| $Y = \lambda X$             | $\text{Exp}(\lambda)$ | $\text{Exp}(1)$           | 标准化指数       |
| $Y = \tan X$                | $U(-\pi/2, \pi/2)$    | 柯西分布                    | 肥尾建模         |

## 7. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | $g$ 不单调却直接套公式法 | 方法错误 | 忘记公式法的前提 | 公式法仅限严格单调可导；否则用分布函数法 |
| 2 | 公式法忘记乘 $|h'(y)|$ 或把 $h'(y)$ 写成正的 | 公式错误 | 推导没吃透 | 用"密度守恒" $f_Y(y)dy = f_X(x)dx$ 推一遍 |
| 3 | 离散变换漏合并 $g(x_k)$ 相同的概率 | 计算错误 | 忽略"多对一" | 先列 $Y$ 的取值去重，再逐个累加映射来的概率 |
| 4 | 值域判断错误：把 $Y$ 的定义域写错 | 概念错误 | 没考虑 $g$ 的值域 | 先确定 $Y$ 的可能取值范围，再分段讨论 $F_Y$ |
| 5 | 正态平方 $X^2$ 忘了拆成 $\pm\sqrt{y}$ 两段 | 计算错误 | 解不等式不完整 | $\{X^2 \leq y\} = \{-\sqrt{y} \leq X \leq \sqrt{y}\}$，不可只取正根 |
| 6 | 分布函数法求完 $F_Y$ 忘记对 $y$ 求导得 $f_Y$ | 步骤缺失 | 流程不完整 | 四步走完：定义→解不等式→求概率→求导 |

## 8. 实战练习

### 练习 1（入门）：线性变换

设 $X \sim U(0, 1)$，求 $Y = 3X + 2$ 的密度。

**提示**：线性变换，$Y \sim U(2, 5)$。

**参考答案要点**：$f_Y(y) = \dfrac{1}{3}$，$2 \leq y \leq 5$；其余为 0。

### 练习 2（入门）：离散变换

$X$ 分布律：$P(X = -2) = 0.1$，$P(X = -1) = 0.2$，$P(X = 1) = 0.3$，$P(X = 2) = 0.4$。求 $Y = X^2$ 的分布律。

**提示**：$Y$ 取值 $1, 4$；注意合并。

**参考答案要点**：$P(Y = 1) = P(X=-1) + P(X=1) = 0.2 + 0.3 = 0.5$；$P(Y = 4) = P(X=-2) + P(X=2) = 0.1 + 0.4 = 0.5$。

### 练习 3（进阶）：指数到均匀

设 $X \sim \text{Exp}(1)$，求 $Y = e^{-X}$ 的分布。

**提示**：$y = e^{-x}$ 单调递减，$x = -\ln y$，$|x'(y)| = \dfrac{1}{y}$；$Y \in (0, 1)$。

**参考答案要点**：$f_Y(y) = e^{-(-\ln y)} \cdot \dfrac{1}{y} = 1$，$0 < y < 1$，即 $Y \sim U(0, 1)$。指数 → 均匀，与第 3.4 节"均匀 → 指数"互为逆变换。

### 练习 4（进阶）：$U(-1, 2)$ 的平方

设 $X \sim U(-1, 2)$，求 $Y = X^2$ 的密度。

**提示**：$Y \in [0, 4]$；分段：$0 \le y < 1$ 时 $X$ 的区间为 $[-\sqrt{y}, \sqrt{y}]$；$1 \le y < 4$ 时左端被 $-1$ 截断。

**参考答案要点**：

$$f_Y(y) = \begin{cases} \dfrac{1}{3\sqrt{y}}, & 0 < y < 1 \\ \dfrac{1}{6\sqrt{y}}, & 1 \leq y < 4 \\ 0, & \text{其他} \end{cases}$$

（$0 \le y < 1$：$F_Y = \dfrac{2\sqrt{y}}{3}$；$1 \le y < 4$：$F_Y = \dfrac{\sqrt{y} + 1}{3}$，分别求导。）

### 练习 5（挑战）：正态平方与卡方

证明：若 $X \sim N(0, 1)$，则 $Y = X^2 \sim \chi^2(1)$；并写出 $P(Y \leq 3.841)$ 用 $\Phi$ 的表达（$3.841 = 1.96^2$）。

**提示**：$P(Y \leq y) = 2\Phi(\sqrt{y}) - 1$。

**参考答案要点**：$P(Y \leq 3.841) = 2\Phi(1.96) - 1 = 0.95$。这正是"标准正态的平方落入 $[0, 3.841]$ 的概率为 95%"——与卡方分布临界值 $3.841$ 对应，是假设检验中卡方临界值的来源。

## 9. 一句话记忆

> **随机变量函数的分布只有两把钥匙：不单调或不会做就用分布函数法（$F_Y(y) = P(g(X) \le y)$ 四步走），严格单调就用公式法（$f_Y(y) = f_X(h(y))|h'(y)|$，密度守恒）；离散型则把映射到同一值的概率合并。**

## 深度专题扩展

### 13.1 雅可比行列式：多维变换的公式法

对二维变换 $(U, V) = (g_1(X, Y), g_2(X, Y))$，公式法推广为

$$f_{UV}(u, v) = f_{XY}(x(u,v), y(u,v)) \cdot |J|$$

其中 $J = \det\begin{pmatrix} \frac{\partial x}{\partial u} & \frac{\partial x}{\partial v} \\ \frac{\partial y}{\partial u} & \frac{\partial y}{\partial v} \end{pmatrix}$ 为雅可比行列式。它是"密度守恒"思想在多维的推广，也是求 $X + Y$、$XY$、$\dfrac{X}{Y}$ 等分布的标准工具。

### 13.2 对数正态与金融建模

资产价格通常用**对数正态分布**建模：$S_t = S_0 e^{X_t}$，$X_t \sim N(\mu t, \sigma^2 t)$。因为价格恒正、且收益率的连续复利对数近似正态。$Y = e^X$ 的变换（本讲 3.2 节）正是这一模型的数学基础。
