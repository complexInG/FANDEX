## 0. 身高换算单位：一个函数的故事

你的身高是 175 cm。换算成英尺：$175 \div 30.48 \approx 5.74$ ft。这是一次**单位换算**——把厘米数 $X$ 变成 $Y = g(X) = X / 30.48$。

现在把 $X$ 换成一个**随机变量**（比如"随机抽一位成年人的身高"），问题就来了：**$Y = g(X)$ 还是随机变量，那么 $Y$ 服从什么分布？** 身高原本近似正态，换算成英尺后还是正态吗？方差会变吗？平均值会变吗？

这个"随机变量套上一个函数后，求新随机变量的分布"的问题，就是本讲的**变换驱动**主题。它在工程中无处不在：仪表读数换算、温度的摄氏/华氏互换、平方/开方处理（$X^2$、$\sqrt{X}$）、对数压缩（$\ln X$）、以及后面抽样分布里的 $\dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}}$ 标准化——全都是"随机变量的函数"。

**核心武器只有两件**：对连续型，要么用**分布函数法**（万能，从定义出发），要么用**公式法**（单调函数的快捷方式）；对离散型，直接**合并同类取值**。

## 1. 问题的提出与总览

设 $X$ 的分布已知，$g$ 是一个实值函数，求 $Y = g(X)$ 的分布。按 $X$ 的类型分两条路线：

| $X$ 的类型 | 方法                     | 特点                     |
| ---------- | ------------------------ | ------------------------ |
| 离散型     | 合并取值法               | 把 $g(x_k)$ 相同的 $x_k$ 的概率相加 |
| 连续型（$g$ 单调） | 公式法            | 快，但要求严格单调可导   |
| 连续型（$g$ 不单调） | 分布函数法（分段处理） | 万能，任何函数都适用     |

## 2. 分布函数法：万能工具

### 2.1 四步流程

1. 写 $Y$ 的分布函数：$F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$；
2. 解不等式 $g(X) \leq y$，转化为关于 $X$ 的不等式；
3. 用 $X$ 的分布函数/密度求该概率；
4. 若是连续型，对 $F_Y(y)$ 求导得 $f_Y(y)$。

**为什么万能**：它只依赖"概率 = 分布函数"这个定义，任何 $g$ 都能走通，只是第 2 步解不等式的难度不同。

### 2.2 单调函数的特例

若 $g$ 严格单调递增且可导：

$$F_Y(y) = P(g(X) \leq y) = P(X \leq g^{-1}(y)) = F_X(g^{-1}(y))$$

若 $g$ 严格单调递减：

$$F_Y(y) = P(g(X) \leq y) = P(X \geq g^{-1}(y)) = 1 - F_X(g^{-1}(y))$$

## 3. 公式法：单调函数的快捷方式

### 3.1 公式

若 $g$ 严格单调可导，$h = g^{-1}$，则 $Y = g(X)$ 的密度为：

$$f_Y(y) = \begin{cases} f_X(h(y)) \cdot |h'(y)|, & y \in g \text{ 的值域} \\ 0, & \text{其他} \end{cases}$$

**推导直觉**：密度在变换下要"守恒"——$f_Y(y) \, dy = f_X(x) \, dx$，即 $f_Y(y) = f_X(x)\left|\dfrac{dx}{dy}\right|$。取绝对值是因为 $g$ 递减时 $dx/dy < 0$，概率密度必须是正的。

### 3.2 常见变换公式表

| 变换             | 公式                                                     | 结论                         |
| ---------------- | -------------------------------------------------------- | ---------------------------- |
| 线性 $Y = aX + b$ | $f_Y(y) = \dfrac{1}{|a|} f_X\left(\dfrac{y-b}{a}\right)$ | 正态仍正态、均匀仍均匀       |
| 幂 $Y = X^2$（$X > 0$） | $f_Y(y) = \dfrac{1}{2\sqrt{y}} f_X(\sqrt{y})$     | —                            |
| 指数 $Y = e^X$   | $f_Y(y) = \dfrac{1}{y} f_X(\ln y)$（$y > 0$）            | 正态的对数 → 对数正态        |
| 对数 $Y = \ln X$（$X > 0$） | $f_Y(y) = e^y f_X(e^y)$                        | —                            |

## 4. 非单调函数的处理：分段单调

### 4.1 思路

$g$ 不单调时，公式法失效。正确姿势：

1. 把 $g$ 的定义域分成若干单调区间；
2. 在每个区间上用分布函数法（或公式法）求 $F_Y$ 的贡献；
3. 合并（注意值域可能重叠，需分段讨论 $y$）。

## 5. 离散型随机变量函数的分布

### 5.1 方法：合并取值

设 $X$ 分布律 $P(X = x_k) = p_k$，$Y = g(X)$：

1. 列出 $Y$ 的所有可能取值 $y_1, y_2, \cdots$；
2. 对每个 $y_j$：$P(Y = y_j) = \sum_{g(x_k) = y_j} p_k$（把映射到同一 $y_j$ 的所有 $x_k$ 的概率相加）。

## 6. 常见变换的分布结论表

| 变换                        | $X$ 的分布            | $Y$ 的分布                 | 应用             |
| --------------------------- | --------------------- | -------------------------- | ---------------- |
| $Y = aX + b$                | $N(\mu, \sigma^2)$    | $N(a\mu + b, a^2\sigma^2)$ | 标准化           |
| $Y = X^2$                   | $N(0, 1)$             | $\chi^2(1)$                | 卡方分布         |
| $Y = \dfrac{X - \mu}{\sigma}$ | $N(\mu, \sigma^2)$  | $N(0, 1)$                  | 查表计算         |
| $Y = e^X$                   | $N(\mu, \sigma^2)$    | 对数正态                    | 金融资产价格     |
| $Y = aX + b$                | $U(0, 1)$             | $U(b, a + b)$              | 区间平移伸缩     |
| $Y = -\dfrac{1}{\lambda}\ln X$ | $U(0, 1)$         | $\text{Exp}(\lambda)$      | 指数随机数       |
| $Y = \lambda X$             | $\text{Exp}(\lambda)$ | $\text{Exp}(1)$           | 标准化指数       |
| $Y = \tan X$                | $U(-\pi/2, \pi/2)$    | 柯西分布                    | 肥尾建模         |

## 7. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | $g$ 不单调却直接套公式法 | 方法错误 | 忘记公式法的前提 | 公式法仅限严格单调可导；否则用分布函数法 |
| 2 | 公式法忘记乘 $|h'(y)|$ 或把 $h'(y)$ 写成正的 | 公式错误 | 推导没吃透 | 用"密度守恒" $f_Y(y)dy = f_X(x)dx$ 推一遍 |
| 3 | 离散变换漏合并 $g(x_k)$ 相同的概率 | 计算错误 | 忽略"多对一" | 先列 $Y$ 的取值去重，再逐个累加映射来的概率 |
| 4 | 值域判断错误：把 $Y$ 的定义域写错 | 概念错误 | 没考虑 $g$ 的值域 | 先确定 $Y$ 的可能取值范围，再分段讨论 $F_Y$ |
| 5 | 正态平方 $X^2$ 忘了拆成 $\pm\sqrt{y}$ 两段 | 计算错误 | 解不等式不完整 | $\{X^2 \leq y\} = \{-\sqrt{y} \leq X \leq \sqrt{y}\}$，不可只取正根 |
| 6 | 分布函数法求完 $F_Y$ 忘记对 $y$ 求导得 $f_Y$ | 步骤缺失 | 流程不完整 | 四步走完：定义→解不等式→求概率→求导 |

## 9. 一句话记忆

> **随机变量函数的分布只有两把钥匙：不单调或不会做就用分布函数法（$F_Y(y) = P(g(X) \le y)$ 四步走），严格单调就用公式法（$f_Y(y) = f_X(h(y))|h'(y)|$，密度守恒）；离散型则把映射到同一值的概率合并。**
