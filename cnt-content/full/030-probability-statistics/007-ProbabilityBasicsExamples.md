## 0. 一张彩票背后的全部概率知识

假设你花 10 元买了一张"幸运抽奖券"：开奖时从装有 100 个球的机器里摇出 5 个号码，你的券上也有 5 个号码。这张小小的彩票，几乎牵动了前六讲的全部知识点：

- 摇球机器里所有可能的号码组合——**样本空间与事件**（001 讲）；
- "中 3 个号"的概率——**古典概型**（002 讲）；
- 如果开奖结果与号码位置在某种"连续尺度"上随机——**几何概型**（003 讲）；
- "已知你已中 2 个号，再中 1 个的概率"——**条件概率**（004 讲）；
- "开奖结果是次品/异常信号，反推是哪个环节出了问题"——**贝叶斯公式**（005 讲）；
- "两个摇奖球互不影响"——**独立性**（006 讲）。

本讲把前六讲的知识点放在一组**真实感案例**里综合演练。建议先独立试做，再看解析；重点体会"这道题该用哪个工具"的判断过程。

## 1. 样本空间与事件运算（001 讲）

### 例题 1：事件的文字翻译

设 $A, B, C$ 为三个事件，用 $A, B, C$ 的运算表示下列事件：

（1）$A$ 发生，$B$ 与 $C$ 不发生：$A\bar{B}\bar{C}$；
（2）$A$ 与 $B$ 都发生，$C$ 不发生：$AB\bar{C}$；
（3）$A, B, C$ 中至少有一个发生：$A \cup B \cup C$；
（4）$A, B, C$ 都发生：$ABC$；
（5）$A, B, C$ 都不发生：$\bar{A}\bar{B}\bar{C}$；
（6）$A, B, C$ 中不多于一个发生：$\bar{A}\bar{B}\bar{C} \cup A\bar{B}\bar{C} \cup \bar{A}B\bar{C} \cup \bar{A}\bar{B}C$；
（7）$A, B, C$ 中恰有两个发生：$AB\bar{C} \cup A\bar{B}C \cup \bar{A}BC$；
（8）$A, B, C$ 中至少有两个发生：$AB \cup AC \cup BC$。

**要点**：先"逐字翻译"，再用德摩根律化简校验（如"都不发生" $\iff$ $\overline{A \cup B \cup C}$）。

### 例题 2：证明 $A \cup B = A \cup B\bar{A}$ 且两者互斥

**证明**：$A \cup B = A \cup (B - AB) = A \cup B\bar{A}$（差事件定义）。又

$$A \cap B\bar{A} = AB\bar{A} = A\bar{A}B = \varnothing$$

故 $A$ 与 $B\bar{A}$ 互斥。这个分解说明：**"$A$ 或 $B$"可以拆成互斥的两块**，是加法公式成立的几何直觉来源。

## 2. 古典概型（002 讲）

### 例题 3：抽鞋配双

从 5 双不同的鞋中任取 4 只，求：（1）至少有两只配成一双；（2）恰好配成两双。

**解**：分母 $\dbinom{10}{4} = 210$。

（1）$A$ = "至少配一双"，对立事件 $\bar{A}$ = "4 只都不配对"：从 5 双中选 4 双（$\dbinom{5}{4}$），每双取 1 只（$2^4$）：

$$P(\bar{A}) = \frac{5 \times 16}{210} = \frac{8}{21}, \qquad P(A) = 1 - \frac{8}{21} = \frac{13}{21}$$

（2）恰好两双：从 5 双中选 2 双：

$$P = \frac{\dbinom{5}{2}}{210} = \frac{10}{210} = \frac{1}{21}$$

**要点**："至少"优先对立事件；注意 $\bar{A}$ 的计数不重不漏。

### 例题 4：两数之和为偶数

从 $1, 2, \cdots, n$ 中任取两个数，求两数之和为偶数的概率。

**解**：两数和为偶数 $\iff$ 同为奇数或同为偶数。设 $n$ 中有 $k$ 个奇数、$n-k$ 个偶数。

- $n$ 为偶数时，$k = \dfrac{n}{2}$：

$$P = \frac{\binom{n/2}{2} + \binom{n/2}{2}}{\binom{n}{2}} = \frac{n-2}{2(n-1)}$$

- $n$ 为奇数时，$k = \dfrac{n+1}{2}$：

$$P = \frac{\binom{(n+1)/2}{2} + \binom{(n-1)/2}{2}}{\binom{n}{2}} = \frac{n-1}{2n}$$

**要点**：分类讨论时"不重不漏"，用组合数统一表达。

## 3. 几何概型（003 讲）

### 例题 5：两数之积小于四分之一

在 $(0,1)$ 中随机取两个数 $x, y$，求 $xy < \dfrac{1}{4}$ 的概率。

**解**：$\Omega$ 为单位正方形，$S(\Omega) = 1$。事件区域为双曲线 $y = \dfrac{1}{4x}$ 下方，分段积分（分段点 $x = \dfrac{1}{4}$ 是曲线与 $y = 1$ 的交点）：

$$S(A) = \int_0^{1/4} 1 \, dx + \int_{1/4}^{1} \frac{1}{4x} \, dx = \frac{1}{4} + \frac{1}{4}\ln 4$$

$$P(A) = \frac{1 + \ln 4}{4} \approx 0.597$$

### 例题 6：两船靠泊

甲乙两船在同一泊位停靠，甲停 1 小时、乙停 2 小时，两船到达时刻在一昼夜内等可能，求两船无需等待的概率。

**解**：设甲到达为 $x$、乙为 $y$（小时），$\Omega = [0,24]^2$，$S(\Omega) = 576$。无需等待 $\iff$ $y \geq x + 1$（乙到时空位已让出）或 $x \geq y + 2$。事件区域为两个三角形：

$$S(A) = \frac{1}{2}(23)^2 + \frac{1}{2}(22)^2 = \frac{529 + 484}{2} = \frac{1013}{2}$$

$$P(A) = \frac{1013/2}{576} = \frac{1013}{1152} \approx 0.879$$

**要点**：两个随机量 $\Rightarrow$ 二维样本空间；"无需等待"翻译成两条边界不同的直线区域。

## 4. 条件概率与乘法公式（004 讲）

### 例题 7：第三次才取到白球

袋中有 3 红 2 白，不放回取 3 次，求第三次才取到白球的概率。

**解**：设 $A_i$ = 第 $i$ 次取到红球：

$$P(\bar{A}_3 \text{ 前两次为红}) = P(A_1) P(A_2 \mid A_1) P(\bar{A}_3 \mid A_1 A_2) = \frac{3}{5} \times \frac{2}{4} \times \frac{2}{3} = \frac{1}{5}$$

**要点**：链式乘法中每步更新袋中构成（总数减一、红球减一）。

### 例题 8：已知条件概率反推

已知 $P(A) = \dfrac{1}{4}$，$P(B \mid A) = \dfrac{1}{3}$，$P(A \mid B) = \dfrac{1}{2}$，求 $P(A \cup B)$。

**解**：$P(AB) = P(A)P(B \mid A) = \dfrac{1}{4} \times \dfrac{1}{3} = \dfrac{1}{12}$；

$$P(B) = \frac{P(AB)}{P(A \mid B)} = \frac{1/12}{1/2} = \frac{1}{6}$$

$$P(A \cup B) = \frac{1}{4} + \frac{1}{6} - \frac{1}{12} = \frac{1}{3}$$

**要点**：条件概率定义式本身就是"解方程"的工具——已知 $P(AB)$ 与一个条件概率，可反解另一个边缘概率。

## 5. 全概率与贝叶斯公式（005 讲）

### 例题 9：三箱取一等品

三箱同型号产品各装 10、15、20 件，其中一等品 7、10、14 件。随机取一箱再取一件，求取到一等品的概率。

**解**：设 $B_i$ = 取到第 $i$ 箱（$i = 1,2,3$），$A$ = 取到一等品。全概率公式：

$$P(A) = \frac{1}{3} \times \frac{7}{10} + \frac{1}{3} \times \frac{10}{15} + \frac{1}{3} \times \frac{14}{20} = \frac{1}{3}\left(\frac{7}{10} + \frac{2}{3} + \frac{7}{10}\right) = \frac{61}{90}$$

**要点**：先找"原因分割"（三箱），再求加权平均。

### 例题 10：肝癌化验的阳性预测值

某地区肝癌发病率 0.0004；患癌者化验阳性的概率 0.95，非患癌者化验阴性的概率 0.90。某人化验阳性，求确患肝癌的概率。

**解**：设 $D$ = 患癌，$+$ = 阳性。

$$P(D \mid +) = \frac{0.0004 \times 0.95}{0.0004 \times 0.95 + 0.9996 \times 0.10} = \frac{0.00038}{0.00038 + 0.09996} = \frac{0.00038}{0.10034} \approx 0.00379$$

**结论**：即便化验为阳性，患癌概率也仅约 0.38%——低患病率下假阳性淹没真阳性（基础概率谬误）。

## 6. 事件的独立性（006 讲）

### 例题 11：互斥与独立下的条件不同解

设 $P(A) = 0.4$，$P(A \cup B) = 0.7$，在两种情况下求 $P(B)$：（1）$A$ 与 $B$ 互斥；（2）$A$ 与 $B$ 独立。

**解**：

（1）互斥：$P(A \cup B) = P(A) + P(B)$，$P(B) = 0.7 - 0.4 = 0.3$；

（2）独立：$P(A \cup B) = P(A) + P(B) - P(A)P(B)$，

$$0.7 = 0.4 + P(B) - 0.4P(B) = 0.4 + 0.6P(B) \implies P(B) = \frac{0.3}{0.6} = 0.5$$

**要点**：同一题面，关系不同则答案不同——先确认关系类型再选公式。

### 例题 12：三人破译密码

三人独立破译，能译出的概率分别为 $\dfrac{1}{5}, \dfrac{1}{3}, \dfrac{1}{4}$，求密码被译出的概率。

**解**：

$$P = 1 - \frac{4}{5} \times \frac{2}{3} \times \frac{3}{4} = 1 - \frac{2}{5} = \frac{3}{5}$$

## 7. 综合题（多知识点嵌套）

### 例题 13：次品来源追溯（全概率 + 贝叶斯 + 条件概率）

某工厂甲、乙、丙三台机器生产螺丝钉，产量占比 25%、35%、40%，次品率 5%、4%、2%。任取一件发现是次品，求它是甲机器生产的概率。

**解**：

$$P(\text{甲} \mid \text{次品}) = \frac{0.25 \times 0.05}{0.25 \times 0.05 + 0.35 \times 0.04 + 0.40 \times 0.02} = \frac{0.0125}{0.0345} = \frac{25}{69} \approx 0.362$$

虽然甲线产量最小，但次品率最高，所以"次品来自甲"的后验（36.2%）高于甲的产量占比（25%）——先验与似然共同决定后验。

### 例题 14：转移抽样（条件概率 + 全概率）

甲袋 2 白 3 黑，乙袋 4 白 1 黑。从甲袋取一球放入乙袋，再从乙袋取一球，求取到白球的概率。

**解**：设 $A$ = 从甲袋取到白球，$B$ = 从乙袋取到白球：

$$P(B) = P(A)P(B \mid A) + P(\bar{A})P(B \mid \bar{A}) = \frac{2}{5} \times \frac{5}{6} + \frac{3}{5} \times \frac{4}{6} = \frac{10 + 12}{30} = \frac{11}{15}$$

**要点**："转移抽样"是最典型的全概率应用题——第一步的结果改变第二步的条件，必须分情形加权。

### 例题 15：正相关的对称性

证明：若 $P(A \mid B) > P(A)$，则 $P(B \mid A) > P(B)$。

**证明**：

$$\frac{P(AB)}{P(B)} > P(A) \implies P(AB) > P(A)P(B)$$

$$\implies P(B \mid A) = \frac{P(AB)}{P(A)} > \frac{P(A)P(B)}{P(A)} = P(B)$$

**结论**："$A$ 促进 $B$"与"$B$ 促进 $A$"是同一件事的两种说法——相关性是**对称**的。这是理解"相关 ≠ 因果"的重要一环：相关性是双向的，因果性是单向的。

## 8. 综合解题心法：先分类，再选工具

面对一道概率应用题，按以下顺序"过筛子"：

| 判断问题                       | 使用的工具                                   | 对应讲次 |
| ------------------------------ | -------------------------------------------- | -------- |
| 样本空间有限且等可能？         | 古典概型 $\dfrac{m}{n}$ + 排列组合           | 002 讲   |
| 样本空间是连续几何区域？       | 几何概型（度量之比）+ 画图                   | 003 讲   |
| 题目含"已知……条件下"？         | 条件概率定义 + 乘法公式                       | 004 讲   |
| 求"整体概率"而原因可分类？     | 全概率公式                                   | 005 讲   |
| 求"某原因的概率"而结果已知？   | 贝叶斯公式                                   | 005 讲   |
| 题中含"独立""互不影响""至少"？ | 独立性 + $1 - \prod(1-p_i)$                  | 006 讲   |
| "至少/至多"难算？              | 对立事件 $1 - P(\bar{A})$                    | 001 讲   |

## 9. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 未判断"有限等可能"就套古典概型公式 | 概念错误 | 题型识别失误 | 先看样本空间：有限离散→古典，连续区域→几何 |
| 2 | 综合题中把"条件概率"与"联合概率"混用 | 概念错误 | 读题不细 | 有"已知"字样用条件概率；"同时/都"用联合概率 |
| 3 | 全概率公式中原因分割选错 | 建模错误 | 分类不互斥或不完备 | 检查分割：互斥 + 并集为 $\Omega$；画树状图辅助 |
| 4 | 贝叶斯题分母直接写 $P(A)$ 而不展开 | 公式错误 | 不知道分母是归一化常数 | 分母必须用全概率公式展开为 $\sum P(B_i)P(A \mid B_i)$ |
| 5 | 独立性题直接相乘 $P(AB) = P(A)P(B)$ 未验证 | 概念错误 | 把独立当默认 | 确认独立（机制或验证）后再相乘，否则用乘法公式 |
| 6 | 多步抽取后忘记更新袋中构成 | 计算错误 | 条件概率分子分母不变 | 每步都写"已知前序结果后"的条件概率并核对数量 |

## 10. 实战练习

### 练习 1（入门）：事件运算

从一副扑克牌（52 张）中任取一张，设 $A$ = 红桃，$B$ = 人头牌（J/Q/K）。求 $P(A \cup B)$。

**提示**：加法公式，注意 $AB$（红桃人头牌）有 3 张。

**参考答案要点**：$P(A) = \dfrac{13}{52}$，$P(B) = \dfrac{12}{52}$，$P(AB) = \dfrac{3}{52}$，$P(A \cup B) = \dfrac{13+12-3}{52} = \dfrac{22}{52} = \dfrac{11}{26}$。

### 练习 2（入门）：古典概型

袋中 6 个球（4 红 2 蓝），有放回取 3 次，求恰好 2 红 1 蓝的概率。

**提示**：有放回 = 每次独立；"恰好 2 红"用 $\dbinom{3}{2}$ 选位置。

**参考答案要点**：$P = \dbinom{3}{2}\left(\dfrac{4}{6}\right)^2\left(\dfrac{2}{6}\right) = 3 \times \dfrac{16}{36} \times \dfrac{1}{3} = \dfrac{48}{108} = \dfrac{4}{9}$。

### 练习 3（进阶）：条件概率

某班 30 人，其中 18 人学过编程、15 人学过概率、10 人两门都学过。任选一人，已知他学过编程，求他也学过概率的概率。

**提示**：条件概率定义，或缩小样本空间到 18 人。

**参考答案要点**：$P(\text{概率} \mid \text{编程}) = \dfrac{10}{18} = \dfrac{5}{9}$。

### 练习 4（进阶）：贝叶斯

某检测仪对真缺陷检出率 98%，对无缺陷误报率 5%。产品缺陷率 2%。一件产品被检出"有缺陷"，求它确有缺陷的概率。

**提示**：两事件贝叶斯。

**参考答案要点**：$P(D \mid +) = \dfrac{0.02 \times 0.98}{0.02 \times 0.98 + 0.98 \times 0.05} = \dfrac{0.0196}{0.0686} \approx 0.2857$。

### 练习 5（挑战）：综合设计

设计一个 3 个事件的例子（可用掷骰子/抽牌），使其**两两独立但三事件不相互独立**，并验证之。

**提示**：参考 006 讲两枚硬币 $A, B, C$ 反例的结构：令 $C$ 由 $A, B$ 共同决定（如"两次结果相同"）。

**参考答案要点**：掷两枚硬币，$A$ = 第一枚正，$B$ = 第二枚正，$C$ = 两次相同。验证：两两独立的三个等式成立，但 $P(ABC) = \dfrac{1}{4} \neq \dfrac{1}{8}$，故不相互独立。

## 11. 一句话记忆

> **先判断"有限等可能还是连续区域"，再看"有没有已知条件、要不要反推原因、有没有独立关系"，最后按工具表选公式——概率题的大多数错误，出在"选错工具"而非"算错数"。**

## 深度专题扩展

### 13.1 把"频率"当"概率"的工程陷阱

现实工程中我们常用频率近似概率（如用历史次品率估计次品概率）。这在大样本下成立（大数定律），但小样本、相关数据、选择偏差都会让频率严重偏离概率。做数据分析时，先问"这个频率是在什么条件下、对什么总体统计出来的"。

### 13.2 从事件概率到随机变量

前六讲讨论的是"事件"，但工程上更关心"数值"（次品件数、等待分钟数、偏差毫米数）。把事件编码成数，就得到**随机变量**——从下一讲开始，概率论将进入"分布律—分布函数—数字特征"的新语言体系。
