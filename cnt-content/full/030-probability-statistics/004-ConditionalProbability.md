## 0. 体检报告上的"已知信息"

设想你去体检，报告显示一项指标异常。此时你脑子里冒出的第一个问题是："我生病的概率有多大？"

注意：这个问题的答案，与体检之前你心中的"我可能有病"的概率**完全不同**。体检结果——那条"已知信息"——改变了你对各种可能性的估计。今天下雨（概率 40%）与"看到窗外地面全湿了"之后再判断"正在下雨"（概率大幅上升），是两个不同的概率。

这种"**知道了某些信息之后，重新评估另一个事件的概率**"的机制，就是本讲的主题——**条件概率**。它是概率论中最重要、也最容易被误用的概念之一：后面的全概率公式、贝叶斯公式、独立性、以及整座贝叶斯统计大厦，全部建立在条件概率之上。

## 1. 条件概率的定义

### 1.1 记号与定义

设 $A, B$ 是两个事件，且 $P(B) > 0$，则称

$$P(A \mid B) = \frac{P(AB)}{P(B)}$$

为**在事件 $B$ 发生的条件下，事件 $A$ 发生的条件概率**。

**读法**：$P(A \mid B)$ 读作"在 $B$ 条件下 $A$ 的概率"。竖线右边是**已知条件**，左边是**被重新评估的事件**。

### 1.2 为什么是"除以 $P(B)$"

这是条件概率最核心的直觉。把样本空间看成一块蛋糕：

- $P(AB)$ 是"蛋糕里 $A$ 和 $B$ 重叠的部分"占整块蛋糕的比例；
- 一旦知道 $B$ 发生了，样本空间就从整块蛋糕**缩小到 $B$ 这块**；
- 在缩小后的世界里，$A$ 占的比例 = $\dfrac{AB \text{ 部分}}{B \text{ 部分}} = \dfrac{P(AB)}{P(B)}$。

**条件概率 = 在缩小的样本空间里重新数比例。** 记住这一句，你就不会搞错方向。

### 1.3 一个直观例题：先理解再算

**例题**：掷一颗均匀骰子，已知掷出的是偶数，求掷出的是 2 的概率。

**解**：直接数：$\Omega = \{1,2,3,4,5,6\}$，已知偶数 $B = \{2,4,6\}$，在 $B$ 里只有 $\{2\}$ 满足条件：

$$P(\text{掷出 2} \mid \text{偶数}) = \frac{1}{3}$$

用定义验证：$P(AB) = P(\{2\}) = \dfrac{1}{6}$，$P(B) = \dfrac{3}{6} = \dfrac{1}{2}$，

$$P(A \mid B) = \frac{1/6}{1/2} = \frac{1}{3} \quad \checkmark$$

> 注意：$P(A) = \dfrac{1}{6}$，而 $P(A \mid B) = \dfrac{1}{3}$，两者不同——**已知信息改变了概率**。

### 1.4 条件概率与无条件概率的三种关系

| 关系             | 含义                                   | 例子                     |
| ---------------- | -------------------------------------- | ------------------------ |
| $P(A \mid B) > P(A)$ | $B$ 的发生**促进**了 $A$             | 下雨 → 带伞的概率上升    |
| $P(A \mid B) = P(A)$ | $B$ 与 $A$ **无关**（独立，见 006 讲） | 掷骰子 → 明天天气        |
| $P(A \mid B) < P(A)$ | $B$ 的发生**抑制**了 $A$             | 晴天 → 带伞的概率下降    |

## 2. 条件概率的性质：还是那三条公理

固定 $B$（$P(B) > 0$）时，$P(\cdot \mid B)$ 依然是一个合法的概率，因此满足：

1. 非负性：$P(A \mid B) \geq 0$；
2. 规范性：$P(\Omega \mid B) = 1$；
3. 可列可加性：$A_1, A_2, \cdots$ 两两互斥时，

$$P\left(\bigcup_{i=1}^{\infty} A_i \biggm| B\right) = \sum_{i=1}^{\infty} P(A_i \mid B)$$

因此无条件概率的所有公式在"条件后"仍然成立：

$$P(\bar{A} \mid B) = 1 - P(A \mid B)$$

$$P(A_1 \cup A_2 \mid B) = P(A_1 \mid B) + P(A_2 \mid B) - P(A_1 A_2 \mid B)$$

**一个常见误区**：$P(A \mid B) + P(A \mid \bar{B})$ 一般**不等于** 1。因为两个条件概率在不同的"缩小空间"里计算，分母不同，不能简单互补。

## 3. 乘法公式：把"链式依赖"串起来

### 3.1 两个事件的乘法公式

由定义直接移项：

$$P(AB) = P(A) \cdot P(B \mid A) = P(B) \cdot P(A \mid B)$$

**直觉**："$A$ 与 $B$ 同时发生" = "先发生 $A$（概率 $P(A)$），再在 $A$ 已发生的条件下发生 $B$（概率 $P(B \mid A)$）"。选择哪条路取决于哪边条件概率更好求。

### 3.2 多个事件的乘法公式（链式法则）

设 $P(A_1 A_2 \cdots A_{n-1}) > 0$，则

$$P(A_1 A_2 \cdots A_n) = P(A_1) \cdot P(A_2 \mid A_1) \cdot P(A_3 \mid A_1 A_2) \cdots P(A_n \mid A_1 A_2 \cdots A_{n-1})$$

**证明思路**：反复用两事件乘法公式，右边分母分子逐级相消。

## 4. 条件概率的三种计算方法

### 4.1 定义法

直接套 $P(A \mid B) = \dfrac{P(AB)}{P(B)}$。适用于已知 $P(AB)$ 与 $P(B)$ 的题目。

**例题**：已知 $P(A) = \dfrac{1}{4}$，$P(B \mid A) = \dfrac{1}{3}$，$P(A \mid B) = \dfrac{1}{2}$，求 $P(A \cup B)$。

**解**：$P(AB) = P(A)P(B \mid A) = \dfrac{1}{4} \times \dfrac{1}{3} = \dfrac{1}{12}$；

$$P(B) = \frac{P(AB)}{P(A \mid B)} = \frac{1/12}{1/2} = \frac{1}{6}$$

$$P(A \cup B) = \frac{1}{4} + \frac{1}{6} - \frac{1}{12} = \frac{3 + 2 - 1}{12} = \frac{1}{3}$$

### 4.2 缩小样本空间法

在 $B$ 发生的条件下，直接把样本空间换成 $B$，在里面数 $A$ 的比例。适用于古典概型类题目，通常比定义法快。

**例题**：掷两颗骰子，已知点数之和为 7，求其中至少有一颗为 3 的概率。

**解**：和为 7 的样本点共 6 个：$(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)$。其中含 3 的有 2 个：$(3,4), (4,3)$。故

$$P(\text{至少一颗为3} \mid \text{和为7}) = \frac{2}{6} = \frac{1}{3}$$

> 注意不能把"至少一颗为 3"理解成"其中一颗是 3 另一颗是 4"就结束——要回到原样本空间核对每个样本点的权重是否相同。

### 4.3 公式组合法

先用乘法公式、全概率公式（下一讲）等求出所需量，再代入条件概率定义。适用于信息不完整的题目。

## 5. 条件概率的三大应用场景

### 5.1 序贯抽取与决策

"先抽后抽是否公平"是经典问题：n 个人依次抽签（不放回），第 k 个人抽中签的概率是否与第 1 个人相同？

**例题**：5 张签中只有 1 张中签，甲乙依次各抽一张（不放回），求乙抽中签的概率。

**解**：乙抽中 = "甲未抽中且乙抽中"：

$$P(\text{乙中}) = P(\bar{A} B) = P(\bar{A}) P(B \mid \bar{A}) = \frac{4}{5} \times \frac{1}{4} = \frac{1}{5}$$

乙和甲抽中的概率**相同**，都是 $\dfrac{1}{5}$——先抽后抽公平。这就是"抽签与顺序无关"的概率论解释。

### 5.2 信息更新（贝叶斯视角的引子）

条件概率描述了"获得新信息后概率如何更新"。例如天气预报先报"明天下雨概率 30%"，随后雷达回波显示降雨云团接近，概率更新为 70%。本模块 005 讲将把这个思想形式化为贝叶斯公式。

### 5.3 可靠性分析

系统的某个元件"在已知另一元件正常"的条件下仍能工作的概率，是串联、并联系统可靠性计算的基础（详见本模块 006 讲）。

## 6. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 混淆 $P(AB)$ 与 $P(A \mid B)$ | 概念错误 | 分不清"同时发生"与"条件下发生" | $P(AB)$ 是完整样本空间里的比例；$P(A \mid B)$ 是在 $B$ 的缩小空间里的比例 |
| 2 | 混淆 $P(A \mid B)$ 与 $P(B \mid A)$，认为两者相等 | 概念错误 | 忽略条件方向 | 竖线左边是被评估事件，右边是已知信息；两者一般不等，需用贝叶斯公式转换 |
| 3 | 认为 $P(A \mid B) + P(A \mid \bar{B}) = 1$ | 公式错误 | 误以为两个条件概率互补 | 两个条件概率分母不同；只有 $P(A \mid B) + P(\bar{A} \mid B) = 1$ |
| 4 | 乘法公式中分母不随抽取递减（不放回抽球仍用 $\dfrac{5}{8}$） | 计算错误 | 忘记"取走不放回"改变了袋中构成 | 每取一次：总数减一、该类数量减一，逐个更新条件概率 |
| 5 | 缩小样本空间时漏掉样本点或权重不均 | 计数错误 | 枚举不完整 | 列出 $B$ 的全部样本点逐一核对；用定义法交叉验证 |
| 6 | 对 $P(B) = 0$ 的事件求条件概率 | 概念错误 | 忽略定义前提 | $P(A \mid B)$ 要求 $P(B) > 0$，否则无定义 |

## 8. 一句话记忆

> **条件概率 = 把样本空间缩小到"已知信息"上重新算比例：$P(A \mid B) = \dfrac{P(AB)}{P(B)}$；乘法公式则把联合事件拆成一串条件概率的乘积。**
