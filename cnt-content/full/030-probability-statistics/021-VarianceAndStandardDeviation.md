## 0. 从一个生活场景说起：平均分相同的两个班，谁更稳定？

一模考试，A 班和 B 班平均分都是 80 分。A 班人人考 78-82 分，B 班一半人考 60 分、一半人考 100 分。你会怎么评价？

平均分（期望）一样，但两个班的"表现质量"完全不同：A 班**稳定**，B 班**波动大**。老师要看"分数离散程度"，家长要选"成绩稳定的班级"——仅靠期望（中心位置）远远不够，我们还需要一个刻画**波动性**的指标。

这就是方差（Variance）与标准差（Standard Deviation）的用武之地。

本文采用"**对比驱动**"的叙事结构：全程把"期望 vs 方差"放在一起对比——期望回答"平均在哪"，方差回答"波动多大"；期望看中心，方差看散布；期望有线性性质，方差有"平方"性质。通过对比，两个概念的记忆将更加牢固。

## 1. 对比总览：期望与方差

| 对比维度 | 期望 $E(X)$ | 方差 $D(X)$ |
| --- | --- | --- |
| 回答的问题 | 取值中心在哪 | 取值偏离中心多远 |
| 直觉 | 加权平均/重心 | 平均"离均偏差的平方" |
| 定义 | $\sum x_k p_k$ 或 $\int x f(x)dx$ | $E[X - E(X)]^2$ |
| 量纲 | 与 $X$ 相同 | 是 $X$ 量纲的平方 |
| 线性变换 | $E(aX+b) = aE(X)+b$ | $D(aX+b) = a^2 D(X)$ |
| 和的性质 | $E(X+Y) = E(X)+E(Y)$（无需独立） | $D(X+Y) = D(X)+D(Y)$（需独立或不相关） |
| 恒有 | 可正可负 | $D(X) \geq 0$ |

## 2. 方差的定义

### 2.1 定义

设 $X$ 是随机变量，若 $E[X - E(X)]^2$ 存在，则称

$$D(X) = \text{Var}(X) = E\left[X - E(X)\right]^2$$

为 $X$ 的**方差**。

直觉："每个取值离均值多远"的平均。为什么用**平方**而不是绝对值？因为平方可以放大远离均值的偏差、处处可导便于计算，且数学性质最好（与二范数、协方差天然衔接）。代价是量纲变成了平方——于是有了标准差。

### 2.2 最常用的计算公式

$$D(X) = E(X^2) - [E(X)]^2$$

**推导**（利用期望线性性质展开平方）：

$$D(X) = E[X - E(X)]^2 = E\left[X^2 - 2X E(X) + E(X)^2\right]$$

$$= E(X^2) - 2E(X) \cdot E(X) + E(X)^2 = E(X^2) - [E(X)]^2$$

这条公式把"先减均值再平方"换成"先平方再取期望"，计算量大减，做题时优先使用。

### 2.3 离散型与连续型

**离散型**：

$$D(X) = \sum_{k=1}^{\infty} [x_k - E(X)]^2 p_k = \sum_{k=1}^{\infty} x_k^2 p_k - [E(X)]^2$$

**连续型**：

$$D(X) = \int_{-\infty}^{+\infty} [x - E(X)]^2 f(x) \, dx = \int_{-\infty}^{+\infty} x^2 f(x) \, dx - [E(X)]^2$$

### 2.4 例题 1（离散型，两种算法对比）

设 $X$ 的分布律为 $P(X=0)=0.5$，$P(X=1)=0.3$，$P(X=2)=0.2$，求 $D(X)$。

**解**：先算 $E(X) = 0 \times 0.5 + 1 \times 0.3 + 2 \times 0.2 = 0.7$。

再算 $E(X^2) = 0^2 \times 0.5 + 1^2 \times 0.3 + 2^2 \times 0.2 = 0.3 + 0.8 = 1.1$。

$$D(X) = E(X^2) - [E(X)]^2 = 1.1 - 0.49 = 0.61$$

### 2.5 例题 2（连续型）

设 $X$ 的密度为 $f(x) = \begin{cases} 3x^2, & 0 < x < 1 \\ 0, & \text{其他} \end{cases}$，求 $D(X)$。

**解**：

$$E(X) = \int_0^1 x \cdot 3x^2 \, dx = \frac{3}{4}, \qquad E(X^2) = \int_0^1 x^2 \cdot 3x^2 \, dx = \frac{3}{5}$$

$$D(X) = \frac{3}{5} - \left(\frac{3}{4}\right)^2 = \frac{3}{5} - \frac{9}{16} = \frac{48 - 45}{80} = \frac{3}{80}$$

## 3. 标准差：把量纲"还"回去

### 3.1 定义

方差的算术平方根称为**标准差**（均方差）：

$$\sigma(X) = \sqrt{D(X)}$$

### 3.2 为什么需要标准差

身高数据的方差单位是"平方厘米"，无法直观解释；标准差单位回到"厘米"，可以直接说"身高平均偏离均值约 5 厘米"。标准差的另一个名字叫 $\sigma$，正态分布的 $\sigma$ 直接控制曲线胖瘦：$\sigma$ 小则曲线尖瘦集中，$\sigma$ 大则曲线扁平分散。

### 3.3 例题 3（标准差）

承例题 2，$\sigma(X) = \sqrt{\dfrac{3}{80}} \approx 0.1936$。即 $X$ 平均偏离均值 $\dfrac{3}{4}$ 约 0.19。

## 4. 方差的性质

设 $C$ 为常数，$X, Y$ 为随机变量，则：

1. **非负性**：$D(X) \geq 0$，且 $D(X) = 0 \iff P(X = C) = 1$（方差为 0 意味着 $X$ 是"退化"的常数）；
2. **常数**：$D(C) = 0$；
3. **线性变换**：$D(aX + b) = a^2 D(X)$——平移 $b$ 不改变波动，缩放 $a$ 使方差放大 $a^2$ 倍；
4. **独立可加性**：若 $X$ 与 $Y$ 独立，则 $D(X \pm Y) = D(X) + D(Y)$；
5. **一般公式**：$D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X, Y)$（不独立时交叉项出现，见《协方差》）；
6. **标准化**：若 $D(X) > 0$，则 $D\left(\dfrac{X - E(X)}{\sqrt{D(X)}}\right) = 1$——标准化的变量方差恒为 1。

### 4.1 性质 3 的证明

$$D(aX + b) = E[aX + b - aE(X) - b]^2 = E[a(X - E(X))]^2 = a^2 E[X - E(X)]^2 = a^2 D(X)$$

### 4.2 性质 4 的证明（独立情形）

$$D(X + Y) = E[(X+Y)^2] - [E(X+Y)]^2$$

$$= E(X^2) + 2E(XY) + E(Y^2) - [E(X)]^2 - 2E(X)E(Y) - [E(Y)]^2$$

独立时 $E(XY) = E(X)E(Y)$，交叉项抵消：

$$D(X + Y) = E(X^2) - [E(X)]^2 + E(Y^2) - [E(Y)]^2 = D(X) + D(Y)$$

**关键对比**：期望的可加性**不需要独立**（$E(X+Y)=E(X)+E(Y)$ 永远成立），而方差的"可加性"**必须独立**（否则要加 $2\text{Cov}$ 交叉项）。这是新手最容易混淆的一对性质。

## 5. 常用分布的方差

| 分布 | 期望 | 方差 |
| --- | --- | --- |
| 0-1 分布 $B(1, p)$ | $p$ | $p(1-p)$ |
| 二项分布 $B(n, p)$ | $np$ | $np(1-p)$ |
| 泊松分布 $P(\lambda)$ | $\lambda$ | $\lambda$ |
| 几何分布 $G(p)$ | $\dfrac{1}{p}$ | $\dfrac{1-p}{p^2}$ |
| 均匀分布 $U(a, b)$ | $\dfrac{a+b}{2}$ | $\dfrac{(b-a)^2}{12}$ |
| 指数分布 $\text{Exp}(\lambda)$ | $\dfrac{1}{\lambda}$ | $\dfrac{1}{\lambda^2}$ |
| 正态分布 $N(\mu, \sigma^2)$ | $\mu$ | $\sigma^2$ |

### 5.1 例题 4（二项分布方差的推导）

$X \sim B(n, p)$：写成 $X = \sum X_i$，$X_i \sim B(1, p)$ 独立。

$$D(X_i) = E(X_i^2) - [E(X_i)]^2 = p - p^2 = p(1-p)$$

$$D(X) = \sum_{i=1}^n D(X_i) = np(1-p)$$

### 5.2 例题 5（泊松分布方差的推导）

$X \sim P(\lambda)$，$E(X) = \lambda$。可以算得 $E(X^2) = \lambda(\lambda + 1)$，故

$$D(X) = E(X^2) - [E(X)]^2 = \lambda(\lambda + 1) - \lambda^2 = \lambda$$

泊松分布的期望与方差相等（都等于 $\lambda$），这是它独有的识别特征。

## 6. 变异系数：消除量纲的"相对波动"

$$C_V = \frac{\sqrt{D(X)}}{E(X)} = \frac{\sigma}{\mu}$$

变异系数把标准差除以均值，得到一个无量纲的比值，用来比较**不同量纲或不同均值水平**的离散程度。例如比较"大象体重（kg）"与"蚂蚁体重（mg）"的波动，直接用标准差不可比，用变异系数就公平了。

### 例题 6（变异系数）

股票 A 年收益率均值 20%、标准差 40%；股票 B 年收益率均值 5%、标准差 15%。谁的相对风险更大？

**解**：

$$C_V^A = \frac{40\%}{20\%} = 2.0, \qquad C_V^B = \frac{15\%}{5\%} = 3.0$$

B 的变异系数更大，说明相对其收益水平，B 的波动更剧烈，风险更高。

## 7. 方差的应用：风险度量与投资组合

在金融中，方差是**风险**的标准度量：方差越大，收益不确定性越高。

设两种资产收益率分别为 $X$、$Y$，权重为 $w$、$1-w$，组合收益 $R = wX + (1-w)Y$ 的方差为

$$D(R) = w^2 D(X) + (1-w)^2 D(Y) + 2w(1-w)\text{Cov}(X, Y)$$

当 $\text{Cov}(X, Y) < 0$ 时，第三项为负，组合方差下降——**分散投资降低风险**的数学原理（马科维茨投资组合理论）。这里的 $\text{Cov}$ 就是下一篇要学的协方差。

### 例题 7（组合风险）

$X$、$Y$ 独立，$D(X) = D(Y) = 0.04$，权重各半，求组合方差并与单资产对比。

**解**：$w = 0.5$，独立时协方差为 0：

$$D(R) = 0.25 \times 0.04 + 0.25 \times 0.04 = 0.02$$

组合方差 $0.02$ 小于单资产方差 $0.04$——只要两资产不完全正相关，分散化就能降低风险。

## 8. 常见错误与对策

| 错误示例 | 错误类型 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 认为 $D(X+Y) = D(X)+D(Y)$ 无条件成立 | 前提遗漏 | 把期望可加性套到方差上 | 方差可加需要独立（或不相关）；否则加 $2\text{Cov}(X,Y)$ |
| 把 $D(2X)$ 算成 $2D(X)$ | 公式误用 | 忘记系数要平方 | $D(aX+b) = a^2 D(X)$；$D(2X) = 4D(X)$ |
| 用 $E(X^2)$ 冒充 $D(X)$ | 概念混淆 | 忘记减掉 $[E(X)]^2$ | $D(X) = E(X^2) - [E(X)]^2$；只有 $E(X)=0$ 时两者才相等 |
| 算方差忘写单位/量纲 | 概念混淆 | 忽略量纲意义 | 方差是量纲的平方，标准差量纲与原变量一致，解释用标准差 |
| 认为 $D(X) = 0$ 就是 $X = 0$ | 概念错误 | 混淆"退化分布"与"取值 0" | $D(X)=0 \iff P(X=C)=1$，$C$ 是某个常数（即 $E(X)$），$X$ 以概率 1 恒等于 $C$ |
| 求 $E[(X+1)^2]$ 时展开漏项 | 计算错误 | 平方展开不完整 | $E[(X+1)^2] = E(X^2) + 2E(X) + 1$，再代入 $E(X^2) = D(X)+[E(X)]^2$ |

## 9. 实战练习

### 练习 1（定义计算）

设 $X$ 的分布律为 $P(X=1)=0.4$，$P(X=2)=0.4$，$P(X=3)=0.2$，求 $D(X)$。

**提示**：先算 $E(X)$ 与 $E(X^2)$。

**参考答案要点**：$E(X) = 1.8$，$E(X^2) = 3.6$，$D(X) = 3.6 - 3.24 = 0.36$。

### 练习 2（连续型方差）

设 $X$ 的密度为 $f(x) = 2x$（$0 < x < 1$），求 $D(X)$ 与 $\sigma(X)$。

**提示**：$E(X) = \int_0^1 2x^2 dx$。

**参考答案要点**：$E(X) = \dfrac{2}{3}$，$E(X^2) = \dfrac{1}{2}$，$D(X) = \dfrac{1}{2} - \dfrac{4}{9} = \dfrac{1}{18}$，$\sigma = \dfrac{1}{3\sqrt{2}} \approx 0.2357$。

### 练习 3（线性变换）

设 $X \sim B(10, 0.4)$，求 $E(3X+2)$ 与 $D(3X+2)$。

**提示**：$E(X) = 4$，$D(X) = 2.4$。

**参考答案要点**：$E(3X+2) = 14$；$D(3X+2) = 9 \times 2.4 = 21.6$。

### 练习 4（已知期望方差反推）

设 $E(X) = 10$，$D(X) = 4$，求 $E[(X+1)^2]$。

**提示**：展开后用 $E(X^2) = D(X) + [E(X)]^2$。

**参考答案要点**：$E[(X+1)^2] = E(X^2) + 2E(X) + 1 = (4+100) + 20 + 1 = 125$。

### 练习 5（独立和方差）

设 $X \sim N(1, 4)$，$Y \sim N(2, 9)$ 独立，求 $D(2X - 3Y + 1)$。

**提示**：独立时系数平方后相加。

**参考答案要点**：$D = 4 \times 4 + 9 \times 9 = 97$。

## 10. 一句话记忆

期望看"中心"（$E(X)$），方差看"波动"（$D(X) = E[X-E(X)]^2 = E(X^2) - [E(X)]^2$），标准差 $\sigma = \sqrt{D(X)}$ 把量纲还回去；线性变换 $D(aX+b) = a^2 D(X)$，独立时方差才可加。
