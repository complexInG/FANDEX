## 0. 用一把"刻度未知的尺子"量东西

上一篇文章里，$Z$ 检验的前提是"手里有出厂校准的标准尺"（$\sigma$ 已知）。可现实中，$\sigma$ 常常是**未知**的——你手里只有一把粗糙的尺子（样本标准差 $S$ 就是它的刻度）。用 $S$ 代替 $\sigma$ 之后，标准化统计量的尾巴会变"胖"（不确定性变大），分布不再是标准正态，而成了 **$t$ 分布**。

**t 检验的适用条件**：

- 总体服从正态分布 $N(\mu, \sigma^2)$；
- **$\sigma$ 未知**（用小样本 $S$ 代替）；
- 样本量不大（$n$ 小，$t$ 分布与正态差异明显；$n$ 大时 $t$ 近似正态，两种检验趋同）。

"t"这个名字来自戈塞特（W. S. Gosset）1908 年以"Student"笔名发表的论文——他当时是酿酒厂检验员，用小样本数据发现了这个分布，因此 $t$ 分布也叫**学生分布**。

本文用**条件驱动**的方式组织：围绕"$\sigma$ 未知"这一核心条件，依次给出单总体 $t$ 检验、双总体等方差 $t$ 检验、双总体不等方差 Welch $t$ 检验、配对 $t$ 检验四种场景，每种场景讲清"什么时候用、统计量是什么、自由度是多少"，并配完整例题。

## 1. 单总体均值的 t 检验

### 1.1 适用条件

- 总体 $X \sim N(\mu, \sigma^2)$，**$\sigma$ 未知**；
- 用样本标准差 $S$ 代替 $\sigma$。

### 1.2 检验步骤

**假设**：

- 双侧：$H_0: \mu = \mu_0$，$H_1: \mu \neq \mu_0$
- 右侧：$H_0: \mu \leq \mu_0$，$H_1: \mu > \mu_0$
- 左侧：$H_0: \mu \geq \mu_0$，$H_1: \mu < \mu_0$

**检验统计量**（抽样分布定理四）：

$$T = \frac{\bar{X} - \mu_0}{S/\sqrt{n}} \sim t(n-1)$$

**拒绝域**：

| 检验类型 | 拒绝域 |
| --- | --- |
| 双侧 | $\|T\| > t_{\alpha/2}(n-1)$ |
| 右侧 | $T > t_\alpha(n-1)$ |
| 左侧 | $T < -t_\alpha(n-1)$ |

### 1.3 完整例题

**例题**：某批零件的长度服从正态分布，标准长度为 50mm。现抽取 6 件，测得长度为：49.8, 50.2, 50.1, 49.7, 50.3, 49.9。在 $\alpha = 0.05$ 下检验该批零件长度是否符合标准。

**解**：

**第 1 步（提假设）**：

$$H_0: \mu = 50, \quad H_1: \mu \neq 50 \quad \text{（双侧）}$$

**第 2 步（算统计量）**：

$$\bar{x} = \frac{49.8 + 50.2 + 50.1 + 49.7 + 50.3 + 49.9}{6} = \frac{300.0}{6} = 50.0$$

$$\sum x_i^2 = 2480.04 + 2520.04 + 2510.01 + 2470.09 + 2530.09 + 2490.01 = 15000.28$$

$$S^2 = \frac{1}{5}(15000.28 - 6 \times 50.0^2) = \frac{1}{5}(15000.28 - 15000.00) = 0.056, \quad S \approx 0.237$$

$$T = \frac{50.0 - 50}{0.237/\sqrt{6}} = \frac{0}{0.0968} = 0$$

**第 3 步（定拒绝域）**：双侧，$t_{0.025}(5) = 2.571$，拒绝域 $|T| > 2.571$。

**第 4 步（决策）**：$|T| = 0 < 2.571$，**不拒绝 $H_0$**——没有证据表明零件长度偏离标准。

### 1.4 例题：右侧检验

**例题**：某品牌宣称其麦片每袋平均含量不少于 500g。质检员抽查 9 袋，$\bar{x} = 502$g，$s = 3$g。设含量服从正态分布，在 $\alpha = 0.05$ 下检验该宣称是否可信。

**解**：

想证明"不足"（$\mu < 500$）需左侧检验；这里检验"宣称是否可信"，即检验是否有证据表明 $\mu > 500$（厂商吹牛方向），通常按：

$$H_0: \mu \leq 500, \quad H_1: \mu > 500 \quad \text{（右侧）}$$

$$T = \frac{502 - 500}{3/\sqrt{9}} = \frac{2}{1} = 2$$

右侧拒绝域 $T > t_{0.05}(8) = 1.860$。$T = 2 > 1.860$，**拒绝 $H_0$**——有显著证据表明平均含量超过 500g（宣称得到数据支持）。

## 2. 双总体均值差的 t 检验

### 2.1 等方差情形（Student t 检验）

**条件**：两个正态总体，$\sigma_1^2 = \sigma_2^2 = \sigma^2$（但**未知**）。

**检验统计量**（抽样分布定理六）：

$$T = \frac{(\bar{X} - \bar{Y}) - d_0}{S_w\sqrt{\frac{1}{n_1} + \frac{1}{n_2}}} \sim t(n_1 + n_2 - 2)$$

其中联合方差

$$S_w^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}$$

**为什么用联合方差**：$\sigma^2$ 对两个总体相同，把两组的平方和"合并"起来估计，信息更充分、估计更准。

### 2.2 不等方差情形（Welch t 检验）

**条件**：$\sigma_1^2 \neq \sigma_2^2$（未知）。

**检验统计量**：

$$T = \frac{(\bar{X} - \bar{Y}) - d_0}{\sqrt{\frac{S_1^2}{n_1} + \frac{S_2^2}{n_2}}}$$

近似服从 $t(\nu)$，自由度由 **Welch-Satterthwaite 公式**给出：

$$\nu = \frac{\left(\frac{S_1^2}{n_1} + \frac{S_2^2}{n_2}\right)^2}{\frac{(S_1^2/n_1)^2}{n_1-1} + \frac{(S_2^2/n_2)^2}{n_2-1}}$$

（通常不是整数，取整即可。）$\nu$ 介于 $\min(n_1, n_2) - 1$ 与 $n_1 + n_2 - 2$ 之间。

### 2.3 等方差 t 检验的完整例题

**例题**：比较两种肥料对作物产量的影响。肥料A施于 7 块地，平均产量 $\bar{x} = 48.6$，$s_1 = 4.2$；肥料B施于 6 块地，平均产量 $\bar{y} = 44.2$，$s_2 = 3.8$。假设产量服从正态分布且方差相等，在 $\alpha = 0.05$ 下检验两种肥料效果是否有显著差异。

**解**：

$$H_0: \mu_1 = \mu_2, \quad H_1: \mu_1 \neq \mu_2$$

联合方差：

$$S_w^2 = \frac{6 \times 4.2^2 + 5 \times 3.8^2}{7 + 6 - 2} = \frac{6 \times 17.64 + 5 \times 14.44}{11} = \frac{105.84 + 72.20}{11} = 16.185$$

检验统计量：

$$T = \frac{48.6 - 44.2}{\sqrt{16.185 \times \left(\frac{1}{7} + \frac{1}{6}\right)}} = \frac{4.4}{\sqrt{16.185 \times 0.3095}} = \frac{4.4}{\sqrt{5.010}} = \frac{4.4}{2.238} = 1.966$$

双侧拒绝域 $|T| > t_{0.025}(11) = 2.201$。$|T| = 1.966 < 2.201$，**不拒绝 $H_0$**——没有足够证据表明两种肥料效果有显著差异。

## 3. 配对 t 检验

### 3.1 适用条件

当两个样本**不独立**而是"配对"时（同一组对象在两种条件下的测量，如同一患者用药前后、同一产品两种方法测量），不能用独立的双总体 $t$ 检验，要用**配对 $t$ 检验**。

配对设计的妙处：把"个体差异"这个混杂因素通过**做差**消掉，只检验"处理效应"。

### 3.2 方法

设 $d_i = X_i - Y_i$（$i = 1, 2, \cdots, n$）为成对差值，检验 $H_0: \mu_d = 0$：

$$T = \frac{\bar{d}}{S_d/\sqrt{n}} \sim t(n-1)$$

其中 $\bar{d} = \dfrac{1}{n}\sum d_i$，$S_d^2 = \dfrac{1}{n-1}\sum (d_i - \bar{d})^2$。

本质上，配对 $t$ 检验就是"对差值 $d_i$ 做单总体 $t$ 检验"——把配对数据转化为 $n$ 个差值，然后检验差值均值是否为 0。

### 3.3 配对 vs 非配对

| 设计 | 适用场景 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 配对设计 | 同一对象两次测量 | 消除个体差异，检验更灵敏 | 需先做差，丢失"水平"信息 |
| 非配对设计 | 两组独立对象 | 适用范围广 | 个体差异混入误差，功效较低 |

### 3.4 配对 t 检验的完整例题

**例题**：为比较两种测量方法的差异，对 8 个样品分别用两种方法测量，差值（方法A - 方法B）为：0.3, -0.2, 0.5, 0.1, -0.1, 0.4, 0.2, -0.3。在 $\alpha = 0.05$ 下检验两种方法是否有系统差异。

**解**：

$$H_0: \mu_d = 0, \quad H_1: \mu_d \neq 0$$

$$\bar{d} = \frac{0.3 - 0.2 + 0.5 + 0.1 - 0.1 + 0.4 + 0.2 - 0.3}{8} = \frac{0.9}{8} = 0.1125$$

$$\sum d_i^2 = 0.09 + 0.04 + 0.25 + 0.01 + 0.01 + 0.16 + 0.04 + 0.09 = 0.69$$

$$S_d^2 = \frac{1}{7}(0.69 - 8 \times 0.1125^2) = \frac{1}{7}(0.69 - 0.10125) = \frac{0.58875}{7} = 0.08411, \quad S_d \approx 0.290$$

$$T = \frac{0.1125}{0.290/\sqrt{8}} = \frac{0.1125}{0.1025} = 1.098$$

双侧拒绝域 $|T| > t_{0.025}(7) = 2.365$。$|T| = 1.098 < 2.365$，**不拒绝 $H_0$**——没有显著证据表明两种测量方法存在系统差异。

## 4. t 检验家族速查

| 检验类型 | 条件 | 检验统计量 | 自由度 |
| --- | --- | --- | --- |
| 单总体 | $\sigma$ 未知 | $\dfrac{\bar{X}-\mu_0}{S/\sqrt{n}}$ | $n-1$ |
| 双总体（等方差） | $\sigma_1^2 = \sigma_2^2$ | $\dfrac{\bar{X}-\bar{Y}}{S_w\sqrt{1/n_1+1/n_2}}$ | $n_1+n_2-2$ |
| 双总体（不等方差） | $\sigma_1^2 \neq \sigma_2^2$ | $\dfrac{\bar{X}-\bar{Y}}{\sqrt{S_1^2/n_1+S_2^2/n_2}}$ | Welch 公式 |
| 配对 | 配对设计 | $\dfrac{\bar{d}}{S_d/\sqrt{n}}$ | $n-1$ |

**选择流程**：先问"独立还是配对"（配对 → 配对 $t$）；再问"方差是否相等"（相等 → 合并方差 $t$；不等 → Welch $t$）。

## 5. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 条件误用 | $\sigma$ 已知还用 $t$ | 没区分 $Z$/$t$ 条件 | $\sigma$ 已知用 $Z$（或大样本近似）；$\sigma$ 未知用 $t$ |
| 配对数据当独立 | 同一批对象的两次测量用双总体 $t$ | 忽略数据相关性 | 先判断是否配对；配对必须做差后单样本 $t$ 检验 |
| 自由度算错 | 双总体用 $n_1 + n_2$ 或 $\min(n_1,n_2)$ | 不知联合方差消耗自由度 | 等方差：$n_1+n_2-2$；不等方差：Welch 公式 |
| 等方差假设不验证 | 方差悬殊还硬套合并方差 $t$ | 忘了前提 | 先用 $F$ 检验（方差齐性检验）判断，不等则用 Welch |
| 符号搞反 | 差值的正负方向搞混 | 未约定 $d_i$ 定义 | 统一约定 $d_i = X_i - Y_i$ 并保持一致；结论方向随约定改变 |
| 检验前不查正态性 | 严重偏态的小样本硬用 $t$ | $t$ 检验依赖正态假设 | 小样本先做正态性检验；严重偏离可转非参数检验（如 Wilcoxon） |

## 6. 实战练习

**练习 1（单总体）**：某品牌方便面标称每包净重 100g，抽取 9 包测得：99.3, 98.7, 100.5, 101.2, 98.3, 99.7, 99.5, 100.1, 100.7。在 $\alpha = 0.05$ 下检验净重是否符合标称。

**提示**：单总体双侧 $t$ 检验，$t_{0.025}(8) = 2.306$。

**参考答案要点**：$\bar{x} = 99.78$，$s \approx 0.914$，$T = \dfrac{99.78 - 100}{0.914/3} = -0.72$；$|T| < 2.306$，不拒绝 $H_0$，净重符合标称。

**练习 2（配对）**：10 名患者服用两种安眠药，延长睡眠时间差值（A - B）为：1.2, 2.4, 1.3, 1.3, 0, 1.0, 1.8, 0.8, 4.6, 1.4。在 $\alpha = 0.05$ 下检验两种药效果是否有差异。

**提示**：$\bar{d} = 1.58$，$s_d \approx 1.229$，$t_{0.025}(9) = 2.262$。

**参考答案要点**：$T = \dfrac{1.58}{1.229/\sqrt{10}} = 4.06 > 2.262$，拒绝 $H_0$，两种药效果有显著差异。

**练习 3（双总体等方差）**：甲乙两种工艺产品长度：甲 $n_1 = 8$，$\bar{x} = 10.5$，$s_1 = 0.4$；乙 $n_2 = 6$，$\bar{y} = 10.1$，$s_2 = 0.3$。假设方差相等，$\alpha = 0.05$ 检验长度是否有差异。

**提示**：$S_w^2 = \dfrac{7 \times 0.16 + 5 \times 0.09}{12} = 0.131$，$t_{0.025}(12) = 2.179$。

**参考答案要点**：$T = \dfrac{0.4}{\sqrt{0.131 \times (1/8 + 1/6)}} = 2.04 < 2.179$，不拒绝 $H_0$，无显著差异。

**练习 4（Welch）**：两总体方差不等，$n_1 = 10$，$\bar{x} = 5$，$s_1^2 = 2$；$n_2 = 8$，$\bar{y} = 4$，$s_2^2 = 0.5$。求 Welch 检验的自由度 $\nu$。

**提示**：套 Welch-Satterthwaite 公式。

**参考答案要点**：$\nu = \dfrac{(2/10 + 0.5/8)^2}{(2/10)^2/9 + (0.5/8)^2/7} = \dfrac{(0.2625)^2}{0.004444/9 + 0.003906/7} = \dfrac{0.0689}{0.001052} \approx 65.5$，取 $\nu = 65$（或 66）。

**练习 5（综合判断）**：给出一组场景，判断该用哪种检验：（a）同一批电池测两次寿命；（b）两组不同学生用两种教材后的成绩（方差未知且不等）；（c）已知历史波动 $\sigma = 3$ 的机器均值检验。

**提示**：按"配对/独立、方差已知/未知、方差相等/不等"分类。

**参考答案要点**：（a）配对 $t$ 检验；（b）Welch $t$ 检验（不等方差）；（c）$Z$ 检验（$\sigma$ 已知）。

## 7. 一句话记忆

**t 检验是"未知尺子"检验：$\sigma$ 未知时用 $S$ 代替，统计量 $T = \dfrac{\bar{X}-\mu_0}{S/\sqrt{n}} \sim t(n-1)$；配对数据先做差、方差相等用合并方差、方差不等用 Welch 自由度公式。**
