## 0. 从体检报告单说起：为什么要"压缩"数据

想象你刚做完年度体检，抽血化验拿到了几十项指标。医生不会让你盯着几百个原始化验数字发呆，而是会给你一张**体检报告单**：上面写着"血红蛋白 135g/L""总胆固醇 4.2mmol/L""收缩压 118mmHg"等几个关键数字，再和参考范围一比，就能判断你的身体状况。

这张报告单的本质是什么？它把**海量的原始测量数据**压缩成了**少数几个有意义的指标**。体检报告单上的每个指标，都是对原始数据做了一次"加工"——求平均、找极值、看波动。

统计量（Statistic）在数理统计中的角色，与体检报告单完全一致：**用几个精心设计的函数，把杂乱无章的样本数据浓缩成有用的信息，供医生（统计学家）做诊断（推断）**。

从本文开始，我们进入数理统计的核心篇章。上一篇文章《随机样本》告诉我们如何从总体中抽取样本；本文则回答：拿到样本之后，**第一步该算什么**。

## 1. 统计量的定义

### 1.1 从概念到定义

体检报告单上的"血红蛋白 135g/L"其实是一个"函数"：输入是几十项血液化验的原始数据，输出是一个数字。统计量的定义正是把这个思想数学化。

**定义**：设 $X_1, X_2, \cdots, X_n$ 为来自总体 $X$ 的样本，$g(X_1, X_2, \cdots, X_n)$ 是一个 $n$ 元函数。若 $g$ 中**不包含任何未知参数**，则称 $g(X_1, X_2, \cdots, X_n)$ 为一个**统计量**。

把样本观测值 $x_1, x_2, \cdots, x_n$ 代入统计量得到的数值 $g(x_1, x_2, \cdots, x_n)$，称为该统计量的**观测值**。

### 1.2 判断统计量的两个硬性标准

做题时判断一个式子是不是统计量，只需要检查两条：

1. **只能由样本 $X_1, X_2, \cdots, X_n$ 构成**（可以含有已知常数）；
2. **绝对不能含有未知参数**（如未知的 $\mu$、$\sigma^2$、$\lambda$ 等）。

举几个正反例子（设总体 $X \sim N(\mu, \sigma^2)$，$\mu$、$\sigma^2$ 均未知）：

| 表达式 | 是否统计量 | 原因 |
| --- | --- | --- |
| $\bar{X} = \dfrac{1}{n}\sum X_i$ | 是 | 只含样本 |
| $\max(X_1, X_2, \cdots, X_n)$ | 是 | 只含样本 |
| $X_1 + 2\mu$ | 是（若 $\mu$ 为已知常数） | 已知常数不算未知参数 |
| $\dfrac{X_1 - \mu}{\sigma}$ | 否 | 含未知参数 $\mu, \sigma$ |
| $\dfrac{1}{n}\sum (X_i - \mu)^2$（$\mu$ 未知） | 否 | 含未知参数 $\mu$ |

> 一个容易忽略的细节：**统计量本身不依赖于未知参数，但它的分布却依赖于未知参数**。比如 $\bar{X}$ 不依赖 $\mu$，可 $E(\bar{X}) = \mu$ 却含 $\mu$。这正说明了为什么统计量能用来推断参数——它的"统计行为"携带着参数的信息。

### 1.3 为什么要求统计量不含未知参数

逻辑很简单：统计量的用途是**从样本数据算出数值**，进而推断未知参数。如果统计量本身含未知参数，那么面对一组具体数据时你根本无法算出它的值——"用一个算不出来的东西去估计另一个不知道的东西"显然行不通。

## 2. 样本均值：数据的"重心"

### 2.1 定义

$$\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$$

$\bar{X}$ 称为**样本均值**。它是对总体均值 $\mu$ 最自然的估计：既然总体平均就是 $\mu$，样本平均自然最有资格当"候选人"。

### 2.2 样本均值的性质（概念驱动：为什么它可靠）

设 $E(X) = \mu$，$D(X) = \sigma^2$，则：

1. **$E(\bar{X}) = \mu$（无偏性）**：平均而言，样本均值恰好等于总体均值，没有系统性偏差。

2. **$D(\bar{X}) = \dfrac{\sigma^2}{n}$**：样本量越大，样本均值越"聚拢"在 $\mu$ 周围。

3. **大样本正态近似**：由中心极限定理，当 $n$ 较大时，$\bar{X}$ 近似服从 $N\left(\mu, \dfrac{\sigma^2}{n}\right)$。这是"无论总体什么分布，样本均值都趋向正态"的伟大结论。

4. **正态总体的精确分布**：若总体 $X \sim N(\mu, \sigma^2)$，则 $\bar{X} \sim N\left(\mu, \dfrac{\sigma^2}{n}\right)$（精确成立，无需 $n$ 很大）。

### 2.3 样本均值的计算

**未分组数据**：

$$\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i$$

**分组数据**（已整理成频数表时）：

$$\bar{x} = \frac{\sum_{j=1}^k f_j x_j}{\sum_{j=1}^k f_j}$$

其中 $f_j$ 为第 $j$ 组的频数，$x_j$ 为第 $j$ 组的组中值（组中点）。分组计算是加权平均的思想：每个组中值"代表"该组所有数据。

## 3. 样本方差：数据的"离散程度"

### 3.1 定义

光有"重心"还不够。两组数据可以有相同的平均数，但一组挤在一起，另一组天南地北。刻画离散程度需要**样本方差**：

$$S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2$$

$S$ 称为**样本标准差**：

$$S = \sqrt{S^2}$$

### 3.2 为什么除以 $n-1$ 而不是 $n$（核心概念）

这是初学者最常问的问题。直觉上，算"平均离差平方"似乎该除以 $n$，为什么教材里用 $n-1$？

答案在于**无偏性**。可以证明：

$$E(S^2) = E\left[\frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \sigma^2$$

即除以 $n-1$ 后，$S^2$ 的期望恰好等于总体方差 $\sigma^2$，称 $S^2$ 为 $\sigma^2$ 的**无偏估计**。

若误除以 $n$，则有：

$$E\left[\frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2\right] = \frac{n-1}{n}\sigma^2 < \sigma^2$$

也就是说，除以 $n$ 会**系统性低估**总体方差。原因也不难理解：样本均值 $\bar{X}$ 是从这批数据本身算出来的，数据围绕 $\bar{X}$ 的波动天然小于围绕真值 $\mu$ 的波动，这一"损失的自由度"（一个）需要用 $n-1$ 来补偿。$n-1$ 被称为**自由度**。

### 3.3 样本方差的简化计算公式

手算时，直接套定义要算 $n$ 次平方差，容易出错。用下面两个等价公式更方便：

$$S^2 = \frac{1}{n-1}\left(\sum_{i=1}^n X_i^2 - n\bar{X}^2\right) = \frac{n\sum X_i^2 - (\sum X_i)^2}{n(n-1)}$$

推导思路（这就是"偏差平方和的展开式"）：

$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - 2\bar{X}\sum_{i=1}^n X_i + n\bar{X}^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2$$

### 3.4 样本方差的性质

1. **$E(S^2) = \sigma^2$（无偏性）**——见上文。

2. **正态总体下的分布**：当总体 $X \sim N(\mu, \sigma^2)$ 时，

$$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

这个结论是"三大分布"与后续区间估计、假设检验的基石，下一篇文章会详细展开。

3. **$\bar{X}$ 与 $S^2$ 独立**（正态总体时）：这是正态总体特有的性质，非正态总体一般不成立。它的直观解释是：样本均值反映"位置"，样本方差反映"分散程度"，二者携带的信息正交。

## 4. 样本矩：把"平均"推广到任意次幂

### 4.1 样本 k 阶原点矩

$$A_k = \frac{1}{n}\sum_{i=1}^n X_i^k, \quad k = 1, 2, \cdots$$

特别地，$A_1 = \bar{X}$——一阶原点矩就是样本均值。

### 4.2 样本 k 阶中心矩

$$B_k = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^k, \quad k = 2, 3, \cdots$$

注意：$B_2 = \dfrac{n-1}{n}S^2$，即二阶中心矩**不是**样本方差，而是"除以 $n$ 的版本"，它是有偏的（略小于 $\sigma^2$）。

### 4.3 样本矩与总体矩的关系（矩估计的伏笔）

由大数定律，当 $n \to \infty$ 时：

$$A_k \xrightarrow{P} E(X^k) = \mu_k$$

$$B_k \xrightarrow{P} E[X - E(X)]^k = \nu_k$$

"样本矩依概率收敛于总体矩"是后面**矩估计法**的理论依据：既然样本矩能逼近总体矩，那就可以用样本矩反解未知参数。这个概念请务必记住，下一章《点估计》会用到。

## 5. 其他常用统计量

### 5.1 样本极差

$$R = X_{(n)} - X_{(1)} = \max(X_i) - \min(X_i)$$

极差只用了两个极端值，简单粗暴地刻画波动范围，但受异常值影响很大，稳健性差。

### 5.2 样本中位数

$$M_e = \begin{cases} X_{\left(\frac{n+1}{2}\right)}, & n \text{ 为奇数} \\ \dfrac{1}{2}\left[X_{\left(\frac{n}{2}\right)} + X_{\left(\frac{n}{2}+1\right)}\right], & n \text{ 为偶数} \end{cases}$$

中位数对异常值不敏感，是均值在"数据含离群点"时的稳健替代品。比如统计居民收入时，少数富豪会把均值拉得很高，而中位数更能代表"普通人的水平"。

### 5.3 样本 p 分位数

$$m_p = \begin{cases} X_{([np]+1)}, & np \text{ 不是整数} \\ \dfrac{1}{2}(X_{(np)} + X_{(np+1)}), & np \text{ 是整数} \end{cases}$$

$p$ 分位数表示"约 $100p\%$ 的数据不超过它"。$m_{0.5}$ 就是中位数，$m_{0.25}$、$m_{0.75}$ 是下、上四分位数。

### 5.4 变异系数

$$CV = \frac{S}{\bar{X}}$$

当两组数据的量纲或均值差异很大时（比如比较"成年大象的体重波动"和"蚂蚁的体重波动"），直接用标准差比较不公平。变异系数把标准差按均值"归一化"，衡量相对离散程度。

### 5.5 样本偏度与峰度

**样本偏度**（衡量分布左右是否对称，对称时为 0）：

$$g_1 = \frac{B_3}{B_2^{3/2}}$$

**样本峰度**（衡量分布是否"尖峰"或"扁平"，标准正态为 0）：

$$g_2 = \frac{B_4}{B_2^2} - 3$$

$g_1 > 0$ 称右偏（长尾在右），$g_2 > 0$ 称尖峰。偏度与峰度在金融数据分析中用于检查收益率的分布形态。

## 6. 次序统计量

### 6.1 定义

把样本按从小到大排成一列：

$$X_{(1)} \leq X_{(2)} \leq \cdots \leq X_{(n)}$$

则 $X_{(k)}$ 称为第 $k$ 个**次序统计量**。$X_{(1)}$ 是最小值，$X_{(n)}$ 是最大值。前面说的极差、中位数、分位数，其实都是次序统计量的函数。

### 6.2 次序统计量的分布

设总体 $X$ 的分布函数为 $F(x)$，密度函数为 $f(x)$，则第 $k$ 个次序统计量的密度函数为：

$$f_{X_{(k)}}(x) = \frac{n!}{(k-1)!(n-k)!}[F(x)]^{k-1}[1-F(x)]^{n-k}f(x)$$

直观理解：要让 $X_{(k)}$ 落在 $x$ 附近，需要恰好 $k-1$ 个观测在 $x$ 左边、$n-k$ 个在 $x$ 右边，剩下的一个落在 $x$ 处。这是典型的"多项式选择"计数。

特别地，最小值和最大值：

$$f_{X_{(1)}}(x) = n[1-F(x)]^{n-1}f(x)$$

$$f_{X_{(n)}}(x) = n[F(x)]^{n-1}f(x)$$

## 8. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 判定失误 | 把含 $\mu$（未知）的表达式误认为统计量 | 混淆"已知常数"与"未知参数" | 牢牢记住判定两标准：只含样本、不含未知参数；已知常数（如 $\mu_0 = 5$）不算未知 |
| 分母错误 | 用 $\dfrac{1}{n}\sum (X_i - \bar{X})^2$ 当样本方差 | 不清楚 $n-1$ 的来由 | 记住 $E[\frac{1}{n}\sum (X_i - \bar{X})^2] = \frac{n-1}{n}\sigma^2$，为无偏必须除以 $n-1$ |
| 混用矩 | 把 $B_2$ 当成 $S^2$ | 二阶中心矩与样本方差差一个因子 $\frac{n-1}{n}$ | 记牢 $B_2 = \dfrac{n-1}{n}S^2$，两者只在 $n \to \infty$ 时趋于一致 |
| 计算粗心 | 用 $(\sum x_i)^2$ 代替 $\sum x_i^2$ | 平方和与和的平方混淆 | 简化公式中两项含义不同：$\sum x_i^2$ 先平方后求和，$(\sum x_i)^2$ 先求和后平方 |
| 期望误用 | 认为 $E(S^2)$ 需要知道分布 | 不知无偏性对任意总体成立 | $E(S^2) = \sigma^2$ 只要总体方差存在就成立，不需要正态假设 |
| 稳健性错觉 | 用均值估计含异常值数据 | 均值对极端值敏感 | 数据含离群点时改用中位数，或先做异常值处理 |

## 10. 一句话记忆

**统计量就是"体检报告单"——把一大把样本数字浓缩成不含未知参数的几个指标（均值、方差、矩、次序量），而指标背后能否代表总体，要看无偏性等"体检标准的可信度"。**
