## 0. 从一个生活场景说起：地图上的"筛选"

用手机地图找餐馆时，你面对的是"全市所有餐馆"这张完整地图。但如果你打开筛选器，只看"评分 4.5 分以上"的餐馆，你看到的就不是全市的餐馆分布，而是**在"评分高"这个条件下**的餐馆分布。

条件分布干的就是同一件事：手里有一张"联合分布"表格，**固定其中一个变量的取值**（打开筛选器），再看另一个变量在此条件下如何分布。筛选条件一变，"地图"就变，这正是条件分布与边缘分布的本质区别：

- **边缘分布**：把 $Y$ 彻底"忘掉"，只看 $X$ 独自的分布（不看筛选器，只看全部）；
- **条件分布**：先锁定 $Y = y$（打开筛选器），再看此时 $X$ 的分布。

本文沿着"**条件驱动**"的思路展开：先直观理解"条件"如何改变分布，再给出离散型与连续型的严格定义与公式，最后用例题、易错点与练习把它彻底吃透。

## 1. 直观理解：条件是如何"改写"概率的

回忆条件概率的基本公式：在事件 $B$ 已经发生的条件下，事件 $A$ 发生的概率为

$$P(A \mid B) = \frac{P(AB)}{P(B)} \quad (P(B) > 0)$$

"分母收缩、分子保留"是条件概率的运算核心：分子是 $A$ 与 $B$ 同时发生，分母是 $B$ 发生的总概率。条件分布只是把这条规则从"事件"升级到"随机变量的取值"。

假设 $(X, Y)$ 的联合分布律如下表（每一格是 $P(X = x_i, Y = y_j)$）：

| $X \backslash Y$ | $y_1$ | $y_2$ | 行和 $P(X = x_i)$ |
| :--------------: | :---: | :---: | :----------------: |
| $x_1$            | 0.1   | 0.3   | 0.4                |
| $x_2$            | 0.3   | 0.3   | 0.6                |
| 列和 $P(Y = y_j)$ | 0.4   | 0.6   | 1                  |

现在"筛选" $Y = y_2$：在这一列中，概率总和是 $0.6$。把这一列重新"归一化"（每个数除以 $0.6$），就得到在 $Y = y_2$ 条件下 $X$ 的分布：

$$P(X = x_1 \mid Y = y_2) = \frac{0.3}{0.6} = \frac{1}{2}, \qquad P(X = x_2 \mid Y = y_2) = \frac{0.3}{0.6} = \frac{1}{2}$$

对比不看条件时 $P(X = x_1) = 0.4$、$P(X = x_2) = 0.6$——**条件改变之后，$X$ 的分布变了**。这正是"条件"一词的含义：信息（$Y = y_2$）进入了我们的视野，概率就被重新分配。

## 2. 离散型随机变量的条件分布律

### 2.1 定义

设 $(X, Y)$ 是二维离散型随机变量，联合分布律为 $P(X = x_i, Y = y_j) = p_{ij}$，边缘分布律为

$$p_{i\cdot} = \sum_{j} p_{ij} = P(X = x_i), \qquad p_{\cdot j} = \sum_{i} p_{ij} = P(Y = y_j)$$

若 $P(Y = y_j) > 0$，则在 $Y = y_j$ 条件下 $X$ 的**条件分布律**为

$$P(X = x_i \mid Y = y_j) = \frac{P(X = x_i, Y = y_j)}{P(Y = y_j)} = \frac{p_{ij}}{p_{\cdot j}}, \qquad i = 1, 2, \cdots$$

对称地，若 $P(X = x_i) > 0$，则在 $X = x_i$ 条件下 $Y$ 的**条件分布律**为

$$P(Y = y_j \mid X = x_i) = \frac{p_{ij}}{p_{i\cdot}}, \qquad j = 1, 2, \cdots$$

### 2.2 条件分布律的两条基本性质

1. **非负性**：$P(X = x_i \mid Y = y_j) \geq 0$，对一切 $i$ 成立；
2. **规范性**：$\displaystyle\sum_{i=1}^{\infty} P(X = x_i \mid Y = y_j) = \frac{1}{p_{\cdot j}} \sum_i p_{ij} = 1$。

规范性说明：固定 $Y = y_j$ 后，$X$ 各取值概率之和仍为 1，构成合法分布。

## 3. 连续型随机变量的条件概率密度

### 3.1 定义

对于连续型随机变量，单点概率 $P(Y = y) = 0$，无法直接套用条件概率公式。处理办法是"用密度之比代替概率之比"。

设 $(X, Y)$ 的联合密度为 $f(x, y)$，边缘密度为 $f_X(x)$、$f_Y(y)$。若 $f_Y(y) > 0$，则在 $Y = y$ 条件下 $X$ 的**条件概率密度**为

$$f_{X \mid Y}(x \mid y) = \frac{f(x, y)}{f_Y(y)}$$

对称地，若 $f_X(x) > 0$，则在 $X = x$ 条件下 $Y$ 的**条件概率密度**为

$$f_{Y \mid X}(y \mid x) = \frac{f(x, y)}{f_X(x)}$$

### 3.2 条件分布函数

在 $Y = y$ 条件下 $X$ 的**条件分布函数**为

$$F_{X \mid Y}(x \mid y) = \int_{-\infty}^{x} f_{X \mid Y}(u \mid y) \, du = \frac{\int_{-\infty}^{x} f(u, y) \, du}{f_Y(y)}$$

### 3.3 条件概率密度的性质

1. **非负性**：$f_{X \mid Y}(x \mid y) \geq 0$；
2. **规范性**：$\displaystyle\int_{-\infty}^{+\infty} f_{X \mid Y}(x \mid y) \, dx = \frac{1}{f_Y(y)} \int_{-\infty}^{+\infty} f(x, y) \, dx = \frac{f_Y(y)}{f_Y(y)} = 1$；
3. **乘法公式**：$f(x, y) = f_X(x) \cdot f_{Y \mid X}(y \mid x) = f_Y(y) \cdot f_{X \mid Y}(x \mid y)$。

乘法公式是把联合密度"拆"成边缘密度与条件密度之积，是贝叶斯推断与条件期望推导的基础。

## 4. 条件分布与边缘分布：全概率公式的"密度版"

边缘分布可以从条件分布"加权平均"回来。对离散型：

$$P(X = x_i) = \sum_j P(X = x_i \mid Y = y_j) \, P(Y = y_j)$$

对连续型：

$$f_X(x) = \int_{-\infty}^{+\infty} f_{X \mid Y}(x \mid y) \, f_Y(y) \, dy$$

这是全概率公式在连续型情形的推广：把"$Y$ 取每个可能值时的条件分布"按 $Y$ 的权重叠加，就还原出 $X$ 的无条件分布，常用于"先按条件建模、再对条件取平均"的场景。

## 5. 条件分布与独立性

条件分布是检验独立性的"天然工具"：

- 离散型：$X$ 与 $Y$ 独立 $\iff$ 对所有 $i, j$，$P(X = x_i \mid Y = y_j) = P(X = x_i)$；
- 连续型：$X$ 与 $Y$ 独立 $\iff$ 对（几乎）所有 $x, y$，$f_{X \mid Y}(x \mid y) = f_X(x)$。

直观解释：独立性意味着"知道 $Y$ 不改变对 $X$ 的判断"——条件分布等于无条件分布；两者不同，则 $Y$ 携带了 $X$ 的信息。

条件分布与边缘分布差异越大，说明变量间关联越强；两者完全相同，则两变量独立（详见下一篇《随机变量的独立性》）。

## 6. 条件分布的应用

### 6.1 条件期望与回归分析

有了条件分布，就能定义条件期望：

$$E(X \mid Y = y) = \int_{-\infty}^{+\infty} x \, f_{X \mid Y}(x \mid y) \, dx$$

把 $E(X \mid Y = y)$ 看作 $y$ 的函数，就是**回归函数**，它是用 $Y$ 预测 $X$ 的理论最优模型（详见《数学期望》中的条件期望部分）。

### 6.2 贝叶斯推断

贝叶斯公式的密度形式：

$$f_{X \mid Y}(x \mid y) = \frac{f_{Y \mid X}(y \mid x) \, f_X(x)}{f_Y(y)} \propto f_{Y \mid X}(y \mid x) \, f_X(x)$$

即"后验 $\propto$ 似然 $\times$ 先验"。条件分布正是贝叶斯推断（贝叶斯分类、垃圾邮件过滤）的数学核心。

## 8. 常见错误与对策

| 错误示例 | 错误类型 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 计算条件密度时忘记写取值范围 | 支撑集遗漏 | 只写了公式 $f(x,y)/f_Y(y)$，没有交代 $x$（或 $y$）的可行区间 | 每写出一个条件密度，紧跟其后写明支撑集；用"$0 < y < x$"这类不等式描述 |
| 把 $f_{X \mid Y}(x \mid y)$ 与 $f_X(x)$ 混为一谈 | 概念混淆 | 没有区分"加了条件的分布"与"无条件分布" | 记住：条件分布由"固定 $Y = y$ 后的那一列/那一条线"归一化得到 |
| 连续型直接写 $P(Y = y)$ | 概念错误 | 连续型单点概率恒为 0，不能作为分母 | 连续型一律用密度之比 $f(x,y)/f_Y(y)$，不要写 $P(Y=y)$ |
| 求边缘密度时代入条件密度 | 方向颠倒 | 混淆"由联合求边缘"与"由条件求联合" | 边缘密度 = 对联合密度积分掉另一个变量；条件密度 = 联合密度除以边缘密度 |
| 积分上下限定错 | 计算错误 | 对非矩形区域积分时凭感觉定限 | 先画出非零区域的图形，再按"先积哪个变量"确定上下限，最后用规范性 $\int f_{X\mid Y} = 1$ 自检 |
| 认为条件分布必不等于边缘分布 | 以偏概全 | 忽略了独立情形 | 若 $X$ 与 $Y$ 独立，条件分布恰等于边缘分布，这是判断独立性的等价条件之一 |

## 10. 一句话记忆

条件分布就是"打开筛选器后的分布"：固定 $Y = y$，把联合概率（密度）按 $Y = y$ 这一列（这一条线）重新归一化，即 $f_{X\mid Y}(x \mid y) = \dfrac{f(x, y)}{f_Y(y)}$；若条件分布等于边缘分布，则两变量独立。
