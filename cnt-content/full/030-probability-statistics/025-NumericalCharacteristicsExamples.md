## 0. 从一个生活场景说起：一份"股票收益分析报告"

假设你是量化研究员，手里有两份资产：股票 A 和股票 B。你要回答一连串问题：

- 平均收益率谁高？（求**期望**）
- 谁的收益更不稳定？（求**方差/标准差**）
- 两者是否同涨同跌？（求**协方差/相关系数**）
- 各投一半，组合风险多大？（**方差线性组合**）

这一串问题，正好把"数字特征"四大件——期望、方差、协方差、相关系数——全部串起来。这也是本文的定位：**案例驱动**的综合例题篇。

本文不再重复概念，而是用 5 个由浅入深的实际案例，把数字特征的"计算全流程"演示一遍。每个案例都给出完整的解题步骤与"步骤讲解"，帮你在实战中形成肌肉记忆。

## 1. 案例一：彩票的期望收益（期望的直觉）

### 例题 1（离散型期望）

某彩票每张 2 元，中奖规则：一等奖概率 $10^{-6}$，奖金 500000 元；二等奖概率 $10^{-4}$，奖金 5000 元；三等奖概率 $10^{-3}$，奖金 100 元。购买一张彩票的期望收益是多少？这个游戏公平吗？

**解**：设随机变量 $X$ 为"中奖金额"。$X$ 的分布律：

$$P(X = 500000) = 10^{-6}, \quad P(X = 5000) = 10^{-4}, \quad P(X = 100) = 10^{-3}, \quad P(X = 0) = 1 - 10^{-6} - 10^{-4} - 10^{-3}$$

$$E(X) = 500000 \times 10^{-6} + 5000 \times 10^{-4} + 100 \times 10^{-3} = 0.5 + 0.5 + 0.1 = 1.1 \text{（元）}$$

买一张花 2 元，期望回收 1.1 元，期望净收益 = $1.1 - 2 = -0.9$ 元——**每买一张平均亏 0.9 元**，游戏对玩家不公平（这正是彩票的盈利模式）。

**步骤讲解**：① 列出分布律（含 $X=0$ 的概率）；② 按定义 $E(X) = \sum x_k p_k$ 加权；③ 与成本比较判断公平性。

## 2. 案例二：两个方案，谁更优？（期望 + 方差双指标）

### 例题 2（投资方案选择）

两个投资方案的收益（万元）分布如下。应选哪个方案？

- 方案 A：$P(X = 4) = 0.2$，$P(X = 5) = 0.6$，$P(X = 6) = 0.2$；
- 方案 B：$P(Y = 0) = 0.3$，$P(Y = 5) = 0.4$，$P(Y = 10) = 0.3$。

**解**：

方案 A 的期望与方差：

$$E(X) = 4 \times 0.2 + 5 \times 0.6 + 6 \times 0.2 = 5$$

$$E(X^2) = 16 \times 0.2 + 25 \times 0.6 + 36 \times 0.2 = 25.4, \qquad D(X) = 25.4 - 25 = 0.4$$

方案 B 的期望与方差：

$$E(Y) = 0 \times 0.3 + 5 \times 0.4 + 10 \times 0.3 = 5$$

$$E(Y^2) = 0 \times 0.3 + 25 \times 0.4 + 100 \times 0.3 = 40, \qquad D(Y) = 40 - 25 = 15$$

**结论**：两方案期望相同（都是 5 万元），但方案 A 方差 0.4 远小于方案 B 的 15——**期望相同看方差，方差小者更优**（稳健投资者选 A；激进投资者若追求"10 万大奖"也可能选 B，但理性选择是 A）。

**步骤讲解**：① 期望相等时比较方差；② 方差用 $E(X^2) - [E(X)]^2$ 快速计算；③ 结合风险偏好下结论。

### 例题 3（线性变换的数字特征）

设 $X \sim B(10, 0.4)$，求 $E(3X + 2)$ 与 $D(3X + 2)$。

**解**：$E(X) = 10 \times 0.4 = 4$，$D(X) = 10 \times 0.4 \times 0.6 = 2.4$。

$$E(3X + 2) = 3E(X) + 2 = 14$$

$$D(3X + 2) = 3^2 D(X) = 9 \times 2.4 = 21.6$$

**步骤讲解**：记住两条"变换规则"：$E(aX+b) = aE(X) + b$（线性），$D(aX+b) = a^2 D(X)$（系数平方）。

### 例题 4（由期望方差反推二阶矩）

设 $E(X) = 10$，$D(X) = 4$，求 $E[(X+1)^2]$。

**解**：

$$E[(X+1)^2] = E(X^2 + 2X + 1) = E(X^2) + 2E(X) + 1$$

由 $E(X^2) = D(X) + [E(X)]^2 = 4 + 100 = 104$：

$$E[(X+1)^2] = 104 + 20 + 1 = 125$$

**步骤讲解**：见到"平方的期望"，先展开成 $E(X^2)$ 再代入 $E(X^2) = D(X) + [E(X)]^2$，这是最高频的套路。

## 3. 案例三：双变量联动分析（协方差 + 相关系数）

### 例题 5（离散型：完整表格）

设 $(X, Y)$ 的联合分布律为：

| $X \backslash Y$ | -1     | 1      |
| :--------------: | :----: | :----: |
| -1               | 1/8    | 3/8    |
| 1                | 3/8    | 1/8    |

求 $E(X)$、$E(Y)$、$\text{Cov}(X, Y)$、$\rho_{XY}$。

**解**：先算边缘分布：$P(X = -1) = \dfrac{1}{2}$，$P(X = 1) = \dfrac{1}{2}$；$P(Y = -1) = \dfrac{1}{2}$，$P(Y = 1) = \dfrac{1}{2}$。

$$E(X) = 0, \qquad E(Y) = 0$$

$$E(XY) = (-1)(-1)\frac{1}{8} + (-1)(1)\frac{3}{8} + (1)(-1)\frac{3}{8} + (1)(1)\frac{1}{8} = \frac{1}{8} - \frac{3}{8} - \frac{3}{8} + \frac{1}{8} = -\frac{1}{2}$$

$$\text{Cov}(X, Y) = -\frac{1}{2} - 0 = -\frac{1}{2}$$

再算方差：$E(X^2) = 1$，$E(Y^2) = 1$，$D(X) = 1$，$D(Y) = 1$。

$$\rho_{XY} = \frac{-1/2}{1} = -0.5$$

**解读**：$\rho = -0.5$ 说明 $X$ 与 $Y$ 中度负相关——表格里"主对角线"概率小（$1/8$）、"副对角线"概率大（$3/8$），两者倾向于反向取值，与 $\rho < 0$ 完全吻合。

### 例题 6（连续型：三角形区域）

设 $(X, Y)$ 的联合密度为

$$f(x, y) = \begin{cases} 2, & 0 < y < x < 1 \\ 0, & \text{其他} \end{cases}$$

求 $\text{Cov}(X, Y)$ 与 $\rho_{XY}$。

**解**：

$$E(X) = \int_0^1 \int_0^x 2x \, dy \, dx = \int_0^1 2x^2 \, dx = \frac{2}{3}$$

$$E(Y) = \int_0^1 \int_y^1 2y \, dx \, dy = \int_0^1 2y(1-y) \, dy = \frac{1}{3}$$

$$E(XY) = \int_0^1 \int_0^x 2xy \, dy \, dx = \int_0^1 x^3 \, dx = \frac{1}{4}$$

$$\text{Cov}(X, Y) = \frac{1}{4} - \frac{2}{3} \times \frac{1}{3} = \frac{1}{36}$$

$$E(X^2) = \int_0^1 \int_0^x 2x^2 \, dy \, dx = \frac{1}{2}, \qquad D(X) = \frac{1}{2} - \frac{4}{9} = \frac{1}{18}$$

$$E(Y^2) = \int_0^1 \int_y^1 2y^2 \, dx \, dy = \frac{1}{6}, \qquad D(Y) = \frac{1}{6} - \frac{1}{9} = \frac{1}{18}$$

$$\rho_{XY} = \frac{1/36}{\sqrt{(1/18) \times (1/18)}} = \frac{1/36}{1/18} = \frac{1}{2}$$

**步骤讲解**：连续型协方差的标准流程是"先期望、再二阶矩、最后代入公式"。本例题中 $D(X) = D(Y)$ 是巧合（区域对称性），不要默认。

### 例题 7（由 $\rho$ 反推组合方差）

设 $X$ 与 $Y$ 的相关系数 $\rho = 0.5$，$D(X) = D(Y) = 1$，求 $D(X - Y)$。

**解**：$\text{Cov}(X, Y) = \rho \sqrt{D(X)D(Y)} = 0.5$。

$$D(X - Y) = D(X) + D(Y) - 2\text{Cov}(X, Y) = 1 + 1 - 2 \times 0.5 = 1$$

**要点**：给的是 $\rho$ 不是 $\text{Cov}$ 时，先用 $\text{Cov} = \rho\sqrt{D(X)D(Y)}$ 转换，再套方差公式。

## 4. 案例四：样本均值的数字特征（统计推断的基础）

### 例题 8（样本均值与样本平方和）

设 $X_1, X_2, \cdots, X_n$ 独立同分布，$E(X_i) = \mu$，$D(X_i) = \sigma^2$，令 $\bar{X} = \dfrac{1}{n}\sum_{i=1}^n X_i$。

（1）求 $E(\bar{X})$ 与 $D(\bar{X})$；（2）求 $E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right]$。

**解**（1）：

$$E(\bar{X}) = \frac{1}{n} \sum_{i=1}^n E(X_i) = \mu$$

$$D(\bar{X}) = \frac{1}{n^2} \sum_{i=1}^n D(X_i) = \frac{\sigma^2}{n}$$

**关键结论**：样本均值是无偏的（$E(\bar{X}) = \mu$），且方差随 $n$ 增大而缩小——样本量越大，均值越精确。这是大数定律与参数估计的地基。

**解**（2）：先把平方和改写：

$$\sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n X_i^2 - n\bar{X}^2$$

逐项取期望：

$$E\left[\sum_{i=1}^n X_i^2\right] = n(\mu^2 + \sigma^2)$$

$$E\left[n\bar{X}^2\right] = n\left[D(\bar{X}) + E(\bar{X})^2\right] = n\left(\frac{\sigma^2}{n} + \mu^2\right) = \sigma^2 + n\mu^2$$

$$E\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] = n(\mu^2 + \sigma^2) - \sigma^2 - n\mu^2 = (n-1)\sigma^2$$

**要点**：这正是"样本方差要用 $n-1$ 做分母"的数学来源——$E\left[\dfrac{1}{n-1}\sum(X_i - \bar{X})^2\right] = \sigma^2$ 才能无偏估计总体方差（详见《估计量评选标准》）。

### 例题 9（独立正态线性组合）

设 $X$ 与 $Y$ 独立，$X \sim N(1, 4)$，$Y \sim N(2, 9)$，求 $E(2X - 3Y + 1)$ 与 $D(2X - 3Y + 1)$。

**解**：

$$E(2X - 3Y + 1) = 2 \times 1 - 3 \times 2 + 1 = -3$$

$$D(2X - 3Y + 1) = 2^2 \times 4 + (-3)^2 \times 9 = 16 + 81 = 97$$

且由正态可加性，$2X - 3Y + 1 \sim N(-3, 97)$（完整分布都能写出来）。

## 5. 案例五：不等式与渐近估计

### 例题 10（切比雪夫不等式估计）

设 $X_1, X_2, \cdots, X_{100}$ 独立同分布，$X_i \sim B(1, 0.6)$，用切比雪夫不等式估计 $P\left(\sum_{i=1}^{100} X_i \geq 70\right)$。

**解**：设 $S = \sum_{i=1}^{100} X_i$，$E(S) = 100 \times 0.6 = 60$，$D(S) = 100 \times 0.6 \times 0.4 = 24$。

$$P(S \geq 70) = P(S - 60 \geq 10) \leq P(|S - 60| \geq 10) \leq \frac{D(S)}{10^2} = \frac{24}{100} = 0.24$$

**要点**：$\{S \ge 70\} \subseteq \{|S - 60| \ge 10\}$（单边事件被双边事件包含），所以可以用双边切比雪夫不等式给出上界。这个估计很粗糙（真实值远小于 0.24），中心极限定理能给出精确近似（见《大数定律与中心极限定理典型例题》）。

### 例题 11（函数期望与对称性）

设 $X \sim U(0, 2\pi)$，求 $E(\sin X)$ 与 $E(\cos X)$。

**解**：

$$E(\sin X) = \frac{1}{2\pi}\int_0^{2\pi} \sin x \, dx = 0, \qquad E(\cos X) = \frac{1}{2\pi}\int_0^{2\pi} \cos x \, dx = 0$$

**要点**：$\sin$、$\cos$ 在一个整周期上积分为 0。由此出发可以构建"不相关但不独立"的反例（见《相关系数》例题 2）。

## 6. 数字特征计算"路线图"

| 求什么 | 路线 | 常见陷阱 |
| --- | --- | --- |
| $E(X)$ | 加权求和/积分 | 忘记 $X=0$ 那一项（概率不能丢） |
| $E[g(X)]$ | 懒人定理 $\int g(x)f(x)dx$ | $E[g(X)] \neq g(E(X))$ |
| $D(X)$ | $E(X^2) - [E(X)]^2$ | 只算 $E(X^2)$ 忘记减平方 |
| $\text{Cov}(X,Y)$ | $E(XY) - E(X)E(Y)$ | 忘记算 $E(X)$ 或 $E(Y)$ |
| $\rho$ | $\text{Cov} / \sqrt{D(X)D(Y)}$ | 用 $|\rho| \le 1$ 自检 |
| 组合方差 | 一般公式带 $\pm 2\text{Cov}$ | 独立才能省交叉项 |
| 样本均值 | $E(\bar{X}) = \mu$，$D(\bar{X}) = \sigma^2/n$ | 系数 $1/n^2$ 别漏 |

## 7. 常见错误与对策

| 错误示例 | 错误类型 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 案例一里漏算 $X=0$ 的概率项 | 计算遗漏 | 中奖概率之外还有"不中奖" | 分布律必须完整（概率之和为 1）；$X=0$ 项常使 $E(X)$ 明显下降 |
| 方案选择只看期望不看方差 | 分析片面 | 期望相同只是"打平"，还要比风险 | 期望相同比方差；期望不同时用变异系数 $C_V = \sigma/\mu$ 比较 |
| $E[(X+1)^2]$ 展开漏 $2X$ 项 | 计算错误 | 平方展开不完整 | $(X+1)^2 = X^2 + 2X + 1$，逐项取期望 |
| 由 $\rho$ 直接代入方差公式 | 单位错误 | $\rho$ 无量纲而 $\text{Cov}$ 有量纲 | 先换算 $\text{Cov} = \rho\sqrt{D(X)D(Y)}$ 再套公式 |
| 样本平方和期望用 $n\sigma^2$ | 公式误用 | 忘记 $\bar{X}$ 与 $X_i$ 相关，不能直接相加 | 用 $\sum(X_i - \bar{X})^2 = \sum X_i^2 - n\bar{X}^2$ 恒等式拆解 |
| 把 $P(S \ge 70)$ 直接当 $P(|S-60| \ge 10)$ | 集合关系错误 | 单边事件只是双边事件的子集 | 先写包含关系再套不等式；不等号方向必须保持"概率上界"语义 |

## 8. 实战练习

### 练习 1（离散期望）

摸奖游戏：每次 5 元，奖金分布为 $P(0) = 0.7$，$P(10) = 0.25$，$P(50) = 0.05$。求期望收益并判断是否划算。

**提示**：$E(X) = 0 \times 0.7 + 10 \times 0.25 + 50 \times 0.05$。

**参考答案要点**：$E(X) = 2.5 + 2.5 = 5$ 元，与成本 5 元打平，期望公平。

### 练习 2（期望与方差）

设 $X$ 的密度为 $f(x) = \dfrac{1}{2}e^{-|x|}$，求 $E(X)$、$E(X^2)$、$D(X)$。

**提示**：$f$ 为偶函数；$\int_0^\infty x^2 e^{-x} dx = \Gamma(3) = 2$。

**参考答案要点**：$E(X) = 0$；$E(X^2) = \int_0^\infty x^2 e^{-x} dx = 2$；$D(X) = 2$。

### 练习 3（协方差）

设 $(X, Y)$ 的联合分布律为 $P(0,0)=\dfrac{1}{6}$，$P(0,1)=\dfrac{1}{3}$，$P(1,0)=\dfrac{1}{3}$，$P(1,1)=\dfrac{1}{6}$，求 $\text{Cov}(X,Y)$。

**提示**：先求边缘。

**参考答案要点**：$E(X)=E(Y)=\dfrac{1}{2}$，$E(XY)=\dfrac{1}{6}$，$\text{Cov} = \dfrac{1}{6} - \dfrac{1}{4} = -\dfrac{1}{12}$（负联动）。

### 练习 4（相关系数）

设 $X$ 与 $Y$ 独立，$X \sim N(0, 1)$，$Y = X^2$（注意 $Y$ 由 $X$ 决定）。求 $\text{Cov}(X, Y)$ 与 $\rho$。

**提示**：$E(X^3) = 0$。

**参考答案要点**：$E(X)=0$，$E(Y)=1$，$E(XY) = E(X^3) = 0$，$\text{Cov} = 0$，$\rho = 0$——不相关但不独立。

### 练习 5（组合）

设 $X_1, X_2, \cdots, X_n$ 独立同分布，$E(X_i) = \mu$，$D(X_i) = \sigma^2$，求 $E(\bar{X})$、$D(\bar{X})$ 与 $E(\bar{X}^2)$。

**提示**：$E(\bar{X}^2) = D(\bar{X}) + [E(\bar{X})]^2$。

**参考答案要点**：$E(\bar{X}) = \mu$；$D(\bar{X}) = \dfrac{\sigma^2}{n}$；$E(\bar{X}^2) = \dfrac{\sigma^2}{n} + \mu^2$。

## 9. 一句话记忆

数字特征是一套"体检指标"：期望看水平（$E(X)$），方差看风险（$D(X) = E(X^2) - [E(X)]^2$），协方差看联动（$\text{Cov} = E(XY) - E(X)E(Y)$），相关系数看线性强度（$\rho = \text{Cov}/\sqrt{D(X)D(Y)}$），所有计算都走"期望优先、公式带入、结果自检"的路线。
