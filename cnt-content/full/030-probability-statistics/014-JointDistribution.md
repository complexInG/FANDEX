## 0. 地图定位：从一维到二维

手机地图上定位一个位置，你需要两个数字：**经度 $X$** 和 **纬度 $Y$**。单个经度告诉你"东西向在哪"，单个纬度告诉你"南北向在哪"，但只有 $(X, Y)$ 组合起来，才能确定"你在哪个路口"。

这就是本讲的**维度驱动**主题：前几讲研究单个随机变量（一维），现在把两个随机变量 $(X, Y)$ 放在一起研究——**联合分布**。关键认知升级是：

- **两个一维分布 ≠ 二维分布**。知道"体重分布"和"身高分布"，并不能确定"身高和体重的联合规律"（高个子可能更重，也可能无关）；
- 联合分布描述的是 $(X, Y)$ **同时取值的完整规律**，它包含的信息比两个边缘分布加起来更多。

联合分布是后续边缘分布（015 讲）、条件分布（016 讲）、独立性（017 讲）以及协方差相关（022、023 讲）的公共地基。

## 1. 二维随机变量

### 1.1 定义

设 $E$ 是随机试验，$\Omega$ 是其样本空间，$X = X(\omega)$、$Y = Y(\omega)$ 是定义在 $\Omega$ 上的两个随机变量，则 $(X, Y)$ 称为**二维随机变量**（**二维随机向量**）。

**大白话**：一次试验同时记录两个数字——比如抽一个人同时记身高 $X$ 和体重 $Y$，掷两颗骰子记 $(X, Y)$ =（第一颗点数, 第二颗点数）。

### 1.2 分类

| 类型         | 条件                                       | 例子                         |
| ------------ | ------------------------------------------ | ---------------------------- |
| 二维离散型   | $X, Y$ 都取有限或可列个值                  | 两枚骰子的点数对             |
| 二维连续型   | 存在非负 $f(x,y)$ 使 $F(x,y) = \iint f \, du\,dv$ | 随机点在地图上的坐标         |
| 混合型       | 一个离散一个连续                           | 是否患病 × 发病时间          |

## 2. 联合分布函数：二维的"累计器"

### 2.1 定义

对任意实数 $x, y$，二元函数

$$F(x, y) = P(X \leq x, Y \leq y)$$

称为 $(X, Y)$ 的**联合分布函数**。

**几何意义**：$F(x, y)$ 是随机点 $(X, Y)$ 落在"以 $(x, y)$ 为右上顶点的无穷矩形"$(-\infty, x] \times (-\infty, y]$ 内的概率。一维的"向左累计"变成了二维的"向左下累计"。

### 2.2 联合分布函数的性质

1. **单调性**：关于 $x$、$y$ 分别单调不减；
2. **有界**：$0 \leq F(x, y) \leq 1$；
3. **边界值**：

$$F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0, \qquad F(+\infty, +\infty) = 1$$

4. **右连续**：关于 $x$、$y$ 分别右连续；
5. **非负矩形概率**：对 $x_1 < x_2$，$y_1 < y_2$，

$$P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1) \geq 0$$

**性质 5 是二维特有的**：二维"矩形概率"必须非负，这比一维单调性更强，是判断二元函数是否为分布函数的"额外关卡"（一维只需单调 + 边界 + 右连续）。

### 2.3 由联合分布函数计算矩形概率

$$P(x_1 < X \leq x_2, y_1 < Y \leq y_2) = F(x_2, y_2) - F(x_1, y_2) - F(x_2, y_1) + F(x_1, y_1)$$

**理解**："左下加，右下减，左上减，右上加"——用文氏图看，就是把 $(-\infty, x_2] \times (-\infty, y_2]$ 这块大矩形里，不属于目标矩形的部分剔除掉。

## 3. 二维离散型：联合分布律

### 3.1 定义

$(X, Y)$ 的所有可能取值为 $(x_i, y_j)$（$i, j = 1, 2, \cdots$），则

$$P(X = x_i, Y = y_j) = p_{ij}, \quad i, j = 1, 2, \cdots$$

称为 $(X, Y)$ 的**联合分布律**，性质：

1. $p_{ij} \geq 0$；
2. $\displaystyle\sum_{i=1}^{\infty}\sum_{j=1}^{\infty} p_{ij} = 1$。

与联合分布函数的关系：

$$F(x, y) = \sum_{x_i \leq x} \sum_{y_j \leq y} p_{ij}$$

### 3.2 完整例题：不放回抽球

**例题**：袋中 2 红 3 白，不放回取两次，$X$ = 第一次红球数，$Y$ = 第二次红球数，求联合分布律。

**解**：

$$P(X=0, Y=0) = \frac{3}{5} \times \frac{2}{4} = \frac{3}{10}, \quad P(X=0, Y=1) = \frac{3}{5} \times \frac{2}{4} = \frac{3}{10}$$

$$P(X=1, Y=0) = \frac{2}{5} \times \frac{3}{4} = \frac{3}{10}, \quad P(X=1, Y=1) = \frac{2}{5} \times \frac{1}{4} = \frac{1}{10}$$

| $X \backslash Y$ | 0                | 1                |
| :--------------: | :--------------: | :--------------: |
|        0         | $\dfrac{3}{10}$  | $\dfrac{3}{10}$  |
|        1         | $\dfrac{3}{10}$  | $\dfrac{1}{10}$  |

**验证**：四个概率之和 $\dfrac{3+3+3+1}{10} = 1$。

**要点**：不放回抽球要用乘法公式（条件概率）逐格计算；若改为有放回，则 $X, Y$ 独立，$p_{ij} = p_{i\cdot}p_{\cdot j}$（见 015、017 讲）。

### 3.3 完整例题：由联合分布律求事件概率

**例题**：承上题，求 $P(X + Y \leq 1)$ 与 $P(X > Y)$。

**解**：

$$P(X + Y \leq 1) = p_{00} + p_{01} + p_{10} = \frac{3}{10} + \frac{3}{10} + \frac{3}{10} = \frac{9}{10}$$

$$P(X > Y) = p_{10} = \frac{3}{10}$$

**要点**：事件概率 = 满足条件的格点概率之和——联合分布律是"查表"的基础。

## 4. 二维连续型：联合概率密度

### 4.1 定义

若存在非负可积函数 $f(x, y)$，使

$$F(x, y) = \int_{-\infty}^{y} \int_{-\infty}^{x} f(u, v) \, du \, dv$$

则 $(X, Y)$ 为**二维连续型随机变量**，$f(x, y)$ 为**联合概率密度函数**。

### 4.2 性质

1. **非负性**：$f(x, y) \geq 0$；
2. **规范性**：$\displaystyle\int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} f(x, y) \, dx \, dy = 1$；
3. **区域概率**：$P((X, Y) \in D) = \iint_D f(x, y) \, dx \, dy$（**概率 = 密度曲面下的体积**，这是 009 讲"面积"思想的二维推广）；
4. **混合偏导**：在 $f$ 的连续点处 $\dfrac{\partial^2 F}{\partial x \partial y} = f(x, y)$。

### 4.3 完整例题：验证规范性与区域概率

**例题**：设 $(X, Y)$ 的联合密度为

$$f(x, y) = \begin{cases} 6xy^2, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

验证规范性并求 $P(X + Y \leq 1)$。

**解**：规范性（可分离变量）：

$$\int_0^1 \int_0^1 6xy^2 \, dx \, dy = 6 \int_0^1 x \, dx \cdot \int_0^1 y^2 \, dy = 6 \times \frac{1}{2} \times \frac{1}{3} = 1 \quad \checkmark$$

区域概率（三角形区域 $x + y \leq 1$）：

$$P(X + Y \leq 1) = \int_0^1 \int_0^{1-x} 6xy^2 \, dy \, dx = \int_0^1 6x \cdot \frac{(1-x)^3}{3} \, dx = 2\int_0^1 x(1-x)^3 \, dx$$

$$= 2 \cdot B(2, 4) = 2 \cdot \frac{\Gamma(2)\Gamma(4)}{\Gamma(6)} = 2 \cdot \frac{1! \cdot 3!}{5!} = 2 \cdot \frac{6}{120} = \frac{1}{10}$$

**要点**：区域概率的积分限由"密度非零区域 ∩ 事件区域"决定——先画图确定积分区域，再定积分限。本题 $\int_0^{1-x}$ 的限来自 $x + y \leq 1$ 即 $y \leq 1 - x$。

**Python 模拟验证**：

```python
import random

def joint_prob(trials=100000):
    hit = 0
    for _ in range(trials):
        x, y = random.random(), random.random()   # 在单位正方形均匀取点
        if x + y <= 1:                            # 概率权重 ∝ 6xy^2
            hit += 6 * x * y * y / 1
    return hit / trials

print(f"模拟 P(X+Y<=1): {joint_prob():.4f}")   # 理论值 0.1
```

## 5. 常见二维分布

### 5.1 二维均匀分布

$D$ 为平面有界区域，面积 $S_D$：

$$f(x, y) = \begin{cases} \dfrac{1}{S_D}, & (x, y) \in D \\ 0, & \text{其他} \end{cases}$$

**意义**：随机点在 $D$ 内"均匀撒落"，区域概率 = 面积比——这正是 003 讲几何概型的密度语言表达。

**完整例题**：$(X, Y)$ 在单位圆 $x^2 + y^2 \leq 1$ 内均匀分布，求 $P(X > Y)$。

**解**：$S_D = \pi$。事件区域为圆内 $x > y$ 的半圆（直径 $x = y$ 平分圆）：

$$P(X > Y) = \frac{\text{半圆面积}}{\pi} = \frac{\pi/2}{\pi} = \frac{1}{2}$$

### 5.2 二维正态分布

$$f(x, y) = \frac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}} \exp\left\{-\frac{1}{2(1-\rho^2)}\left[\frac{(x-\mu_1)^2}{\sigma_1^2} - \frac{2\rho(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2} + \frac{(y-\mu_2)^2}{\sigma_2^2}\right]\right\}$$

记作 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，其中 $\rho$ 为 $X$ 与 $Y$ 的相关系数（$|\rho| < 1$）。

**重要性质**：

1. 边缘分布：$X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$（与 $\rho$ 无关）；
2. 独立 $\iff$ $\rho = 0$（二维正态中"不相关"与"独立"等价，一般分布不成立）；
3. 任意线性组合仍为正态（$aX + bY + c$ 服从一维正态）。

**直观**：$\rho$ 决定联合密度"山峰"的朝向——$\rho > 0$ 时椭圆长轴沿 $y = x$ 方向倾斜（$X$ 大则 $Y$ 偏大）。

## 6. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 认为"两个边缘分布已知就能推出联合分布" | 概念错误 | 混淆联合与边缘 | 联合分布信息多于边缘分布之和；只有独立时联合 = 边缘乘积 |
| 2 | 二维离散概率和不验证是否为 1 | 概念错误 | 漏格或多格 | 列出全部 $(x_i, y_j)$ 组合，逐格计算并求和验证 |
| 3 | 区域概率积分限画错（先积谁、限依赖谁） | 计算错误 | 不画图直接积分 | 先画"密度非零区域 ∩ 事件区域"，再根据图形定限 |
| 4 | 二维正态中误以为 $\rho = 0$ 时仍不独立 | 概念错误 | 把一般结论当普适 | 二维正态特例：$\rho = 0 \iff$ 独立；一般分布"不相关 ≠ 独立" |
| 5 | 矩形概率公式 $F$ 的加减号记错 | 公式错误 | 二维累计理解不透 | 记"左下加、右下减、左上减、右上加"，或画矩形验证 |
| 6 | 联合分布函数判定时只查一维单调性 | 概念错误 | 忽略二维特有的矩形非负条件 | 检查性质 5：所有矩形概率非负（含两个交叉项） |

## 7. 实战练习

### 练习 1（入门）：联合分布律

袋中 1 红 2 白，**有放回**取两次，$X$、$Y$ 分别为两次取到红球数（各取 0/1），求联合分布律。

**提示**：有放回时两次独立，$p_{ij} = P(X=i)P(Y=j)$。

**参考答案要点**：$P(X=0) = P(Y=0) = \dfrac{2}{3}$，$P(X=1) = P(Y=1) = \dfrac{1}{3}$。联合分布律：$p_{00} = \dfrac{4}{9}$，$p_{01} = p_{10} = \dfrac{2}{9}$，$p_{11} = \dfrac{1}{9}$。

### 练习 2（入门）：联合分布函数矩形概率

设 $F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$，求 $P(1 < X \leq 2, 1 < Y \leq 2)$。

**提示**：矩形概率公式，代入 $F$。

**参考答案要点**：$F(2,2) - F(1,2) - F(2,1) + F(1,1) = (1-e^{-2})^2 - 2(1-e^{-1})(1-e^{-2}) + (1-e^{-1})^2 = (e^{-1} - e^{-2})^2 \approx 0.0996$。

### 练习 3（进阶）：二维连续型求常数

设 $f(x, y) = \begin{cases} cxy, & 0 < x < 1, 0 < y < x \\ 0, & \text{其他} \end{cases}$，求 $c$。

**提示**：注意 $y$ 的积分限依赖 $x$（$0 < y < x$）。

**参考答案要点**：$\int_0^1 \int_0^x cxy \, dy \, dx = c \int_0^1 x \cdot \dfrac{x^2}{2} dx = \dfrac{c}{2} \cdot \dfrac{1}{4} = \dfrac{c}{8} = 1 \implies c = 8$。

### 练习 4（进阶）：区域概率

承练习 3（$c = 8$），求 $P(X + Y < 1)$。

**提示**：事件区域为 $\{0 < y < x, \, x + y < 1\}$，即 $0 < y < \min(x, 1-x)$，画图后分两段积分或整体积分。

**参考答案要点**：$\int_0^{1/2}\int_0^x 8xy\,dy\,dx + \int_{1/2}^1 \int_0^{1-x} 8xy\,dy\,dx = \dfrac{1}{8} + \dfrac{7}{24} = \dfrac{5}{12} \approx 0.4167$。

### 练习 5（挑战）：二维正态与相关

设 $(X, Y) \sim N(0, 0, 1, 1, 0.5)$，判断 $X$ 与 $Y$ 是否独立；写出 $X + Y$ 的分布。

**提示**：$\rho = 0.5 \neq 0$；线性组合仍正态，$E(X+Y) = 0$，$D(X+Y) = 1 + 1 + 2\rho = 3$。

**参考答案要点**：$\rho = 0.5 \neq 0$，不独立（正相关）；$X + Y \sim N(0, 3)$。二维正态的线性组合正态性、$\rho$ 与方差的关系是后续协方差（022 讲）的预演。

## 8. 一句话记忆

> **联合分布是"两个人的合影"：联合分布律（离散查表）或联合密度（连续积分），$F(x,y)$ 是向左下累计的二维累计器；联合信息 > 两个边缘之和，独立时联合才等于边缘相乘。**

## 深度专题扩展

### 13.1 联合分布与贝叶斯网络的起点

联合分布 $P(X_1, \cdots, X_n)$ 是概率图模型的起点：直接存储 $n$ 个变量的联合分布需要指数级空间，贝叶斯网络通过"条件独立分解" $P(X_1,\cdots,X_n) = \prod_i P(X_i \mid \text{父节点})$ 把复杂度降到线性。理解二维联合分布，是理解这一思想的入口。

### 13.2 二维正态的等概率椭圆

二维正态密度函数的等高线是椭圆：$(x, \mu_1, \sigma_1, y, \mu_2, \sigma_2, \rho)$ 决定的二次型 $= \text{常数}$。$\rho$ 控制椭圆倾斜，$\sigma_1/\sigma_2$ 控制轴比。这个"椭圆"是主成分分析（PCA）和多元统计分析的可视化基础。
