## 0. 用一把"已知刻度的标准尺"量东西

木匠量木板长度，如果手里有一把**出厂校准过、刻度精确的标准尺**（总体的 $\sigma$ 已知），量出来多少就是多少，误差完全可控。可如果尺子是劣质的（$\sigma$ 未知），量出来的数就自带不确定性，得用更"厚实"的尺子（$t$ 分布）兜底。

**Z 检验的适用条件**正是"手里有标准尺"：

1. 总体服从正态分布 $N(\mu, \sigma^2)$ 且 **$\sigma$ 已知**；或
2. 总体分布未知，但**样本量 $n$ 较大**（$n \geq 30$），由中心极限定理，$\bar{X}$ 近似正态，用样本标准差替代也不会差太多。

在这两种条件下，检验统计量都可以用标准正态分布 $N(0,1)$——这就是 $Z$ 检验名字的由来（$Z$ 代表标准正态）。

本文用**条件驱动**的方式组织：先明确"什么时候能用 $Z$"（条件），再分别给出单总体均值、双总体均值差、单/双总体比例的 $Z$ 检验（三种场景），每个场景配完整例题与拒绝域。

## 1. 单总体均值的 Z 检验

### 1.1 适用条件

- 总体 $X \sim N(\mu, \sigma^2)$，**$\sigma$ 已知**；或
- 总体分布未知但 $n$ 大（$\geq 30$），近似适用。

### 1.2 检验步骤

**假设**：

- 双侧：$H_0: \mu = \mu_0$，$H_1: \mu \neq \mu_0$
- 右侧：$H_0: \mu \leq \mu_0$，$H_1: \mu > \mu_0$
- 左侧：$H_0: \mu \geq \mu_0$，$H_1: \mu < \mu_0$

**检验统计量**（$\sigma$ 已知，套抽样分布定理一）：

$$Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$$

在 $H_0$ 成立时，$Z \sim N(0, 1)$。

**拒绝域**：

| 检验类型 | 拒绝域 |
| --- | --- |
| 双侧 | $\|Z\| > z_{\alpha/2}$ |
| 右侧 | $Z > z_\alpha$ |
| 左侧 | $Z < -z_\alpha$ |

常用临界值：$z_{0.05} = 1.645$，$z_{0.025} = 1.96$，$z_{0.005} = 2.576$。

### 1.3 完整例题：单总体左侧检验

**例题**：某工厂生产的灯泡寿命服从正态分布 $N(\mu, 100)$，标准规定平均寿命不低于 1000 小时。现抽取 25 只灯泡，测得平均寿命 $\bar{x} = 995$ 小时。在 $\alpha = 0.05$ 下检验灯泡寿命是否达标。

**解**：

**第 1 步（提假设）**：想证明"不达标"（$\mu < 1000$）放 $H_1$：

$$H_0: \mu \geq 1000, \quad H_1: \mu < 1000 \quad \text{（左侧检验）}$$

**第 2 步（选统计量）**：$\sigma = 10$ 已知，$Z = \dfrac{\bar{X} - 1000}{10/\sqrt{25}}$。

**第 3 步（算观测值）**：

$$Z = \frac{995 - 1000}{10/5} = \frac{-5}{2} = -2.5$$

**第 4 步（定拒绝域）**：左侧检验，$z_{0.05} = 1.645$，拒绝域 $W = \{Z < -1.645\}$。

**第 5 步（决策与结论）**：$Z = -2.5 < -1.645$，落入拒绝域，**拒绝 $H_0$**——有显著证据认为灯泡平均寿命低于 1000 小时，不达标。

**P 值补充**：$P = P(Z < -2.5) = 0.0062 < 0.05$，与拒绝域法结论一致。

### 1.4 例题：双侧检验

**例题**：某自动包装机装袋重量 $X \sim N(\mu, 0.16)$，标准要求平均重量 500g。抽查 16 袋，$\bar{x} = 500.4$g。在 $\alpha = 0.05$ 下检验包装机是否正常工作（平均重量是否偏离标准）。

**解**：

$H_0: \mu = 500$，$H_1: \mu \neq 500$（双侧）。

$\sigma = 0.4$ 已知，$Z = \dfrac{500.4 - 500}{0.4/\sqrt{16}} = \dfrac{0.4}{0.1} = 4$。

双侧拒绝域 $|Z| > z_{0.025} = 1.96$。$|Z| = 4 > 1.96$，**拒绝 $H_0$**——包装机平均重量显著偏离 500g，需检修。

## 2. 双总体均值差的 Z 检验

### 2.1 适用条件

两个正态总体 $N(\mu_1, \sigma_1^2)$、$N(\mu_2, \sigma_2^2)$，**$\sigma_1, \sigma_2$ 已知**；或两样本量都较大（近似）。

### 2.2 检验步骤

**假设**（通常 $d_0 = 0$）：

- 双侧：$H_0: \mu_1 - \mu_2 = d_0$，$H_1: \mu_1 - \mu_2 \neq d_0$
- 右侧：$H_0: \mu_1 - \mu_2 \leq d_0$，$H_1: \mu_1 - \mu_2 > d_0$
- 左侧：$H_0: \mu_1 - \mu_2 \geq d_0$，$H_1: \mu_1 - \mu_2 < d_0$

**检验统计量**（均值差的抽样分布定理五）：

$$Z = \frac{(\bar{X} - \bar{Y}) - d_0}{\sqrt{\frac{\sigma_1^2}{n_1} + \frac{\sigma_2^2}{n_2}}}$$

$H_0$ 下 $Z \sim N(0, 1)$。拒绝域与单总体相同。

### 2.3 完整例题

**例题**：甲乙两台机床加工同一种零件，直径分别服从 $N(\mu_1, 0.04)$ 和 $N(\mu_2, 0.09)$。从甲机床抽取 6 件，$\bar{x} = 14.95$；从乙机床抽取 9 件，$\bar{y} = 15.02$。在 $\alpha = 0.05$ 下检验两机床加工精度是否有显著差异（平均直径是否不同）。

**解**：

$H_0: \mu_1 = \mu_2$，$H_1: \mu_1 \neq \mu_2$（$d_0 = 0$，双侧）。

$\sigma_1 = 0.2$，$\sigma_2 = 0.3$ 已知：

$$Z = \frac{14.95 - 15.02}{\sqrt{\frac{0.04}{6} + \frac{0.09}{9}}} = \frac{-0.07}{\sqrt{0.00667 + 0.01}} = \frac{-0.07}{\sqrt{0.01667}} = \frac{-0.07}{0.1291} = -0.542$$

拒绝域 $|Z| > 1.96$。$|Z| = 0.542 < 1.96$，**不拒绝 $H_0$**——没有显著证据表明两台机床平均直径不同。

## 3. 大样本比例的 Z 检验

### 3.1 单总体比例

设 $X \sim B(n, p)$（$n$ 次独立试验），$\hat{p} = X/n$。

$$H_0: p = p_0, \quad H_1: p \neq p_0 \text{（或单侧）}$$

$$Z = \frac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$$

$n$ 较大时（$np_0 \geq 5$ 且 $n(1-p_0) \geq 5$），$Z$ 近似 $N(0, 1)$。注意：**原假设下的标准误用 $p_0$ 计算**（而不是 $\hat{p}$），这是比例检验与置信区间的关键区别。

### 3.2 双总体比例差

$$H_0: p_1 = p_2, \quad H_1: p_1 \neq p_2$$

$$Z = \frac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}}$$

其中 $\hat{p} = \dfrac{X_1 + X_2}{n_1 + n_2}$ 为**合并比例**（在 $H_0: p_1 = p_2$ 下，用合并样本估计共同比例）。

### 3.3 完整例题

**例题**：某产品原不合格率为 5%。采用新工艺后抽查 200 件，发现 6 件不合格。在 $\alpha = 0.05$ 下检验新工艺是否显著降低了不合格率。

**解**：

$H_0: p \geq 0.05$，$H_1: p < 0.05$（左侧检验）。

$$\hat{p} = \frac{6}{200} = 0.03$$

$$Z = \frac{0.03 - 0.05}{\sqrt{0.05 \times 0.95/200}} = \frac{-0.02}{\sqrt{0.0002375}} = \frac{-0.02}{0.01541} = -1.298$$

左侧拒绝域 $Z < -z_{0.05} = -1.645$。$Z = -1.298 > -1.645$，**不拒绝 $H_0$**——数据不足以证明新工艺显著降低了不合格率（虽然 3% < 5%，但差异未达统计显著）。

**要点**：样本比例 3% 低于 5%，但抽样波动可能造成这种差异。检验告诉我们：凭这 200 件的证据，还不能下"显著降低"的结论。这就是"统计显著"与"表面差异"的区别。

## 4. Z 检验使用条件速查

| 场景 | 统计量 | 条件 | 拒绝域（双侧） |
| --- | --- | --- | --- |
| 单总体均值 | $Z = \dfrac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$ | $\sigma$ 已知或 $n$ 大 | $|Z| > z_{\alpha/2}$ |
| 双总体均值差 | $Z = \dfrac{(\bar{X}-\bar{Y}) - d_0}{\sqrt{\sigma_1^2/n_1 + \sigma_2^2/n_2}}$ | $\sigma_1, \sigma_2$ 已知或 $n$ 大 | $|Z| > z_{\alpha/2}$ |
| 单总体比例 | $Z = \dfrac{\hat{p} - p_0}{\sqrt{p_0(1-p_0)/n}}$ | $np_0 \geq 5$ 且 $n(1-p_0) \geq 5$ | $|Z| > z_{\alpha/2}$ |
| 双总体比例差 | $Z = \dfrac{\hat{p}_1 - \hat{p}_2}{\sqrt{\hat{p}(1-\hat{p})(1/n_1+1/n_2)}}$ | 各组期望频数 $\geq 5$ | $|Z| > z_{\alpha/2}$ |

**与 $t$ 检验的分界线**：$\sigma$ 已知 → $Z$；$\sigma$ 未知（小样本）→ $t$（见下一篇）。

## 5. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 条件不符乱用 | $\sigma$ 未知且 $n$ 小仍用 $Z$ | 只看"均值检验"不看条件 | 小样本 $\sigma$ 未知必须用 $t$；$Z$ 只用于 $\sigma$ 已知或 $n$ 大 |
| 单双尾错乱 | 左侧检验用 $z_{\alpha/2}$ | 套双侧习惯 | 单侧检验用 $z_\alpha$，双侧用 $z_{\alpha/2}$ |
| 比例标准误用错 | 单总体比例用 $\sqrt{\hat{p}(1-\hat{p})/n}$ | 把区间估计公式搬进检验 | 检验时在 $H_0$ 下计算，标准误用 $p_0$：$\sqrt{p_0(1-p_0)/n}$ |
| 双总体比例忘合并 | 直接用两个 $\hat{p}$ 分别算 | 不知 $H_0$ 下 $p_1 = p_2$ | 用合并比例 $\hat{p} = \frac{X_1+X_2}{n_1+n_2}$ |
| 大样本条件不查 | $np_0 < 5$ 还强行近似 | 忽略近似前提 | 先检查 $np_0 \geq 5$、$n(1-p_0) \geq 5$，否则用精确二项检验 |
| 结论过度解读 | 不拒绝就断言"无差异" | 混淆证据不足与证据否定 | "不拒绝 $H_0$"只说明证据不足；要证明"无差异"需等价性检验 |
| 忽略效应量 | $n$ 大时细微差异也显著 | 统计显著 ≠ 实际显著 | 同时报告均值差/比例差的量级与置信区间 |

## 6. 实战练习

**练习 1（单总体均值）**：某厂生产钢丝的抗拉强度服从 $N(\mu, 64)$，标准要求 $\mu \geq 110$。抽取 16 根，$\bar{x} = 106$。在 $\alpha = 0.05$ 下检验钢丝是否达标。

**提示**：左侧检验，$Z = \dfrac{106 - 110}{8/4} = -2$。

**参考答案要点**：$H_0: \mu \geq 110$，$H_1: \mu < 110$；$Z = -2 < -1.645$，拒绝 $H_0$，认为不达标。

**练习 2（单总体比例）**：某市调查 400 户家庭，其中 180 户拥有汽车。在 $\alpha = 0.05$ 下检验该市家庭拥有汽车的比例是否为 50%。

**提示**：双侧比例检验，$p_0 = 0.5$。

**参考答案要点**：$\hat{p} = 0.45$，$Z = \dfrac{0.45 - 0.5}{\sqrt{0.5 \times 0.5/400}} = -2$；$|Z| = 2 > 1.96$，拒绝 $H_0$，比例不是 50%。

**练习 3（双总体均值差）**：两种配料生产的产品指标分别服从 $N(\mu_1, 1)$、$N(\mu_2, 1)$，各抽 25 件，$\bar{x} = 10.2$，$\bar{y} = 9.6$。在 $\alpha = 0.05$ 下检验两种配料效果是否有差异。

**提示**：$\sigma_1 = \sigma_2 = 1$ 已知，双侧 $Z$。

**参考答案要点**：$Z = \dfrac{0.6}{\sqrt{1/25 + 1/25}} = \dfrac{0.6}{0.283} = 2.121 > 1.96$，拒绝 $H_0$，两种配料效果有显著差异。

**练习 4（大样本近似）**：总体分布未知，$n = 60$，$\bar{x} = 100$，$s = 15$，检验 $H_0: \mu = 95$（$\alpha = 0.05$，单侧 $H_1: \mu > 95$）。

**提示**：$n$ 大用近似 $Z$，标准误用 $s/\sqrt{n}$。

**参考答案要点**：$Z = \dfrac{100 - 95}{15/\sqrt{60}} = \dfrac{5}{1.936} = 2.58 > 1.645$，拒绝 $H_0$，认为均值显著大于 95。

**练习 5（综合与 P 值）**：设双侧 $Z$ 检验得 $Z = 2.4$，求 P 值；若 $\alpha = 0.01$，结论如何？

**提示**：P 值 $= 2[1 - \Phi(2.4)]$。

**参考答案要点**：P 值 $= 2 \times 0.0082 = 0.0164$。$0.0164 > 0.01$，不拒绝 $H_0$（$\alpha = 0.05$ 时则会拒绝）——同一数据，显著性水平不同结论可能不同，这就是 $\alpha$ 的意义。

## 7. 一句话记忆

**Z 检验是"标准尺子"检验：$\sigma$ 已知（或样本大）时，把 $\bar{X}$（或 $\hat{p}$）标准化成 $Z \sim N(0,1)$，与 $z_\alpha$ 或 $z_{\alpha/2}$ 比大小定拒绝域；单侧用 $z_\alpha$，双侧用 $z_{\alpha/2}$，比例检验的标准误用 $H_0$ 下的 $p_0$ 算。**
