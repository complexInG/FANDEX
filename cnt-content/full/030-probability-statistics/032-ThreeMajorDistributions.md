## 0. 三种常见的"统计分布工具"

假如你是一个修表匠，桌上摆着三种测量工具：**卡尺**量长度、**游标**测内径、**砝码秤**称重量。三种工具功能不同、适用场景不同，但都离不开同一个源头——标准刻度。

数理统计里也有三件"必备工具"，它们统称为**三大抽样分布**：

- **$\chi^2$ 分布（卡方分布）**：处理与**方差（波动程度）**有关的问题，如"这个生产线的波动是否超标？"
- **$t$ 分布（学生分布）**：处理与**均值（平均水平）**有关的问题，尤其是"总体波动未知"时，如"这批零件的平均长度是否达标？"
- **$F$ 分布**：处理**两个方差之比**的问题，如"两台机器的加工精度谁更稳定？"

更妙的是，这三件工具**同根同源**：它们都是从标准正态分布 $N(0,1)$ 衍生出来的。标准正态 $N(0,1)$ 就是那张"标准刻度"，三大分布是它派生的三件专业工具。

本文用**图谱驱动**的方式，先把三大分布"从哪里来、长什么样、有什么本事、和谁有亲戚关系"这张图完整画出来，再逐个展开。

## 1. 分布图谱总览

### 1.1 一张图看懂三大分布的关系

$$
N(0,1) \xrightarrow{\text{平方和}} \chi^2(n) \xrightarrow{\text{除以自由度后取比值}} t(n) \text{ 与 } F(n_1, n_2)
$$

具体来说：

- $n$ 个独立的 $N(0,1)$ 变量的**平方和** $\to \chi^2(n)$
- 一个 $N(0,1)$ **除以** $\sqrt{\chi^2(n)/n}$ $\to t(n)$
- 两个独立的 $\chi^2$ 变量**各除以其自由度后再取比值** $\to F(n_1, n_2)$
- 特殊亲戚关系：$t^2(n) = F(1, n)$

### 1.2 三件工具的"岗位分工"

| 分布 | 主要用途 | 一句话定位 |
| --- | --- | --- |
| $\chi^2$ | 方差的区间估计与检验、拟合优度检验、独立性检验 | "方差与波动"的代言人 |
| $t$ | 均值的区间估计与检验（$\sigma$ 未知时） | "均值推断"的守卫者 |
| $F$ | 两方差比的检验、方差分析（ANOVA） | "比较谁更稳定"的裁判 |

把这张表记住，后续章节（区间估计、假设检验）里凡是看到"方差"想到 $\chi^2$ 和 $F$，看到"均值且 $\sigma$ 未知"想到 $t$，方向就不会错。

## 2. χ² 分布：平方和的分布

### 2.1 直观理解

为什么研究波动要看"平方和"？因为方差本质上是"离差平方的平均"。而统计里为了消除正负抵消，习惯把偏差**平方**后再求和。若干个独立标准正态变量的平方和，其分布太常出现，于是被单独命名。

### 2.2 定义

设 $X_1, X_2, \cdots, X_n$ 独立同分布，$X_i \sim N(0, 1)$，则

$$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2$$

服从自由度为 $n$ 的 **$\chi^2$ 分布**，记作 $\chi^2 \sim \chi^2(n)$。这里自由度 $n$ 就是参与平方和的**独立标准正态变量的个数**。

### 2.3 密度函数

$$f(x) = \begin{cases} \dfrac{1}{2^{n/2}\Gamma(n/2)} x^{n/2 - 1} e^{-x/2}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

其中 $\Gamma(\cdot)$ 是伽马函数（$\Gamma(s) = \int_0^\infty x^{s-1}e^{-x}dx$）。事实上 $\chi^2(n)$ 就是 $\Gamma\left(\dfrac{n}{2}, \dfrac{1}{2}\right)$ 分布——这条联系是推导密度函数的捷径。密度只在 $x > 0$ 上非零，说明 $\chi^2$ 变量**恒非负**，且分布是右偏的（偏度随 $n$ 增大而减小，$n$ 大时趋近正态）。

### 2.4 性质（图谱节点的"技能点"）

1. **期望与方差**：

$$E(\chi^2) = n, \quad D(\chi^2) = 2n$$

（由矩母函数 $M(t) = (1-2t)^{-n/2}$ 可一次导出。）

2. **可加性**：若 $\chi_1^2 \sim \chi^2(n_1)$，$\chi_2^2 \sim \chi^2(n_2)$，且独立，则

$$\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$$

这是"平方和拆开看"的数学表达：两个独立波动的平方和，总波动等于两者之和。

3. **与样本方差的关系**（连接上一篇文章的关键）：设 $X_1, \cdots, X_n \sim N(\mu, \sigma^2)$，则

$$\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$$

且 $\bar{X}$ 与 $S^2$ 独立。自由度为什么是 $n-1$ 而不是 $n$？因为 $\sum (X_i - \bar{X})^2$ 中，$n$ 个离差满足一个约束 $\sum (X_i - \bar{X}) = 0$，独立成分只有 $n-1$ 个——这正是上一篇文章"除以 $n-1$"的深层原因。

4. **渐近正态性**：当 $n$ 充分大时，$\chi^2(n)$ 近似 $N(n, 2n)$（中心极限定理的直接推论）。

5. **分位数**：$\chi^2_\alpha(n)$ 满足 $P(\chi^2(n) > \chi^2_\alpha(n)) = \alpha$，称为**上 $\alpha$ 分位数**。注意：$\chi^2$ 分布不对称，所以双侧区间估计需要分别查 $\chi^2_{1-\alpha/2}(n)$ 和 $\chi^2_{\alpha/2}(n)$。

## 3. t 分布：小样本均值的守护者

### 3.1 直观理解

想检验均值 $\mu$，最自然的思路是用 $\bar{X} - \mu$。若 $\sigma$ 已知，标准化得 $Z = \dfrac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0,1)$（下一篇会讲）。但现实常常是 **$\sigma$ 也不知道**。那就用 $S$ 代替 $\sigma$。用 $S$ 代替 $\sigma$ 后，统计量的尾巴变得更胖（不确定性变大了），分布不再是正态，而是一个新的分布——$t$ 分布。

### 3.2 定义

设 $X \sim N(0, 1)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 独立，则

$$T = \frac{X}{\sqrt{Y/n}}$$

服从自由度为 $n$ 的 **$t$ 分布**（也叫**学生分布**，因戈塞特以"Student"笔名发表），记作 $T \sim t(n)$。

### 3.3 密度函数

$$f(x) = \frac{\Gamma\left(\frac{n+1}{2}\right)}{\sqrt{n\pi}\,\Gamma\left(\frac{n}{2}\right)}\left(1 + \frac{x^2}{n}\right)^{-(n+1)/2}, \quad -\infty < x < +\infty$$

这个密度长得像正态但**尾巴更厚**：因为分母里的 $\chi^2$ 会随机波动，极端值更容易出现。

### 3.4 性质

1. **对称性**：$t$ 分布关于 $x = 0$ 对称（这是由 $X$ 的对称性继承来的）。

2. **期望与方差**：
   - 当 $n > 1$ 时，$E(T) = 0$（$n = 1$ 时是柯西分布，期望不存在）；
   - 当 $n > 2$ 时，$D(T) = \dfrac{n}{n-2}$（方差比 1 大，印证"尾巴厚"）。

3. **极限行为**：当 $n \to \infty$ 时，$t(n) \to N(0, 1)$。工程上常以 $n \geq 30$ 作为"$t$ 近似正态"的经验界限。

4. **与样本均值的关系**（最重要的一条）：设 $X_1, \cdots, X_n \sim N(\mu, \sigma^2)$，$\sigma$ 未知，则

$$T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$$

这条定理是 $\sigma$ 未知时均值推断的"主引擎"，下一篇文章《正态总体的抽样分布》会给出完整推导。

5. **分位数**：$t_\alpha(n)$ 满足 $P(t(n) > t_\alpha(n)) = \alpha$。由对称性：$t_{1-\alpha}(n) = -t_\alpha(n)$。查表时只给正数表即可。

## 4. F 分布：两方差的比较器

### 4.1 直观理解

要判断"甲机床和乙机床谁更稳定"，就是比较 $\sigma_1^2$ 与 $\sigma_2^2$。用样本方差的比值 $\dfrac{S_1^2}{S_2^2}$ 作依据，其分布就是 $F$ 分布。

### 4.2 定义

设 $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，且 $U$ 与 $V$ 独立，则

$$F = \frac{U/n_1}{V/n_2}$$

服从自由度为 $(n_1, n_2)$ 的 **$F$ 分布**，记作 $F \sim F(n_1, n_2)$。$n_1$ 称第一自由度（分子自由度），$n_2$ 称第二自由度（分母自由度）——**顺序不能颠倒**。

### 4.3 密度函数

$$f(x) = \begin{cases} \dfrac{\Gamma\left(\frac{n_1+n_2}{2}\right)}{\Gamma\left(\frac{n_1}{2}\right)\Gamma\left(\frac{n_2}{2}\right)} \left(\frac{n_1}{n_2}\right)^{n_1/2} x^{n_1/2 - 1} \left(1 + \frac{n_1}{n_2}x\right)^{-(n_1+n_2)/2}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

$F$ 变量恒非负，密度右偏。

### 4.4 性质

1. **期望与方差**：
   - 当 $n_2 > 2$ 时，$E(F) = \dfrac{n_2}{n_2 - 2}$（注意期望由**第二自由度**决定）；
   - 当 $n_2 > 4$ 时，$D(F) = \dfrac{2n_2^2(n_1 + n_2 - 2)}{n_1(n_2 - 2)^2(n_2 - 4)}$。

2. **倒数关系**（查表的"后门钥匙"）：若 $F \sim F(n_1, n_2)$，则 $\dfrac{1}{F} \sim F(n_2, n_1)$。由此得到分位数互换公式：

$$F_{1-\alpha}(n_1, n_2) = \frac{1}{F_\alpha(n_2, n_1)}$$

很多 $F$ 分布表只给 $\alpha$ 较小的上分位数，靠这条公式可以求出左侧分位数。

3. **与 $t$ 分布的关系**：若 $T \sim t(n)$，则 $T^2 \sim F(1, n)$。这条关系让"均值检验"与"方差检验"在图谱上连通。

4. **与样本方差比的关系**：设 $X_1, \cdots, X_{n_1} \sim N(\mu_1, \sigma_1^2)$，$Y_1, \cdots, Y_{n_2} \sim N(\mu_2, \sigma_2^2)$，两样本独立，则

$$F = \frac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(n_1 - 1, n_2 - 1)$$

特别地，当 $\sigma_1^2 = \sigma_2^2$ 时，$F = \dfrac{S_1^2}{S_2^2} \sim F(n_1 - 1, n_2 - 1)$——这就是 $F$ 检验（方差齐性检验）的统计量。

5. **分位数**：$F_\alpha(n_1, n_2)$ 满足 $P(F(n_1, n_2) > F_\alpha(n_1, n_2)) = \alpha$。

## 5. 三大分布的关系总览

### 5.1 生成关系图谱

| 起点 | 运算 | 结果 | 记忆口诀 |
| --- | --- | --- | --- |
| $Z_1, \cdots, Z_n \sim N(0,1)$ i.i.d. | 平方求和 | $\chi^2(n)$ | 平方和出卡方 |
| $Z \sim N(0,1)$，$Y \sim \chi^2(n)$，独立 | $T = \dfrac{Z}{\sqrt{Y/n}}$ | $t(n)$ | 正态除卡方出 t |
| $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$，独立 | $F = \dfrac{U/n_1}{V/n_2}$ | $F(n_1, n_2)$ | 双卡方比值出 F |
| $T \sim t(n)$ | $T^2$ | $F(1, n)$ | t 平方变 F |

### 5.2 查表要点

- $\chi^2$、$t$、$F$ 表给出的都是**上分位数**（右侧尾部面积等于 $\alpha$）。
- $t$ 表利用对称性：$t_{1-\alpha}(n) = -t_\alpha(n)$。
- $F$ 表利用倒数关系：$F_{1-\alpha}(n_1, n_2) = \dfrac{1}{F_\alpha(n_2, n_1)}$。
- $n \geq 45$ 时 $\chi^2$ 可用近似公式 $\chi^2_\alpha(n) \approx \dfrac{1}{2}(z_\alpha + \sqrt{2n-1})^2$ 估算。

## 6. 完整例题

### 例题 1：识别统计量的分布

设 $X_1, \cdots, X_{10}$ 为来自 $N(0, 1)$ 的样本，求 $\sum_{i=1}^{10} X_i^2$ 的分布，并求 $P\left(\sum_{i=1}^{10} X_i^2 > 18.307\right)$。

**解**：

由定义，$\sum_{i=1}^{10} X_i^2 \sim \chi^2(10)$（10 个独立标准正态平方和）。

查 $\chi^2$ 分布表：$\chi^2_{0.05}(10) = 18.307$，即 $P(\chi^2(10) > 18.307) = 0.05$。

$$P\left(\sum_{i=1}^{10} X_i^2 > 18.307\right) = 0.05$$

### 例题 2：用生成关系构造 t 统计量

设 $X_1, X_2, X_3$ 为来自 $N(0, 1)$ 的样本，证明 $Y = \dfrac{X_1}{\sqrt{(X_2^2 + X_3^2)/2}} \sim t(2)$。

**解**：

$X_1 \sim N(0, 1)$（分子是标准正态）；$X_2^2 + X_3^2 \sim \chi^2(2)$（两个标准正态平方和）；且 $X_1$ 与 $(X_2, X_3)$ 独立，所以 $X_1$ 与 $X_2^2 + X_3^2$ 独立。

对照 $t$ 分布定义 $T = \dfrac{X}{\sqrt{Y/n}}$（$X \sim N(0,1)$，$Y \sim \chi^2(n)$，$X$ 与 $Y$ 独立），取 $X = X_1$，$Y = X_2^2 + X_3^2$，$n = 2$，恰好满足全部条件：

$$Y = \frac{X_1}{\sqrt{(X_2^2 + X_3^2)/2}} \sim t(2)$$

### 例题 3：用倒数关系查 F 分布表

设 $F \sim F(8, 6)$，求 $c$ 使得 $P(F < c) = 0.95$。

**解**：

$P(F < c) = 0.95$ 等价于 $P(F \geq c) = 0.05$，即 $c = F_{0.05}(8, 6)$。

若手头表上没有 $F_{0.05}(8, 6)$，可用倒数关系：

$$c = F_{0.05}(8, 6) = \frac{1}{F_{0.95}(6, 8)} = \frac{1}{1 / F_{0.05}(8, 6)}$$

此式自指，实际查表做法是：先查 $F_{0.05}(6, 8)$（若表中有），再用 $F_{0.95}(8,6) = 1/F_{0.05}(6,8)$ 求左侧分位数。工程实践中常见形式为：

$$F_{1-\alpha}(n_1, n_2) = \frac{1}{F_\alpha(n_2, n_1)}$$

例如求 $F_{0.95}(8, 6)$，查表得 $F_{0.05}(6, 8) = 3.58$，则 $F_{0.95}(8, 6) = 1/3.58 \approx 0.279$。

## 7. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 自由度错乱 | 用 $\chi^2(n)$ 而非 $\chi^2(n-1)$ 描述 $\dfrac{(n-1)S^2}{\sigma^2}$ | 忘记 $\sum (X_i - \bar{X})^2$ 有一个线性约束 | 记住"样本方差配 $n-1$"，因为 $\bar{X}$ 消耗了一个自由度 |
| F 顺序颠倒 | 把 $F(n_1, n_2)$ 写成 $F(n_2, n_1)$ | 混淆分子/分母自由度 | 第一自由度永远是分子的 $\chi^2$ 自由度，分子是谁先写谁 |
| 混淆分位数方向 | $\chi^2$ 区间估计用同一个分位数 | 不知道 $\chi^2$ 不对称 | 双侧要分别用 $\chi^2_{1-\alpha/2}$ 和 $\chi^2_{\alpha/2}$，且 $\chi^2_{1-\alpha/2} < \chi^2_{\alpha/2}$（右侧尾更细长，上分位数更大） |
| 忘记独立性 | 直接用两个不独立的变量构造 $t$ 或 $F$ | 定义要求分子分母独立 | 构造统计量前先确认独立性，正态样本中 $\bar{X}$ 与 $S^2$ 独立是常用"免费午餐" |
| 尾部判断错误 | 认为 $t$ 分布与正态完全一样 | 忽略 $t$ 尾部更厚 | $t$ 的密度在中部更矮、尾部更高；相同分位数下 $t_\alpha(n) > z_\alpha$（$n$ 小时更明显） |
| 查表用错 $\alpha$ | 双侧检验用 $t_\alpha$ 而非 $t_{\alpha/2}$ | 把单侧面积当成双侧 | 双侧拒绝域尾部总面积为 $\alpha$，每侧 $\alpha/2$，故用 $t_{\alpha/2}$ |

## 8. 实战练习

**练习 1（定义验证）**：设 $X_1, \cdots, X_8 \sim N(0, 4)$，求 $a$ 使 $P\left(\sum_{i=1}^8 X_i^2 > a\right) = 0.05$。

**提示**：$\dfrac{X_i}{2} \sim N(0,1)$，所以 $\dfrac{1}{4}\sum X_i^2 \sim \chi^2(8)$。

**参考答案要点**：$\dfrac{a}{4} = \chi^2_{0.05}(8) = 15.507$，故 $a = 62.028$。

**练习 2（t 分布性质）**：设 $T \sim t(10)$，求 $P(|T| < 1.812)$。

**提示**：利用对称性 $P(|T| < c) = 1 - 2\alpha$，其中 $t_\alpha(10) = c$。

**参考答案要点**：$t_{0.05}(10) = 1.812$，故 $P(|T| < 1.812) = 1 - 2 \times 0.05 = 0.90$。

**练习 3（F 分布构造）**：设 $X_1, \cdots, X_5 \sim N(0, \sigma_1^2)$，$Y_1, \cdots, Y_6 \sim N(0, \sigma_2^2)$，两样本独立。求 $\dfrac{\sum X_i^2 / (5\sigma_1^2)}{\sum Y_j^2 / (6\sigma_2^2)}$ 的分布。

**提示**：$\dfrac{\sum X_i^2}{\sigma_1^2} \sim \chi^2(5)$，$\dfrac{\sum Y_j^2}{\sigma_2^2} \sim \chi^2(6)$。

**参考答案要点**：该统计量形如 $\dfrac{\chi^2(5)/5}{\chi^2(6)/6} \sim F(5, 6)$。

**练习 4（可加性）**：设 $W_1 \sim \chi^2(4)$，$W_2 \sim \chi^2(6)$ 独立，求 $E(W_1 + W_2)$、$D(W_1 + W_2)$，并写出 $W_1 + W_2$ 的分布。

**提示**：$E(\chi^2(n)) = n$，$D(\chi^2(n)) = 2n$。

**参考答案要点**：$E = 4 + 6 = 10$，$D = 8 + 12 = 20$，$W_1 + W_2 \sim \chi^2(10)$。

**练习 5（综合应用）**：设 $X_1, \cdots, X_{16} \sim N(\mu, \sigma^2)$，$S^2$ 为样本方差。求 $P\left(\dfrac{S^2}{\sigma^2} > 2\right)$ 并说明用到了哪条定理。

**提示**：$\dfrac{15S^2}{\sigma^2} \sim \chi^2(15)$。

**参考答案要点**：$P\left(\dfrac{S^2}{\sigma^2} > 2\right) = P(\chi^2(15) > 30)$。查表 $\chi^2_{0.025}(15) = 27.488$，$\chi^2_{0.01}(15) = 30.578$，故概率介于 0.01 与 0.025 之间（约 0.011）。用到的定理：正态总体样本方差与 $\chi^2$ 分布的关系。

## 9. 一句话记忆

**三大分布同源于标准正态：平方和出 $\chi^2$，正态除卡方出 $t$，双卡方比值出 $F$；碰到方差找 $\chi^2$ 与 $F$，均值且 $\sigma$ 未知找 $t$。**
