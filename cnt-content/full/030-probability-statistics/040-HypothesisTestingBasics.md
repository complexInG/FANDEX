## 0. 法庭审判：假设检验的"母本"

法理上有两个铁律：

1. **无罪推定**：开庭前默认被告无罪（$H_0$ 成立），由控方举证；
2. **证据不足不能定罪**：只有当证据"足够强"（超出合理怀疑）才能判有罪。

假设检验与法庭审判一一对应：

| 法庭审判 | 假设检验 |
| --- | --- |
| 默认被告无罪 | 原假设 $H_0$（默认成立） |
| 控方主张有罪 | 备择假设 $H_1$（需要证据支持） |
| "超出合理怀疑"的证据标准 | 显著性水平 $\alpha$（如 5%） |
| 证据足够强，判有罪 | 拒绝 $H_0$ |
| 证据不足，判无罪 | 不拒绝 $H_0$（≠证明无罪） |
| 冤枉好人（误判） | 第一类错误（弃真） |
| 放过坏人（漏判） | 第二类错误（取伪） |

**注意最后两行**：判"无罪"不等于"证明无罪"，只是"证据不足"；统计上"不拒绝 $H_0$"也不等于"接受 $H_0$"，只是"证据不足"。

本文用**思想驱动**的方式，从法庭审判这个母本出发，把假设检验的核心思想（原假设与备择假设、两类错误、显著性水平、检验统计量与拒绝域、P 值、完整步骤）逐层讲透。这是后续所有检验（$Z$、$t$、$\chi^2$、$F$）的"思想总纲"。

## 1. 统计假设与原假设/备择假设

### 1.1 统计假设

**统计假设**是关于总体分布中未知参数或分布形式的陈述。

- **参数假设**：关于参数的假设，如 $H: \mu = \mu_0$、$H: \sigma^2 = \sigma_0^2$；
- **非参数假设**：关于分布形式的假设，如 $H: X \sim N(\mu, \sigma^2)$。

### 1.2 原假设与备择假设

- **原假设（零假设）$H_0$**：需要检验的假设，通常表示"没有效果""没有差异""没有超标"——对应"无罪"；
- **备择假设（对立假设）$H_1$（或 $H_A$）**：与原假设对立的假设，通常表示"有效果""有差异""超标了"——对应"有罪"。

### 1.3 三种检验形式

| 检验类型 | $H_0$ | $H_1$ | 拒绝域形态 | 适用场景 |
| --- | --- | --- | --- | --- |
| 双侧检验 | $\mu = \mu_0$ | $\mu \neq \mu_0$ | 两侧尾巴 | 只关心"是否等于" |
| 右侧检验 | $\mu \leq \mu_0$ | $\mu > \mu_0$ | 右侧尾巴 | 关心"是否超上限" |
| 左侧检验 | $\mu \geq \mu_0$ | $\mu < \mu_0$ | 左侧尾巴 | 关心"是否低于下限" |

**怎么定 $H_0$ 和 $H_1$？** 实践口诀：**把"想要证明的结论"放在 $H_1$**（因为拒绝 $H_0$ 才是有力结论）；把"默认状态、现状"放在 $H_0$。比如"新工艺降低了不合格率"——想证明"降低"是 $H_1$，默认"没降低"是 $H_0$。

## 2. 两类错误：冤枉好人与放过坏人

### 2.1 定义

| 决策 \ 真相 | $H_0$ 为真 | $H_0$ 为假 |
| --- | --- | --- |
| **拒绝 $H_0$** | **第一类错误**（弃真，概率 $\alpha$） | 正确决策 |
| **不拒绝 $H_0$** | 正确决策 | **第二类错误**（取伪，概率 $\beta$） |

- **第一类错误（弃真错误）**：$H_0$ 为真时拒绝 $H_0$——"冤枉好人"。
- **第二类错误（取伪错误）**：$H_0$ 为假时不拒绝 $H_0$——"放过坏人"。

### 2.2 显著性水平

$$\alpha = P(\text{拒绝 } H_0 \mid H_0 \text{ 为真})$$

$\alpha$ 称为**显著性水平**，是"允许冤枉好人的最大概率"，通常取 $\alpha = 0.05$ 或 $\alpha = 0.01$。$\alpha$ 越小，标准越严苛（如法庭要求"铁证"）。

### 2.3 两类错误的关系

- 样本量固定时，减小 $\alpha$ 会增大 $\beta$（标准严了，更容易漏判），反之亦然；
- **同时减小 $\alpha$ 和 $\beta$ 的唯一方法：增大样本量 $n$**（证据越多，既不容易冤枉也不容易漏判）；
- **Neyman-Pearson 原则**：在控制 $\alpha$ 不超过给定值的条件下，使 $\beta$ 尽可能小（先保护"无辜者"）。

### 2.4 检验的功效

$$1 - \beta = P(\text{拒绝 } H_0 \mid H_1 \text{ 为真})$$

称为检验的**功效**（或**势**）。功效越大，"坏人被抓住"的能力越强。功效分析（power analysis）在实验设计中用于确定样本量。

## 3. 检验统计量与拒绝域

### 3.1 检验统计量

用于检验假设的统计量称为**检验统计量**，通常选择在 $H_0$ 成立时分布已知的枢轴量（如 $Z$、$t$、$\chi^2$、$F$）。

### 3.2 拒绝域

使 $H_0$ 被拒绝的检验统计量取值范围称为**拒绝域**（临界域），记作 $W$：

- 双侧检验：$W = \{|T| > c\}$；
- 右侧检验：$W = \{T > c\}$；
- 左侧检验：$W = \{T < c\}$。

拒绝域的边界值称为**临界值**，由 $\alpha$ 与检验统计量的分布确定（如 $z_{\alpha/2}$、$t_\alpha(n-1)$）。

### 3.3 完整例题：构造拒绝域

**例题**：设 $X_1, \cdots, X_{25} \sim N(\mu, 4)$，检验 $H_0: \mu = 50$，$H_1: \mu \neq 50$，$\alpha = 0.05$。写出拒绝域。

**解**：$\sigma = 2$ 已知，检验统计量 $Z = \dfrac{\bar{X} - 50}{2/\sqrt{25}} = \dfrac{\bar{X} - 50}{0.4}$。

双侧检验，临界值 $z_{0.025} = 1.96$：

$$W = \{|Z| > 1.96\} = \left\{\left|\frac{\bar{X} - 50}{0.4}\right| > 1.96\right\}$$

等价地，$W = \{\bar{X} < 49.216 \text{ 或 } \bar{X} > 50.784\}$。即：样本均值偏离 50 超过 0.784 个单位就拒绝 $H_0$。

## 4. P 值：证据强度的"连续刻度"

### 4.1 定义

**P 值**是在 $H_0$ 成立的条件下，检验统计量取到**观测值及更极端值**的概率：

$$\text{P 值} = P(\text{检验统计量} \geq \text{观测值} \mid H_0)$$

P 值把"证据强度"从"是/否"（拒绝域判断）细化为连续数值：P 值越小，证据越强。

### 4.2 P 值判断规则

- 若 $\text{P 值} \leq \alpha$，拒绝 $H_0$（证据足够强）；
- 若 $\text{P 值} > \alpha$，不拒绝 $H_0$（证据不足）。

**注意**：拒绝域法和 P 值法是**等价**的（同一套逻辑的两个表述），只是 P 值还给出了"证据有多强"的量化信息。

### 4.3 P 值的经验解读

| P 值区间 | 证据强度 | 通俗说法 |
| --- | --- | --- |
| $P < 0.01$ | 非常显著 | 证据很强 |
| $0.01 \leq P < 0.05$ | 显著 | 证据较强 |
| $0.05 \leq P < 0.10$ | 边缘显著 | 证据较弱 |
| $P \geq 0.10$ | 不显著 | 证据不足 |

## 5. 假设检验的标准七步

1. **提出假设**：根据问题建立 $H_0$ 和 $H_1$（想证明的放 $H_1$）；
2. **选择检验统计量**：确定在 $H_0$ 下分布已知的统计量（$Z$/$t$/$\chi^2$/$F$）；
3. **确定显著性水平**：通常取 $\alpha = 0.05$；
4. **计算检验统计量的观测值**：代入样本数据；
5. **确定拒绝域**：由 $\alpha$ 和分布分位数确定临界值；
6. **做出决策**：比较统计量观测值与临界值（或 P 值与 $\alpha$）；
7. **得出结论**：回到原问题用业务语言解释结果（如"拒绝 $H_0$，认为超标"）。

## 6. 完整例题：一套标准的假设检验

**例题**：某厂声称其生产的灯泡平均寿命不低于 1000 小时。质检员抽查 25 只，测得 $\bar{x} = 995$ 小时。已知寿命 $X \sim N(\mu, 100)$。在 $\alpha = 0.05$ 下检验厂家声明是否可信。

**解**：

**第 1 步（提假设）**：想证明"不达标"（$\mu < 1000$），放 $H_1$；默认"达标"放 $H_0$：

$$H_0: \mu \geq 1000, \quad H_1: \mu < 1000 \quad \text{（左侧检验）}$$

**第 2 步（选统计量）**：$\sigma = 10$ 已知，用 $Z = \dfrac{\bar{X} - 1000}{10/\sqrt{25}}$，$H_0$ 下 $Z \sim N(0, 1)$。

**第 3 步（定 $\alpha$）**：$\alpha = 0.05$。

**第 4 步（算观测值）**：

$$Z = \frac{995 - 1000}{10/5} = \frac{-5}{2} = -2.5$$

**第 5 步（定拒绝域）**：左侧检验，$z_{0.05} = 1.645$，拒绝域 $W = \{Z < -1.645\}$。

**第 6 步（决策）**：$Z = -2.5 < -1.645$，落入拒绝域，**拒绝 $H_0$**。

**第 7 步（结论）**：有显著证据表明该厂灯泡平均寿命低于 1000 小时，声明不可信。

## 7. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| $H_0$/$H_1$ 放反 | 把想证明的放 $H_0$ | 不知"拒绝才是有力结论" | 想证明的放 $H_1$；默认/现状放 $H_0$ |
| "不拒绝"当"接受" | 结论写成"接受 $H_0$，没有差异" | 混淆证据不足与证据支持 | "不拒绝 $H_0$"只说明证据不足，不等于证明 $H_0$ 正确 |
| 双侧用单侧分位点 | 双侧检验用 $z_{0.05}$ 而非 $z_{0.025}$ | 单双尾混淆 | 双侧 $\alpha$ 分两半，用 $z_{\alpha/2}$ |
| 忽略检验前提 | 小样本非正态仍用 $Z$ | 忘了适用条件 | $Z$ 检验需 $\sigma$ 已知或 $n$ 大；小样本 $\sigma$ 未知用 $t$ |
| 混淆两类错误 | 把 $\alpha$ 当"$H_1$ 为真时拒绝 $H_0$ 的概率" | 定义记反 | $\alpha$ = 弃真概率（$H_0$ 真时拒）；$\beta$ = 取伪概率（$H_0$ 假时不拒）；功效 $= 1 - \beta$ |
| 统计显著当实际显著 | $n$ 很大时微小差异也显著 | 忽略效应量 | 大样本下任何小差异都会显著；同时报告效应量与置信区间 |
| 多重检验不校正 | 做 20 次检验用同一 $\alpha$ | 每检验都有 $\alpha$ 概率出错 | 用 Bonferroni 校正（$\alpha/m$）等方法控制总错误率 |

## 8. 实战练习

**练习 1（概念）**：判断对错并说明理由：（a）"不拒绝 $H_0$"意味着 $H_0$ 一定正确；（b）$\alpha = 0.05$ 意味着 100 次检验中约 5 次会把正确的 $H_0$ 拒绝掉（$H_0$ 真时）。

**提示**：回顾"证据不足≠证明无罪"与 $\alpha$ 的定义。

**参考答案要点**：（a）错误，只说明证据不足；（b）正确（近似），$\alpha$ 正是"$H_0$ 真时拒绝"的条件概率。

**练习 2（假设设定）**：某饮料标准净含量 500ml，质检想检验"是否不足量"。写出 $H_0$ 与 $H_1$。

**提示**：想证明"不足"（$\mu < 500$）放 $H_1$。

**参考答案要点**：$H_0: \mu \geq 500$，$H_1: \mu < 500$（左侧检验）。

**练习 3（拒绝域）**：设 $X \sim N(\mu, 9)$，$n = 36$，检验 $H_0: \mu = 30$ 对 $H_1: \mu \neq 30$，$\alpha = 0.05$。写出 $Z$ 统计量的拒绝域及等价于 $\bar{X}$ 的拒绝域。

**提示**：$z_{0.025} = 1.96$，$\bar{X}$ 的标准误为 $3/6 = 0.5$。

**参考答案要点**：$W = \{|Z| > 1.96\}$；$\bar{X}$ 域：$30 \pm 1.96 \times 0.5$，即 $\bar{X} < 29.02$ 或 $\bar{X} > 30.98$。

**练习 4（两类错误）**：沿用练习 3 的检验，若真实 $\mu = 30.5$，求 $\beta$（第二类错误概率）。

**提示**：$H_1$ 下 $\bar{X} \sim N(30.5, 0.25)$，$\beta = P(29.02 \leq \bar{X} \leq 30.98)$。

**参考答案要点**：$Z$ 变换：$\beta = \Phi\left(\dfrac{30.98 - 30.5}{0.5}\right) - \Phi\left(\dfrac{29.02 - 30.5}{0.5}\right) = \Phi(0.96) - \Phi(-2.96) \approx 0.8315 - 0.0015 = 0.83$。功效 $1 - \beta \approx 0.17$（检验力较弱，因为真实差异小）。

**练习 5（P 值）**：设 $Z = 2.1$（双侧检验），求 P 值并在 $\alpha = 0.05$ 下决策。

**提示**：P 值 $= 2P(Z > 2.1)$。

**参考答案要点**：P 值 $= 2 \times 0.0179 = 0.0358 < 0.05$，拒绝 $H_0$。

## 9. 一句话记忆

**假设检验就是"法庭审判"：无罪推定（$H_0$ 默认成立）、控方举证（证据支持 $H_1$）、超出合理怀疑（$\alpha$）才定罪（拒绝 $H_0$）；"证据不足"只说不能拒绝 $H_0$，别说"接受 $H_0$"。**
