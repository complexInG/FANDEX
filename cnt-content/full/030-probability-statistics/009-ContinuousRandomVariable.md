## 0. 秒表计时与体重秤

请想象两个场景：

- 用秒表给一位短跑运动员计时，成绩可能是 9.81 秒、9.812 秒、9.8117 秒……读数可以无限细分，你永远无法"穷举"所有可能值。
- 站上电子体重秤，体重可能是 65.0 kg、65.05 kg、65.052 kg……同样是连续的。

这类"取值充满某个区间、可以无限细分"的量，就是**连续型随机变量**。它与上一讲的离散型（骰子点数、呼叫次数）形成鲜明对照：离散型可以逐个点名（分布律），连续型却有不可列无穷多个可能值，无法逐一点名。

**那连续型怎么描述概率？** 答案是：别再问"恰好等于某一点的概率"（那是 0），改问"落在某个区间里的概率"，并用**概率密度**来描述"单位长度上的概率浓度"。本讲用"离散逼近连续"的极限思想把这一概念讲透——这也是理解微积分为什么进入概率论的关键一步。

## 1. 从离散到连续：极限思想的引入

### 1.1 一个思想实验：细分区间

假设我们观察"公交到站间隔时间"，先把它**离散化**：只看间隔是 0-1 分钟、1-2 分钟……还是 10-11 分钟，画一张直方图，每个柱子的高度 = 落在该区间的频率 ÷ 区间宽度。

现在把区间越切越细：0-0.5、0.5-1.0……再切：0-0.25、0.25-0.5……当区间宽度 $\Delta x \to 0$ 时，直方图的外轮廓趋向一条光滑曲线 $f(x)$。这条曲线就是**概率密度函数**：

$$P(x < X \leq x + \Delta x) \approx f(x) \cdot \Delta x \quad (\Delta x \text{ 很小})$$

**直觉**：$f(x)$ 度量的是"$x$ 附近的概率浓度"。$f(x)$ 大的地方，随机变量"挤"在那里的概率高；$f(x)$ 小的地方则稀疏。

### 1.2 由密度到概率：积分

把"浓度 × 宽度"加起来（微积分），就得到区间概率：

$$P(a < X \leq b) = \int_a^b f(x) \, dx$$

**这就是连续型概率的全部秘密：概率 = 密度曲线下的面积。** 上一讲分布律的"求和"，在这里变成了"积分"；$\sum p_k = 1$ 变成了 $\int_{-\infty}^{+\infty} f(x) \, dx = 1$。

## 2. 概率密度函数的定义与性质

### 2.1 定义

设 $F(x)$ 为随机变量 $X$ 的分布函数，若存在非负可积函数 $f(x)$，使得对任意实数 $x$：

$$F(x) = \int_{-\infty}^{x} f(t) \, dt$$

则称 $X$ 为**连续型随机变量**，$f(x)$ 为 $X$ 的**概率密度函数**（简称**密度**）。

### 2.2 密度函数的五个性质

1. **非负性**：$f(x) \geq 0$；
2. **规范性**：$\displaystyle\int_{-\infty}^{+\infty} f(x) \, dx = 1$（密度曲线下总面积为 1）；
3. **区间概率**：$P(a < X \leq b) = \displaystyle\int_a^b f(x) \, dx$；
4. **单点概率为零**：$P(X = x_0) = 0$（对任意 $x_0$）；
5. **密度与分布函数**：在 $f(x)$ 的连续点处 $F'(x) = f(x)$。

### 2.3 连续型的三个"颠覆认知"结论

1. $P(X = x_0) = 0$，但事件 $\{X = x_0\}$ 不是不可能事件——与 003 讲几何概型的结论一致；
2. 端点无关：$P(a < X < b) = P(a \leq X < b) = P(a < X \leq b) = P(a \leq X \leq b)$（端点概率为 0）；
3. $f(x)$ 的值**不是**概率，可以大于 1（如 $f(x) = 2$ 在小区间上），只有面积才是概率。

## 3. 均匀分布 $U(a, b)$：最"平等"的分布

### 3.1 定义

$$f(x) = \begin{cases} \dfrac{1}{b-a}, & a \leq x \leq b \\ 0, & \text{其他} \end{cases}, \qquad X \sim U(a, b)$$

### 3.2 分布函数

$$F(x) = \begin{cases} 0, & x < a \\ \dfrac{x - a}{b - a}, & a \leq x < b \\ 1, & x \geq b \end{cases}$$

### 3.3 性质与应用

- 期望 $E(X) = \dfrac{a+b}{2}$，方差 $D(X) = \dfrac{(b-a)^2}{12}$；
- 等长度子区间概率相等（这正是几何概型的"均匀"）；
- 标准化：$Y = \dfrac{X - a}{b - a} \sim U(0, 1)$。

**应用**：计算机伪随机数生成（`random.uniform`）、舍入误差建模、无先验信息时的均匀假设。

## 4. 指数分布 $\text{Exp}(\lambda)$：等待时间的分布

### 4.1 定义

$$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\ 0, & x \leq 0 \end{cases}, \qquad X \sim \text{Exp}(\lambda)$$

### 4.2 分布函数与存活概率

$$F(x) = \begin{cases} 1 - e^{-\lambda x}, & x > 0 \\ 0, & x \leq 0 \end{cases}$$

"存活超过 $t$"（寿命大于 $t$）的概率：

$$P(X > t) = 1 - F(t) = e^{-\lambda t}$$

### 4.3 性质

1. 期望 $E(X) = \dfrac{1}{\lambda}$，方差 $D(X) = \dfrac{1}{\lambda^2}$；
2. **无记忆性**：对任意 $s, t > 0$，

$$P(X > s + t \mid X > s) = P(X > t)$$

**证明**：

$$P(X > s + t \mid X > s) = \frac{P(X > s+t)}{P(X > s)} = \frac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X > t)$$

**含义**：元件已用了 $s$ 小时，再坚持 $t$ 小时的概率，和全新时一样——指数分布"没有记忆"，不会老化。它是唯一具有无记忆性的连续型分布。

3. **与泊松过程的关系**：泊松过程中相邻两次事件（如呼叫）的时间间隔服从 $\text{Exp}(\lambda)$。

## 5. 正态分布 $N(\mu, \sigma^2)$：概率论的"主角"

### 5.1 定义

$$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}, \quad -\infty < x < +\infty$$

称 $X$ 服从参数 $\mu, \sigma^2$ 的**正态分布**，记作 $X \sim N(\mu, \sigma^2)$。

### 5.2 密度曲线的五个特征

1. 关于 $x = \mu$ **对称**（钟形）；
2. 在 $x = \mu$ 处取最大值 $f(\mu) = \dfrac{1}{\sqrt{2\pi}\sigma}$；
3. 拐点在 $x = \mu \pm \sigma$；
4. $x$ 轴为水平渐近线；
5. $\mu$ 决定**位置**（左右平移），$\sigma$ 决定**胖瘦**（$\sigma$ 大则矮胖、$\sigma$ 小则瘦高）。

### 5.3 标准正态分布

$\mu = 0, \sigma = 1$ 时为**标准正态分布** $N(0, 1)$，密度与分布函数记为：

$$\varphi(x) = \frac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}, \qquad \Phi(x) = \int_{-\infty}^{x} \varphi(t) \, dt$$

**性质**：$\Phi(-x) = 1 - \Phi(x)$（对称性）；$\Phi(0) = 0.5$；$P(|X| \leq a) = 2\Phi(a) - 1$。

### 5.4 标准化：一切正态计算的钥匙

若 $X \sim N(\mu, \sigma^2)$，则

$$Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$$

于是任意正态概率都能化为标准正态查表：

$$P(a < X < b) = \Phi\left(\frac{b - \mu}{\sigma}\right) - \Phi\left(\frac{a - \mu}{\sigma}\right)$$

### 5.6 正态分布的性质

1. $E(X) = \mu$，$D(X) = \sigma^2$；
2. 线性变换不变性：$aX + b \sim N(a\mu + b, a^2\sigma^2)$；
3. 独立正态之和仍正态：$X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$ 独立，则 $X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$；
4. **$3\sigma$ 法则**：

$$P(\mu - \sigma < X < \mu + \sigma) \approx 0.6827, \quad P(\mu \pm 2\sigma) \approx 0.9545, \quad P(\mu \pm 3\sigma) \approx 0.9973$$

### 5.7 为什么正态分布如此重要

- **中心极限定理**（028 讲）：大量独立随机因素之和近似正态——身高、考试成绩、测量误差皆如此；
- **误差理论**：测量误差通常服从正态；
- **统计推断**：$t$ 检验、置信区间等大多基于正态假设或由正态导出。

## 6. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 把 $f(x)$ 的值当作概率（甚至问 $P(X=x)=f(x)$） | 概念错误 | 混淆密度与概率 | 密度是"浓度"，只有积分（面积）才是概率；$f(x)$ 可以大于 1 |
| 2 | 忘记验证规范性 $\int f = 1$ 就求参数 | 方法错误 | 步骤缺失 | 求 $f$ 中的未知常数，必用 $\int_{-\infty}^{+\infty} f(x)dx = 1$ |
| 3 | 正态标准化方向记反：写成 $\dfrac{\mu - x}{\sigma}$ | 公式错误 | 记错标准化公式 | 统一写 $Z = \dfrac{X - \mu}{\sigma}$，标准化后再查 $\Phi$ |
| 4 | 用 $\Phi$ 求 $P(X < x)$ 时忘了 $\Phi(-z) = 1 - \Phi(z)$ | 公式错误 | 不会处理负值 | 负值一律用对称性转成正值再查表 |
| 5 | 指数分布求 $P(X > t)$ 与 $P(X \leq t)$ 混淆 | 公式错误 | 存活函数记反 | $P(X > t) = e^{-\lambda t}$，$P(X \leq t) = 1 - e^{-\lambda t}$ |
| 6 | 分不清"区间开闭无关"仍纠结 $P(a<X<b)$ 与 $P(a \leq X \leq b)$ | 概念错误 | 用离散直觉 | 连续型端点概率为 0，开闭区间概率相同，放心写 |

## 8. 一句话记忆

> **连续型随机变量不点名，只量面积：密度 $f(x)$ 是非负的"浓度函数"且总面积为 1，区间概率 = 曲线下面积，单点概率恒为 0——均匀分布讲平等，指数分布讲等待（无记忆），正态分布是万物主角（钟形、对称、$3\sigma$）。**

## 深度专题扩展

### 13.1 密度函数与核密度估计（KDE）

实践中我们不知道真实密度，只有样本数据。**核密度估计**把每个样本点"糊"一个小核（如高斯核），叠加后得到平滑密度估计——这正是本讲"直方图越切越细"思想的统计实现，也是数据可视化中分布直方图的进阶版。

### 13.2 正态分布的"国王"地位与中心极限定理

中心极限定理说：任意独立同分布随机变量的均值（标准化后）随样本量增大趋于标准正态。这就是为什么现实中的误差、成绩、测量值近似正态，也是假设检验中"正态近似"的理论依据（028、029 讲详述）。
