## 0. 抛硬币记录：从数据到分布

假设你连续抛 1000 次硬币，每次记录"正/反"。把数据整理一下，你会得到：

- 正面出现的**次数**（一个离散型随机变量，近似二项分布）；
- 连续两次正面之间的**间隔**（近似几何分布）；
- 某个"正面流"持续的时间占比（可换算成连续变量）。

同样的道理，工程师每天面对的原始数据——抽检次品数、顾客等待时间、零件尺寸偏差——本质上都是一个或多个随机变量的"观测记录"。本讲用**应用驱动**的方式，把 008-012 讲的所有工具放到真实场景里反复演练：**看到问题 → 识别随机变量 → 确定分布 → 计算概率或函数分布**。这是从"学公式"到"会建模"的最后一公里。

## 1. 离散型随机变量应用

### 例题 1：几何分布——直到命中

某射手每次命中率 0.8，独立射击直到命中为止。求射击次数 $X$ 的分布律及 $P(X \leq 3)$。

**解**：$X \sim G(0.8)$：

$$P(X = k) = 0.2^{k-1} \times 0.8, \quad k = 1, 2, 3, \cdots$$

$$P(X \leq 3) = 0.8 + 0.16 + 0.032 = 0.992$$

**解读**：前 3 次内命中的概率高达 99.2%——"首次成功"等待很少超过 3 次。

### 例题 2：泊松分布——呼叫中心

某电话交换台每分钟呼叫次数 $X \sim P(3)$，求：（1）一分钟恰好 5 次；（2）不超过 2 次。

**解**：

（1）$P(X = 5) = \dfrac{3^5 e^{-3}}{5!} = \dfrac{243 \times 0.0498}{120} \approx 0.1008$

（2）$P(X \leq 2) = e^{-3}(1 + 3 + 4.5) = 8.5e^{-3} \approx 0.4232$

**解读**：$E(X) = 3$ 说明平均每分钟 3 次；"超过平均值的观察"与"低于平均值的观察"混合出现，正是泊松过程的随机性。

### 例题 3：超几何分布——不放回质检

一批产品 100 件，其中 10 件次品。任取 5 件，求次品数 $X$ 的分布律。

**解**：$X \sim H(100, 10, 5)$：

$$P(X = k) = \frac{\binom{10}{k}\binom{90}{5-k}}{\binom{100}{5}}, \quad k = 0, 1, 2, 3, 4, 5$$

**解读**：不放回抽样用超几何；若 100 换成 10000（$N$ 大），则可用二项近似。

## 2. 连续型随机变量应用

### 例题 4：由密度求参数、概率与分布函数

设 $X$ 的密度为

$$f(x) = \begin{cases} Ax^2, & 0 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$$

求：（1）$A$；（2）$P(0.2 < X < 0.5)$；（3）$F(x)$。

**解**：

（1）$\displaystyle\int_0^1 Ax^2 \, dx = A \cdot \frac{1}{3} = 1 \implies A = 3$

（2）$P(0.2 < X < 0.5) = \displaystyle\int_{0.2}^{0.5} 3x^2 \, dx = [x^3]_{0.2}^{0.5} = 0.125 - 0.008 = 0.117$

（3）

$$F(x) = \begin{cases} 0, & x < 0 \\ x^3, & 0 \leq x < 1 \\ 1, & x \geq 1 \end{cases}$$

**解读**：三步是连续型题的"标准套餐"：参数用规范性、区间用积分、分布函数分段积。

### 例题 5：正态分布——成绩区间

设 $X \sim N(2, 9)$，求：（1）$P(X < 5)$；（2）$P(-4 < X < 8)$；（3）$P(|X| > 4)$。

**解**：$\mu = 2$，$\sigma = 3$。

（1）$P(X < 5) = \Phi\left(\dfrac{5-2}{3}\right) = \Phi(1) = 0.8413$

（2）$P(-4 < X < 8) = \Phi(2) - \Phi(-2) = 2\Phi(2) - 1 = 0.9544$

（3）$P(|X| > 4) = 1 - \Phi\left(\dfrac{4-2}{3}\right) + \Phi\left(\dfrac{-4-2}{3}\right) = 1 - \Phi(0.667) + \Phi(-2) = 1 - 0.7476 + 0.0228 = 0.2752$

**解读**：（2）直接给出 $2\sigma$ 区间概率约 95.4%，呼应 $3\sigma$ 法则；（3）是"两侧尾部"的求和，务必分段处理。

## 3. 分布函数应用

### 例题 6：由分布函数反求参数

设 $X$ 的分布函数为

$$F(x) = \begin{cases} 0, & x < 0 \\ Ax + B, & 0 \leq x < 1 \\ 1, & x \geq 1 \end{cases}$$

求 $A, B$ 及 $P(0.3 < X < 0.7)$。

**解**：由 $F(0) = 0$ 得 $B = 0$；由右连续/连续 $F(1) = 1$ 得 $A = 1$。

$$P(0.3 < X < 0.7) = F(0.7) - F(0.3) = 0.7 - 0.3 = 0.4$$

### 例题 7：由分布函数求分布律

设 $X$ 的分布函数为

$$F(x) = \begin{cases} 0, & x < -1 \\ 0.2, & -1 \leq x < 0 \\ 0.7, & 0 \leq x < 1 \\ 1, & x \geq 1 \end{cases}$$

求 $X$ 的分布律。

**解**：$X$ 离散，取值 $-1, 0, 1$（跳跃点）：

$$P(X = -1) = F(-1) - F(-1^-) = 0.2 - 0 = 0.2$$

$$P(X = 0) = F(0) - F(0^-) = 0.7 - 0.2 = 0.5$$

$$P(X = 1) = F(1) - F(1^-) = 1 - 0.7 = 0.3$$

**解读**：跳跃高度 = 概率。由 $F$ 求分布律就是"逐级减法"。

## 4. 常用分布应用

### 例题 8：指数分布与无记忆性

某元件寿命 $X$（小时）$\sim \text{Exp}(0.001)$。求：（1）寿命超 1000 小时的概率；（2）已用 500 小时后再坚持 1000 小时的概率。

**解**：

（1）$P(X > 1000) = e^{-0.001 \times 1000} = e^{-1} \approx 0.3679$

（2）无记忆性：$P(X > 1500 \mid X > 500) = P(X > 1000) = e^{-1} \approx 0.3679$

**解读**：这是"元件不老化"假设下的核心结论——无记忆性使"已用时间"不提供任何信息。

### 例题 9：二项分布反求参数

设 $X \sim B(n, p)$，且 $E(X) = 12$，$D(X) = 8$，求 $n, p$。

**解**：

$$np = 12, \quad np(1-p) = 8 \implies 1 - p = \frac{8}{12} = \frac{2}{3} \implies p = \frac{1}{3}$$

$$n = \frac{12}{1/3} = 36$$

**解读**：期望与方差是分布参数的"两个方程"——已知 $E$ 与 $D$ 可解二项分布的两个参数，这是参数估计（035 讲）矩估计思想的雏形。

## 5. 随机变量函数的分布应用

### 例题 10：均匀到指数（逆变换法）

设 $X \sim U(0, 1)$，求 $Y = -2\ln X$ 的分布。

**解**：$y > 0$ 时（$g$ 单调递减）：

$$F_Y(y) = P(-2\ln X \leq y) = P(X \geq e^{-y/2}) = 1 - e^{-y/2}$$

$$f_Y(y) = \frac{1}{2}e^{-y/2}, \quad y > 0$$

即 $Y \sim \text{Exp}\left(\dfrac{1}{2}\right)$，也即 $Y \sim \chi^2(2)$。

### 例题 11：非单调函数的平方

设 $X \sim U(-1, 2)$，求 $Y = X^2$ 的密度。

**解**：$Y \in [0, 4)$。分两段：

当 $0 \leq y < 1$：

$$F_Y(y) = P(-\sqrt{y} \leq X \leq \sqrt{y}) = \int_{-\sqrt{y}}^{\sqrt{y}} \frac{1}{3} dx = \frac{2\sqrt{y}}{3}, \quad f_Y(y) = \frac{1}{3\sqrt{y}}$$

当 $1 \leq y < 4$：左端被 $-1$ 截断（$\sqrt{y} \geq 1$）：

$$F_Y(y) = P(-1 \leq X \leq \sqrt{y}) = \frac{\sqrt{y} + 1}{3}, \quad f_Y(y) = \frac{1}{6\sqrt{y}}$$

综上：

$$f_Y(y) = \begin{cases} \dfrac{1}{3\sqrt{y}}, & 0 < y < 1 \\ \dfrac{1}{6\sqrt{y}}, & 1 \leq y < 4 \\ 0, & \text{其他} \end{cases}$$

**解读**：$g$ 不单调时必须分段；"截断"发生在 $X$ 的定义域边界处，是这类题的分段依据。

### 例题 12：正态到对数正态

设 $X \sim N(0, 1)$，求 $Y = e^X$ 的密度。

**解**：$y = e^x$ 严格递增，$x = \ln y$，$x'(y) = \dfrac{1}{y}$：

$$f_Y(y) = f_X(\ln y) \cdot \frac{1}{y} = \frac{1}{y\sqrt{2\pi}} e^{-\frac{(\ln y)^2}{2}}, \quad y > 0$$

即**对数正态分布**——金融资产价格的标准模型。

## 6. 综合题：多工具嵌套

### 例题 13：对称双指数分布的绝对值

设 $X$ 的密度为 $f(x) = \dfrac{1}{2}e^{-|x|}$（$-\infty < x < +\infty$），求 $Y = |X|$ 的密度。

**解**：$y > 0$ 时（对称折叠）：

$$F_Y(y) = P(|X| \leq y) = \int_{-y}^{y} \frac{1}{2}e^{-|x|} dx = 2\int_0^y \frac{1}{2}e^{-x} dx = 1 - e^{-y}$$

$$f_Y(y) = e^{-y}, \quad y > 0$$

即 $Y \sim \text{Exp}(1)$。**解读**：拉普拉斯分布的绝对值是指数分布——"折叠"让密度翻倍、尾部只剩正半轴。

### 例题 14：$U(0, \pi)$ 的正弦

设 $X \sim U(0, \pi)$，求 $Y = \sin X$ 的密度。

**解**：$Y \in [0, 1]$。当 $0 < y < 1$ 时，$\sin x \leq y$ 的解为 $x \in [0, \arcsin y] \cup [\pi - \arcsin y, \pi]$：

$$F_Y(y) = P(\sin X \leq y) = \frac{\arcsin y + \arcsin y}{\pi} = \frac{2\arcsin y}{\pi}$$

$$f_Y(y) = \frac{2}{\pi\sqrt{1 - y^2}}, \quad 0 < y < 1$$

**解读**：$g$ 在 $(0, \pi)$ 上先增后减，必须拆两段；正弦函数在 $y$ 值处对应两个 $x$ 区间，是"多对一"的典型。

### 例题 15：标准化证明

证明：$X \sim N(\mu, \sigma^2)$ 时 $Y = \dfrac{X - \mu}{\sigma} \sim N(0, 1)$。

**证明**：$y = \dfrac{x - \mu}{\sigma}$ 严格递增，$x = \sigma y + \mu$，$|x'(y)| = \sigma$：

$$f_Y(y) = f_X(\sigma y + \mu) \cdot \sigma = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{y^2}{2}} \cdot \sigma = \varphi(y)$$

## 7. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 实际问题中识别不出随机变量与分布 | 建模错误 | 缺少"翻译"训练 | 抓关键词：命中/成功→伯努利族，等待→指数/几何，尺寸→正态 |
| 2 | 期望方差当已知条件用时公式记错 | 公式错误 | 各分布特征量混淆 | 二项 $E=np$、泊松 $E=\lambda$、指数 $E=1/\lambda$，对照 011 讲总览表 |
| 3 | 非单调变换不分段（如 $\sin X$ 只取一段） | 方法错误 | 忽视值域重叠 | 画 $g$ 的图像，标出单调区间与值域分段点 |
| 4 | 由分布函数求分布律时漏掉"跳跃高度" | 概念错误 | 忘了 $P(X=x)=F(x)-F(x^-)$ | 找跳跃点，逐点算高度，并验证总概率为 1 |
| 5 | 正态两侧尾部概率只算一边 | 计算错误 | 处理 $P(\|X\|>a)$ 不分段 | $P(|X|>a) = P(X>a) + P(X<-a)$，分别标准化 |
| 6 | 把"不放回"当成"放回"用二项分布 | 建模错误 | 忽略抽样方式 | 不放回小总体→超几何；$N$ 大（如 >20n）才可近似二项 |

## 8. 实战练习

### 练习 1（入门）：二项分布

某设备每日故障概率 0.1，独立运行 7 天，求恰好 1 天故障的概率。

**提示**：$X \sim B(7, 0.1)$。

**参考答案要点**：$P(X = 1) = \dbinom{7}{1}(0.1)(0.9)^6 = 7 \times 0.1 \times 0.5314 = 0.372$。

### 练习 2（入门）：泊松分布

书店每小时卖出 4 本书（$X \sim P(4)$），求一小时内卖出至少 6 本的概率。

**提示**：$P(X \geq 6) = 1 - P(X \leq 5)$。

**参考答案要点**：$P(X \leq 5) = e^{-4}(1 + 4 + 8 + 10.67 + 10.67 + 8.53) = 42.87e^{-4} \approx 0.785$；$P(X \geq 6) \approx 0.215$。

### 练习 3（进阶）：连续型密度

设 $f(x) = \begin{cases} c(1 - x^2), & -1 \leq x \leq 1 \\ 0, & \text{其他} \end{cases}$，求 $c$ 与 $P\left(|X| < \dfrac{1}{2}\right)$。

**提示**：$\int_{-1}^{1} (1-x^2)dx = \dfrac{4}{3}$。

**参考答案要点**：$c \cdot \dfrac{4}{3} = 1 \implies c = \dfrac{3}{4}$；$P\left(|X| < \dfrac{1}{2}\right) = \dfrac{3}{4} \times 2\int_0^{1/2}(1-x^2)dx = \dfrac{3}{4}\left[\dfrac{1}{2} - \dfrac{1}{24}\right] \times 2 = \dfrac{3}{4} \times \dfrac{11}{12} = \dfrac{11}{16}$。

### 练习 4（进阶）：正态与规格

某饮料灌装量 $X \sim N(500, 25)$（ml），国家规定净含量不低于 490 ml 为合格，求合格率。

**提示**：$\sigma = 5$，$P(X \geq 490) = 1 - \Phi\left(\dfrac{490 - 500}{5}\right)$。

**参考答案要点**：$P(X \geq 490) = 1 - \Phi(-2) = \Phi(2) = 0.9772$。合格率约 97.72%。

### 练习 5（挑战）：综合设计

设计一个实际场景，同时用到"二项分布求概率"与"随机变量函数的分布"，并用 Python 模拟验证其中一个结果。

**提示**：例如"抽 20 件产品（次品率 0.1），设 $Y$ 为次品数，求 $Z = Y^2$ 的期望（可先由二项期望方差推 $E(Y^2)$ 再模拟）"。

**参考答案要点**：$Y \sim B(20, 0.1)$，$E(Y) = 2$，$D(Y) = 1.8$，故 $E(Y^2) = D(Y) + [E(Y)]^2 = 1.8 + 4 = 5.8$；用 Python 模拟 10 万次抽样，$E(Z)$ 应接近 5.8。此题串起"分布 → 数字特征 → 变换"，是后续期望方差的预演。

## 9. 一句话记忆

> **应用题的解题链是"读场景 → 认随机变量 → 定分布 → 选公式"：命中成功找伯努利家族，等待时间找指数/几何，尺寸误差找正态；非单调变换分段处理，放回不放回决定二项还是超几何。**

## 深度专题扩展

### 13.1 从分布到数据生成：模拟的工程价值

本讲所有分布都可以用 `numpy.random` / `random` 模拟（`binomial`、`poisson`、`exponential`、`normal`）。模拟的价值在于：当解析计算过于复杂（如多层条件、复杂变换）时，用大量样本逼近答案——这是蒙特卡洛方法的核心思路，也是验证手算结果的标准手段。

### 13.2 分布的拟合与检验

实际问题中"该用哪种分布"并非总是一眼看出：可用直方图、Q-Q 图初判，再用卡方拟合优度检验（043 讲）正式检验。从"选分布"到"验证分布"，是数据分析的标准流程。
