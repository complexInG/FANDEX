## 0. 多组抽样数据的"病例会诊"

医院里有一种教学方式叫**病例会诊**：把不同病人的典型病例摆在一起，逐个分析症状、确诊思路、用药方案。病人各不相同，但诊断方法一脉相承。

本文就是抽样分布的"病例会诊"。前面三篇文章讲了统计量、三大分布、正态总体的抽样分布定理，这里用**案例驱动**的方式，把定理放到具体的数据情境中反复操练：

- 案例一："质检报告"练统计量基本计算；
- 案例二："波动超标调查"练 $\chi^2$ 分布；
- 案例三："精度未知的均值问题"练 $t$ 分布；
- 案例四："两台机床谁稳定"练 $F$ 分布；
- 案例五："综合病例"练多定理联用。

每个案例都按"病例描述 → 诊断思路 → 完整求解 → 方法复盘"四步走。看完这组"病例"，你就能独立"出诊"了。

## 1. 案例一：质检报告的统计量计算

### 病例描述

某质检员从一批零件中随机抽取 7 件，测得长度（mm）为：$21.1, 21.3, 21.4, 21.5, 21.3, 21.7, 21.4$。设 $X_1, \cdots, X_7$ 为来自总体 $X$ 的样本，$E(X) = \mu$，$D(X) = \sigma^2$。求 $E(\bar{X})$、$D(\bar{X})$、$E(S^2)$ 的表达式，并计算该样本的 $\bar{x}$ 与 $S^2$。

### 诊断思路

先写理论结果（任意总体都成立），再代入数据算数值。

### 完整求解

理论部分：

$$E(\bar{X}) = \mu, \quad D(\bar{X}) = \frac{\sigma^2}{n} = \frac{\sigma^2}{7}, \quad E(S^2) = \sigma^2$$

数值部分，先算 $\bar{x}$：

$$\bar{x} = \frac{21.1 + 21.3 + 21.4 + 21.5 + 21.3 + 21.7 + 21.4}{7} = \frac{149.7}{7} = 21.386$$

再算平方和：

$$\sum x_i^2 = 21.1^2 + 21.3^2 + 21.4^2 + 21.5^2 + 21.3^2 + 21.7^2 + 21.4^2 = 445.21 + 453.69 + 457.96 + 462.25 + 453.69 + 470.89 + 457.96 = 3201.65$$

$$S^2 = \frac{1}{6}\left(\sum x_i^2 - n\bar{x}^2\right) = \frac{1}{6}(3201.65 - 7 \times 21.386^2) = \frac{1}{6}(3201.65 - 3201.35) = \frac{0.30}{6} = 0.05$$

### 方法复盘

- 均值、方差的期望公式对**任意总体**成立（只需二阶矩存在），不要求正态。
- 手算方差一定用简化公式 $\sum x_i^2 - n\bar{x}^2$，避免逐项算偏差平方。

## 2. 案例二：波动超标调查（χ² 分布）

### 病例描述

某灌装线宣称饮料净含量标准差不超过 $\sigma_0 = 2$ ml。质检员抽查 $n = 16$ 瓶，算得 $s^2 = 5.5$。在"标准差没超标"的前提下，$S^2$ 如此之大的概率是多少？（即求 $P(S^2 \geq 5.5)$，设净含量服从正态分布。）

### 诊断思路

正态总体下 $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。把 $S^2 \geq 5.5$ 化为 $\chi^2$ 事件。

### 完整求解

在 $H_0$（$\sigma^2 = \sigma_0^2 = 4$）下：

$$\frac{(n-1)S^2}{\sigma^2} = \frac{15 \times 5.5}{4} = 20.625 \sim \chi^2(15)$$

查 $\chi^2$ 分布表：$\chi^2_{0.15}(15) = 19.311$，$\chi^2_{0.10}(15) = 22.307$。

$$P(\chi^2(15) \geq 20.625) \approx 0.125$$

### 方法复盘

- 关键一步是"标准化到已知分布"：把 $S^2$ 乘上 $\dfrac{n-1}{\sigma^2}$ 变成 $\chi^2$ 变量。
- 概率介于两个表值之间时，用线性插值或直接表述"介于 0.10 与 0.15 之间"。

## 3. 案例三：精度未知的均值问题（t 分布）

### 病例描述

某实验室测量某标准件的长度，已知测量误差 $X \sim N(\mu, \sigma^2)$（$\sigma$ 未知）。做了 9 次独立测量。求 $P\left(|\bar{X} - \mu| < S\right)$（即"样本均值与真值之差小于一个样本标准差"的概率）。

### 诊断思路

$\sigma$ 未知，不能直接用 $Z$；套定理四：$T = \dfrac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$。

### 完整求解

$n = 9$，$T = \dfrac{\bar{X} - \mu}{S/3} \sim t(8)$。将目标事件变形：

$$|\bar{X} - \mu| < S \iff \left|\frac{\bar{X} - \mu}{S/3}\right| < 3 \iff |T| < 3$$

查 $t$ 表：$t_{0.01}(8) = 2.896$，$t_{0.005}(8) = 3.355$。由于 $2.896 < 3 < 3.355$，$P(T > 3)$ 介于 0.005 与 0.01 之间：

$$P(|T| < 3) = 1 - 2P(T > 3) \approx 1 - 2 \times 0.0075 = 0.985$$

### 方法复盘

- 看到"$\sigma$ 未知 + 均值"，第一反应是 $t$ 分布，而不是 $Z$。
- 双侧概率 $P(|T| < c) = 1 - 2\alpha$，其中 $t_\alpha(n-1) = c$。

## 4. 案例四：两台机床谁更稳定（F 分布）

### 病例描述

甲机床抽 8 件产品、乙机床抽 10 件产品，测得加工精度（标准差）分别为 $s_1 = 0.5$、$s_2 = 0.3$，设两总体独立且均服从正态分布、方差分别为 $\sigma_1^2$、$\sigma_2^2$。求比值统计量 $\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}$ 的分布，并求 $\dfrac{S_1^2}{S_2^2} > 2$ 的概率（设 $\sigma_1^2 = \sigma_2^2$）。

### 诊断思路

定理七：方差比（各除以其真方差后）服从 $F(n_1 - 1, n_2 - 1)$。若 $\sigma_1^2 = \sigma_2^2$，则 $S_1^2/S_2^2 \sim F(7, 9)$。

### 完整求解

分布：$\dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2} \sim F(7, 9)$。

当 $\sigma_1^2 = \sigma_2^2$ 时：

$$P\left(\frac{S_1^2}{S_2^2} > 2\right) = P(F(7, 9) > 2)$$

查 $F$ 分布表：$F_{0.10}(7, 9) = 2.51$，$F_{0.25}(7, 9) = 1.57$。由于 $1.57 < 2 < 2.51$：

$$P(F(7, 9) > 2) \approx 0.18$$

### 方法复盘

- 两个样本方差的比值，分子分母自由度各为 $n_i - 1$，**顺序别写反**。
- 若题给的是标准差 $s$，先平方再算比值。

## 5. 案例五：综合病例（多定理联用）

### 病例描述

设 $X_1, \cdots, X_{25}$ 为来自 $N(3, 100)$ 的样本。求：（1）$P(0 < \bar{X} - 3 < 6)$；（2）$P(S^2 > 62.5)$。

### 诊断思路

（1）用定理一（均值正态，$\sigma$ 已知）；（2）用定理二（方差 $\chi^2$ 分布）。两条定理分别"出诊"。

### 完整求解

（1）$\bar{X} \sim N\left(3, \dfrac{100}{25}\right) = N(3, 4)$，故 $Z = \dfrac{\bar{X} - 3}{2} \sim N(0, 1)$：

$$P(0 < \bar{X} - 3 < 6) = P(0 < Z < 3) = \Phi(3) - \Phi(0) = 0.9987 - 0.5 = 0.4987$$

（2）$\dfrac{24S^2}{100} \sim \chi^2(24)$：

$$P(S^2 > 62.5) = P\left(\frac{24S^2}{100} > \frac{24 \times 62.5}{100}\right) = P(\chi^2(24) > 15)$$

查表：$\chi^2_{0.90}(24) = 15.659$，$\chi^2_{0.85}(24) = 17.187$，故

$$P(\chi^2(24) > 15) \approx 0.91$$

### 方法复盘

- 一道题可能同时考多条定理，先判断每个问句该用哪条，再分别求解。
- 常数倍的样本方差概率问题，一律先"归一"成 $\chi^2$ 再查表。

## 6. 案例六：独立性定理的应用（证明型）

### 病例描述

设 $X_1, \cdots, X_n$ 为来自 $N(\mu, \sigma^2)$ 的样本，证明 $\bar{X}$ 与 $X_i - \bar{X}$（$i = 1, \cdots, n$）不相关，并由此说明 $\bar{X}$ 与 $S^2$ 独立。

### 完整求解

先算协方差：

$$\text{Cov}(\bar{X}, X_i - \bar{X}) = \text{Cov}(\bar{X}, X_i) - \text{Cov}(\bar{X}, \bar{X})$$

其中 $\text{Cov}(\bar{X}, X_i) = \dfrac{\sigma^2}{n}$（$\bar{X}$ 是 $X_i$ 的系数 $\dfrac{1}{n}$ 倍加上与其他独立项的线性组合），且 $\text{Cov}(\bar{X}, \bar{X}) = D(\bar{X}) = \dfrac{\sigma^2}{n}$，所以

$$\text{Cov}(\bar{X}, X_i - \bar{X}) = \frac{\sigma^2}{n} - \frac{\sigma^2}{n} = 0$$

正态分布中不相关等价于独立，故 $\bar{X}$ 与 $(X_1 - \bar{X}, \cdots, X_n - \bar{X})$ 独立。由于 $S^2 = \dfrac{1}{n-1}\sum (X_i - \bar{X})^2$ 是 $(X_1 - \bar{X}, \cdots, X_n - \bar{X})$ 的函数，所以 $\bar{X}$ 与 $S^2$ 独立。

### 方法复盘

- "不相关"到"独立"的桥梁只对（联合）正态分布有效，证明题中要显式说明这一点。
- $S^2$ 可以看作"离差向量"的平方和函数，独立性沿函数关系传递。

## 7. 常见错误与对策

| 错误类型 | 错误示例 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 分布识别错误 | $\sigma$ 未知时用 $Z$ 算均值概率 | 未判断"已知/未知"条件 | 先看题给条件：给 $\sigma$ 用 $Z$，给 $S$ 用 $t$，给方差比值用 $F$ |
| 归一化错误 | 求 $P(S^2 > c)$ 时忘记乘 $\frac{n-1}{\sigma^2}$ | 事件变形丢系数 | 把 $S^2$ 的事件先等价写成 $\frac{(n-1)S^2}{\sigma^2} > \frac{(n-1)c}{\sigma^2}$ 再查表 |
| 自由度混淆 | $n = 9$ 用 $t(9)$ 而非 $t(8)$ | 忘记 $\bar{X}$ 消耗一个自由度 | 凡出现样本方差 $S^2$ 的 $t$ 统计量，自由度一律 $n-1$ |
| 双侧面积错 | $P(|T| < c)$ 用 $1 - \alpha$ 而非 $1 - 2\alpha$ | 忘了对称分布两侧都有尾巴 | $P(|T| < c) = 1 - 2\alpha$，其中 $\alpha = P(T > c)$ |
| 概率插值粗糙 | 表值之间直接取中间值不说明 | 查表精度不足 | 说明"介于 $a$ 与 $b$ 之间"或做线性插值，标注近似 |
| 方差比方向 | $F$ 检验分子分母颠倒导致自由度错 | 不确定哪个放分子 | 约定"较大样本方差放分子"（双侧时），自由度随之确定 |

## 8. 实战练习

**练习 1（基础）**：设 $X_1, \cdots, X_7$ 为来自 $N(0, 1)$ 的样本，求 $E(\bar{X}^2)$ 和 $D(\bar{X}^2)$。

**提示**：$\bar{X} \sim N(0, 1/7)$，$\sqrt{7}\bar{X} \sim N(0,1)$，故 $7\bar{X}^2 \sim \chi^2(1)$。

**参考答案要点**：$E(\bar{X}^2) = D(\bar{X}) = \dfrac{1}{7}$；$D(\bar{X}^2) = D(\chi^2(1)/7) = \dfrac{2}{49}$。

**练习 2（χ² 分布）**：设 $X_1, \cdots, X_6$ 为来自 $N(0, 4)$ 的样本，求 $a$ 使 $P\left(\sum_{i=1}^6 X_i^2 > a\right) = 0.05$。

**提示**：$\dfrac{X_i}{2} \sim N(0,1)$，$\dfrac{1}{4}\sum X_i^2 \sim \chi^2(6)$。

**参考答案要点**：$\dfrac{a}{4} = \chi^2_{0.05}(6) = 12.592$，$a = 50.368$。

**练习 3（t 分布）**：设 $X_1, \cdots, X_{16}$ 为来自 $N(\mu, \sigma^2)$ 的样本（$\sigma$ 未知），求 $P(|\bar{X} - \mu| < 0.5S)$。

**提示**：$T = \dfrac{\bar{X} - \mu}{S/4} \sim t(15)$，目标事件对应 $|T| < 2$。

**参考答案要点**：$P(|T| < 2)$：$t_{0.025}(15) = 2.131$，$t_{0.05}(15) = 1.753$，$P(T > 2) \approx 0.032$，故概率约 $1 - 2 \times 0.032 = 0.936$。

**练习 4（F 分布）**：设 $X_1, \cdots, X_8$ 与 $Y_1, \cdots, Y_{10}$ 分别来自 $N(\mu_1, \sigma^2)$ 和 $N(\mu_2, \sigma^2)$，求 $P(S_1^2 > 2S_2^2)$。

**提示**：$\dfrac{S_1^2}{S_2^2} \sim F(7, 9)$。

**参考答案要点**：$P(F(7,9) > 2)$：$F_{0.10}(7,9) = 2.51$，$F_{0.25}(7,9) = 1.57$，概率约 0.18。

**练习 5（综合）**：设 $X_1, \cdots, X_6$ 为来自 $N(0, 1)$ 的样本，求 $Y = \dfrac{X_1 + X_2 + X_3}{\sqrt{X_4^2 + X_5^2 + X_6^2}}$ 的分布。

**提示**：分子标准化后是 $N(0,1)$，分母是 $\sqrt{\chi^2(3)}$，对照 $t$ 定义。

**参考答案要点**：$\dfrac{X_1+X_2+X_3}{\sqrt{3}} \sim N(0,1)$，$X_4^2+X_5^2+X_6^2 \sim \chi^2(3)$，两者独立，故 $Y = \dfrac{(X_1+X_2+X_3)/\sqrt{3}}{\sqrt{(X_4^2+X_5^2+X_6^2)/3}} \sim t(3)$。

## 9. 一句话记忆

**做抽样分布的题，先"对症"后"下药"：均值配 $Z$（$\sigma$ 已知）或 $t$（$\sigma$ 未知），方差配 $\chi^2$，方差比配 $F$，最后统一"归一化"到标准统计量再查表。**
