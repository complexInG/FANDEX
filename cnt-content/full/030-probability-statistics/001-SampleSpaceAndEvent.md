## 0. 从一个抽奖箱开始

想象你面前有一个不透明的抽奖箱，里面放了 10 张卡片，其中 3 张写着"一等奖"，5 张写着"二等奖"，2 张写着"谢谢参与"。你伸手进去摸一张：

- 你**事先不知道**会摸到哪张卡片，但你知道**所有可能的结果**：一等奖、二等奖、谢谢参与；
- 你可以在相同条件下**反复摸**（把卡片放回去摇匀再摸）；
- 每摸一次，结果都**不能提前预判**。

这个小小的抽奖箱，其实就包含了概率论的全部"零件"：可能的结果集合（样本空间）、你关心的某类结果（事件）、以及摸到某类结果的可能性大小（概率）。本文就把这些零件一个个拆开讲清楚。这是整个概率论模块的**地基**，后面的古典概型、条件概率、随机变量全部建立在这一讲的概念之上。

## 1. 随机试验：概率论研究的"对象"

### 1.1 随机现象与随机试验

自然界和社会中只有两类现象：

- **确定性现象**：条件一定，结果一定。例如：标准大气压下，水加热到 $100^\circ\text{C}$ 必然沸腾；同性电荷必然相斥。
- **随机现象**：条件一定，结果却可能多种。例如：抛一枚硬币，正面或反面；明天下不下雨；抽奖箱里摸出的卡片。

为了研究随机现象背后的统计规律，我们对它进行观察、记录，每一次观察称为一次**随机试验**，简称**试验**，记作 $E$。

### 1.2 随机试验的三个特征

1. **可重复性**：可以在相同条件下重复进行（抽奖箱放回摇匀再摸）；
2. **多值性**：可能结果不止一个，且所有可能结果在试验前**全部已知**（奖券种类事先清楚）；
3. **随机性**：试验前无法确定哪一个结果会出现（摸之前不知道是哪张）。

> 这三点就是"随机试验"的身份证。缺了任何一点，都不能用概率论的语言来描述它。

**典型示例**：

| 试验   | 描述                                   | 可能结果                    |
| ------ | -------------------------------------- | --------------------------- |
| $E_1$  | 抛一枚硬币                             | 正面、反面                  |
| $E_2$  | 掷一颗骰子                             | 1, 2, 3, 4, 5, 6            |
| $E_3$  | 从一批产品中任取一件                   | 合格品、不合格品            |
| $E_4$  | 记录某电话交换台一分钟内的呼叫次数     | 0, 1, 2, $\cdots$           |
| $E_5$  | 测量某零件的长度                       | $[a, b]$ 中的任意实数       |
| $E_6$  | 从抽奖箱摸一张卡片                     | 一等奖、二等奖、谢谢参与    |

## 2. 样本空间：把所有结果"装进箱子"

### 2.1 定义

随机试验 $E$ 的**所有**可能结果组成的集合，称为 $E$ 的**样本空间**，记作 $\Omega$（或 $S$）。样本空间中的每个元素（即每个可能结果）称为**样本点**，记作 $\omega$：

$$\Omega = \{\omega_1, \omega_2, \cdots\}$$

回到抽奖箱：样本空间就是"所有卡片内容的集合"。摸奖时，结果必然落在样本空间内，绝不会落到样本空间外面——这是样本空间最重要的性质：**它穷尽了所有可能**。

### 2.2 样本空间的分类

**离散样本空间**：样本点有限个或可列无限个。

- 有限：$\Omega = \{\omega_1, \omega_2, \cdots, \omega_n\}$，如掷骰子 $\Omega = \{1, 2, 3, 4, 5, 6\}$；
- 可列无限：$\Omega = \{\omega_1, \omega_2, \cdots, \omega_n, \cdots\}$，如呼叫次数 $\Omega = \{0, 1, 2, \cdots\}$。

**连续样本空间**：样本点不可列，对应某个区间或区域。

$$\Omega = [a, b] \quad \text{或} \quad \Omega = \mathbb{R}$$

如零件长度 $\Omega = [a, b]$。连续样本空间将在"几何概型"和"连续型随机变量"两讲中重点处理。

### 2.3 写样本空间的常见误区

写样本空间时最常见的错误是"漏结果"或"混层次"。例如"掷两颗骰子"，样本空间应写为有序对：

$$\Omega = \{(1,1), (1,2), \cdots, (6,6)\}$$

共有 $6 \times 6 = 36$ 个样本点。若写成 $\{2, 3, \cdots, 12\}$（只看点数之和），虽然也能描述结果，但丢失了"哪颗骰子掷出几"的信息，后续计算概率时容易出错。**原则：样本空间要保留足够的信息，以便区分每一个具体结果。**

## 3. 随机事件：你关心的"那几类结果"

### 3.1 定义

随机试验 $E$ 的样本空间 $\Omega$ 的**子集**称为 $E$ 的**随机事件**，简称**事件**，通常用大写字母 $A, B, C, \cdots$ 表示。

- 当试验结果 $\omega \in A$ 时，称**事件 $A$ 发生**；
- 当 $\omega \notin A$ 时，称**事件 $A$ 不发生**。

抽奖箱中"摸到一等奖"就是一个事件，它是样本空间 $\{\text{一等奖}, \text{二等奖}, \text{谢谢参与}\}$ 的子集 $\{\text{一等奖}\}$。

### 3.2 基本事件与复合事件

- **基本事件**：只含一个样本点的单点集 $\{\omega\}$。掷骰子"掷出 3"是基本事件。
- **复合事件**：含多个样本点。掷骰子"掷出奇数" $= \{1, 3, 5\}$ 是复合事件。

### 3.3 两个特殊事件

- **必然事件**：$\Omega$ 本身，每次试验必然发生；
- **不可能事件**：空集 $\varnothing$，每次试验都不可能发生。

> 注意：必然事件与不可能事件其实已经失去了"随机性"，但把它们当作随机事件的极端情形，会让后面的公式统一、简洁。

### 3.4 用 Python 直观感受"频率趋近概率"

下面的代码模拟 1 万次掷骰子，统计"掷出 6"的频率：

```python
import random

n = 10000          # 试验次数
count = 0          # 事件 A = {掷出6} 发生次数
for _ in range(n):
    if random.randint(1, 6) == 6:
        count += 1
print(f"事件A发生的频率: {count / n:.4f}")   # 输出约 0.1667
```

你会发现试验次数越多，频率越接近 $\dfrac{1}{6}$。这正是概率的**统计定义**思想：概率是"大量重复试验中频率的稳定值"。

## 4. 事件之间的关系：用集合的语言描述"逻辑"

事件是集合，事件间的关系就是集合间的关系。

### 4.1 包含关系

若 $A$ 发生必然导致 $B$ 发生，即 $A$ 中每个样本点都属于 $B$，则称 $B$ **包含** $A$，记作 $A \subseteq B$：

$$A \subseteq B \iff \text{若 } \omega \in A \text{，则 } \omega \in B$$

若 $A \subseteq B$ 且 $B \subseteq A$，则 $A = B$。

例："摸到一等奖" $\subseteq$ "摸到奖"（一等奖也是奖）。

### 4.2 互不相容（互斥）

若 $A$ 与 $B$ 不能同时发生，即 $A \cap B = \varnothing$，则称 $A$ 与 $B$ **互不相容**（**互斥**）。

例：掷骰子，"掷出偶数"与"掷出奇数"互斥——一次掷骰不可能同时出现两种结果。

### 4.3 对立事件（逆事件）

由所有不属于 $A$ 的样本点组成的事件称为 $A$ 的**对立事件**，记作 $\bar{A}$ 或 $A^c$：

$$\bar{A} = \Omega - A = \{\omega \mid \omega \in \Omega, \omega \notin A\}$$

**互斥与对立的区别（必考辨析点）**：

| 关系     | 条件                         | 说明                                   |
| -------- | ---------------------------- | -------------------------------------- |
| 互斥     | $A \cap B = \varnothing$     | 不能同时发生，但可能都不发生           |
| 对立     | $A \cap \bar{A} = \varnothing$ 且 $A \cup \bar{A} = \Omega$ | 必有一个发生，且只发生一个 |

**对立一定互斥，互斥不一定对立。** 例如"掷出 1"与"掷出 2"互斥但不对立（还可能掷出 3）。

## 5. 事件的运算：把复杂事件"拆"成简单事件

### 5.1 并（和）运算

$A$ 与 $B$ 中**至少有一个发生**的事件，记作 $A \cup B$：

$$A \cup B = \{\omega \mid \omega \in A \text{ 或 } \omega \in B\}$$

### 5.2 交（积）运算

$A$ 与 $B$ **同时发生**的事件，记作 $A \cap B$ 或 $AB$：

$$A \cap B = \{\omega \mid \omega \in A \text{ 且 } \omega \in B\}$$

### 5.3 差运算

$A$ 发生而 $B$ **不发生**的事件，记作 $A - B$：

$$A - B = \{\omega \mid \omega \in A \text{ 且 } \omega \notin B\} = A\bar{B}$$

### 5.4 运算律

事件运算满足**交换律、结合律、分配律**，以及最重要的**德摩根律（De Morgan 律）**：

$$\overline{A \cup B} = \bar{A} \cap \bar{B}, \qquad \overline{A \cap B} = \bar{A} \cup \bar{B}$$

推广到 $n$ 个事件：

$$\overline{\bigcup_{i=1}^{n} A_i} = \bigcap_{i=1}^{n} \bar{A}_i, \qquad \overline{\bigcap_{i=1}^{n} A_i} = \bigcup_{i=1}^{n} \bar{A}_i$$

用大白话记德摩根律："**并的反面 = 反面的交**"、"**交的反面 = 反面的并**"。比如"两人都不来" $= \bar{A}\bar{B} = \overline{A \cup B}$，即"不是（至少一人来）"，两句话说的是一回事。

### 5.5 常用分解等式

$$A \cup B = A \cup B\bar{A} = A + B - AB$$

$$A \cup B \cup C = A + B + C - AB - AC - BC + ABC$$

> 这里用 $A + B$ 表示"并"并隐含 $A, B$ 互斥。这种分解是后面推导加法公式的基础。

## 6. 概率：给事件"称重"

### 6.1 概率的公理化定义（柯尔莫哥洛夫，1933）

设 $(\Omega, \mathcal{F})$ 为可测空间（$\mathcal{F}$ 为 $\Omega$ 上的事件域），若定义在 $\mathcal{F}$ 上的实值函数 $P$ 满足三条公理：

**公理 1（非负性）**：对任意 $A \in \mathcal{F}$，$P(A) \geq 0$；

**公理 2（规范性）**：$P(\Omega) = 1$；

**公理 3（可列可加性）**：若 $A_1, A_2, \cdots$ 两两互不相容，则

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

则称 $P$ 为 $(\Omega, \mathcal{F})$ 上的**概率**，$(\Omega, \mathcal{F}, P)$ 称为**概率空间**。

### 6.2 由公理推出的重要性质

1. **不可能事件**：$P(\varnothing) = 0$；
2. **有限可加性**：$A_1, \cdots, A_n$ 两两互斥时，$P\left(\bigcup_{i=1}^{n} A_i\right) = \sum_{i=1}^{n} P(A_i)$；
3. **对立事件**：$P(\bar{A}) = 1 - P(A)$；
4. **单调性**：若 $A \subseteq B$，则 $P(A) \leq P(B)$；
5. **加法公式**：

$$P(A \cup B) = P(A) + P(B) - P(AB)$$

三个事件的加法公式：

$$P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(AB) - P(AC) - P(BC) + P(ABC)$$

6. **减法公式**：

$$P(A - B) = P(A) - P(AB)$$

若 $B \subseteq A$，则 $P(A - B) = P(A) - P(B)$。

## 8. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 样本空间漏写结果或写成"和"（如掷两骰写成 $\{2,\dots,12\}$） | 概念错误 | 混淆"结果"与"结果的函数" | 先问"一次试验的直接结果是什么"，有序试验写成有序对 |
| 2 | 认为互斥事件一定对立 | 概念混淆 | 分不清"不能同时发生"与"必有一个发生" | 记口诀：对立是"你死我活二选一"，互斥只是"不能同时" |
| 3 | 忘记 $P(A \cup B) = P(A) + P(B) - P(AB)$ 中要减去 $P(AB)$ | 公式记忆错误 | 只记住了互斥情形的可加性 | 用文氏图理解"重叠部分被加了两次"；先判断是否互斥再选公式 |
| 4 | 把 $P(AB)$ 写成 $P(A)P(B)$ | 概念错误 | 把独立性当默认条件 | 只有确认 $A, B$ 独立（本模块 006 讲）才可相乘，否则只能按公式计算 |
| 5 | 否定事件时只改一个（如把"甲乙都不来"写成 $\bar{A}B$） | 逻辑错误 | 德摩根律应用不熟 | 逐个事件取反、交并互换，写完用"读回去"验证语句是否一致 |
| 6 | 认为概率为 0 的事件不可能发生、概率为 1 必然发生（连续情形） | 概念错误 | 用离散直觉理解连续模型 | 记住：连续模型单点概率为 0 但点存在（详见几何概型一讲） |

## 10. 一句话记忆

> **样本空间装下所有可能，事件是其中你关心的子集，概率就是给每个事件量出的"可能性标尺"——而运算律是拆解复杂事件的工具箱。**
