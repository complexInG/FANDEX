## 0. 从一个生活场景说起：一把"标准尺子"量遍所有关联

"身高与体重相关"和"学习时长与成绩相关"，谁的关联更强？直接比较协方差是行不通的：身高的单位是厘米、成绩的单位是分，协方差带着"厘米·分"这种混合单位，数值大小毫无可比性。

解决思路很朴素：**给每个变量做一次"标准化"——去掉单位，把它变成"偏离均值几个标准差"的纯数字**。好比测量距离时，不管原始单位是米还是英尺，都换算成统一的"标准尺子"。这样算出来的关联指标无量纲、固定在一个范围内，可以跨场景比较。

这个"标准化的协方差"就是**相关系数**（Correlation Coefficient，皮尔逊相关系数）。

本文采用"**标准化驱动**"的叙事结构：一切从"为什么协方差不够用"出发，引出标准化变量，定义相关系数，证明其性质（$|\rho| \le 1$、$\rho = \pm1$ 的几何意义），最后讲清"相关 vs 因果"、"不相关 vs 独立"这两组易混关系。

## 1. 标准化：把变量变成"纯数字"

### 1.1 标准化变量

设 $E(X) = \mu_X$，$D(X) = \sigma_X^2 > 0$，定义 $X$ 的**标准化变量**：

$$X^* = \frac{X - \mu_X}{\sigma_X}$$

性质：$E(X^*) = 0$，$D(X^*) = 1$——标准化后的变量均值为 0、方差为 1，只剩"形状信息"，不带单位和尺度。

### 1.2 从协方差到相关系数

对 $X^*$ 与 $Y^*$ 求协方差，就得到相关系数：

$$\rho_{XY} = \text{Cov}(X^*, Y^*) = \text{Cov}\left(\frac{X - \mu_X}{\sigma_X}, \frac{Y - \mu_Y}{\sigma_Y}\right) = \frac{\text{Cov}(X, Y)}{\sigma_X \sigma_Y}$$

### 1.3 正式定义

设 $D(X) > 0$，$D(Y) > 0$，称

$$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)} \cdot \sqrt{D(Y)}} = \frac{E[(X - E(X))(Y - E(Y))]}{\sqrt{D(X)} \cdot \sqrt{D(Y)}}$$

为 $X$ 与 $Y$ 的**相关系数**（皮尔逊相关系数）。

> 记忆锚点：**相关系数 = 标准化的协方差**。这一句话同时解释了它的定义、无量纲性、值域与含义。

## 2. 相关系数的性质

### 2.1 基本性质

1. **有界性**：$|\rho_{XY}| \leq 1$；
2. **对称性**：$\rho_{XY} = \rho_{YX}$；
3. **线性变换不变性**：$\rho_{aX + b,\ cY + d} = \text{sgn}(ac) \cdot \rho_{XY}$。平移不改变相关性，正系数缩放不改变，负系数翻转符号；
4. **$|\rho| = 1$ 的充要条件**：存在常数 $a \neq 0$、$b$，使得 $P(Y = aX + b) = 1$（$X$ 与 $Y$ 呈**完全线性关系**）；且 $\rho = 1$ 时 $a > 0$（完全正相关），$\rho = -1$ 时 $a < 0$（完全负相关）；
5. **$\rho = 0$ 的等价条件**：$\rho_{XY} = 0 \iff \text{Cov}(X, Y) = 0 \iff E(XY) = E(X)E(Y)$（$X$ 与 $Y$ 不相关）。

### 2.2 有界性的证明（柯西-施瓦茨不等式）

令 $U = X - E(X)$，$V = Y - E(Y)$。由柯西-施瓦茨不等式 $[E(UV)]^2 \leq E(U^2) E(V^2)$：

$$[\text{Cov}(X, Y)]^2 = [E(UV)]^2 \leq E(U^2) E(V^2) = D(X) \cdot D(Y)$$

两边除以 $D(X) D(Y)$（为正）：

$$\rho_{XY}^2 = \frac{[\text{Cov}(X, Y)]^2}{D(X) \cdot D(Y)} \leq 1 \quad \Longrightarrow \quad |\rho_{XY}| \leq 1$$

### 2.3 $|\rho| = 1$ 的证明（等号条件）

柯西-施瓦茨等号成立 $\iff$ $U$ 与 $V$ 几乎处处成比例，即存在常数 $a$ 使 $P(V = aU) = 1$：

$$P(Y - E(Y) = a[X - E(X)]) = 1 \iff P(Y = aX + b) = 1, \quad b = E(Y) - aE(X)$$

这正说明 $\rho = \pm 1$ 意味着 $X$、$Y$ 在一条直线上——**相关系数度量的是"线性"关联强度**。

## 3. 相关系数的意义

| $\rho$ 的范围 | 含义 |
| --- | --- |
| $\rho = 1$ | 完全正线性相关（点在一条斜率为正的直线上） |
| $0 < \rho < 1$ | 正线性相关（$X$ 增大时 $Y$ 倾向于增大） |
| $\rho = 0$ | 不相关（**无线性关系**，但可能有非线性关系） |
| $-1 < \rho < 0$ | 负线性相关（$X$ 增大时 $Y$ 倾向于减小） |
| $\rho = -1$ | 完全负线性相关（点在一条斜率为负的直线上） |

### 3.1 例题 1（性质应用）

已知 $\rho_{XY} = 0.6$，求 $\rho_{2X, 3Y}$ 与 $\rho_{2X, -3Y}$。

**解**：

$$\rho_{2X, 3Y} = \text{sgn}(2 \times 3) \cdot \rho_{XY} = \rho_{XY} = 0.6$$

$$\rho_{2X, -3Y} = \text{sgn}(2 \times (-3)) \cdot \rho_{XY} = -0.6$$

**要点**：正的线性变换不改变相关系数；一个变量乘以负数会翻转符号——相关性"强度"不变，只是方向相反。

## 4. 相关系数与独立性

### 4.1 关系一览

- **独立 $\Rightarrow$ 不相关**（$\rho = 0$）；
- **不相关 $\not\Rightarrow$ 独立**（$Y = X^2$ 类反例）；
- **二维正态分布**：不相关 $\iff$ 独立。

### 4.2 例题 2（不相关但不独立：三角函数反例）

设 $\Theta \sim U(0, 2\pi)$，$X = \cos\Theta$，$Y = \sin\Theta$。验证 $X$ 与 $Y$ 不相关但不独立。

**解**：$E(X) = E(\cos\Theta) = 0$，$E(Y) = E(\sin\Theta) = 0$。

$$E(XY) = E(\cos\Theta \sin\Theta) = \frac{1}{2} E(\sin 2\Theta) = \frac{1}{2} \cdot \frac{1}{2\pi} \int_0^{2\pi} \sin 2\theta \, d\theta = 0$$

$$\text{Cov}(X, Y) = 0 - 0 = 0 \quad \Rightarrow \quad \rho = 0$$

但 $X^2 + Y^2 = 1$，$X$ 与 $Y$ 完全由彼此决定，显然不独立。**相关系数为 0 只说明没有线性关系**，非线性关系（这里是圆周关系）完全可能藏在背后。

### 4.3 例题 3（不相关但不独立：平方反例）

设 $X \sim N(0, 1)$，$Y = X^2$，求 $\rho_{XY}$。

**解**：$E(X) = 0$，$E(Y) = E(X^2) = 1$。

$$E(XY) = E(X^3) = 0 \quad \text{（正态分布奇数阶矩为 0）}$$

$$\text{Cov}(X, Y) = 0 - 0 = 0 \quad \Rightarrow \quad \rho = 0$$

$Y$ 完全由 $X$ 决定（$Y = X^2$），不独立。注意：$X$ 与 $Y$ 的函数关系极强，但**线性相关为 0**——这正是相关系数只能捕捉线性关系的铁证。

## 5. 相关系数的计算：五步法

1. 算 $E(X)$、$E(Y)$；
2. 算 $E(XY)$；
3. 算 $\text{Cov}(X, Y) = E(XY) - E(X)E(Y)$；
4. 算 $D(X)$、$D(Y)$（先算 $E(X^2)$、$E(Y^2)$）；
5. 代入 $\rho_{XY} = \dfrac{\text{Cov}(X, Y)}{\sqrt{D(X)D(Y)}}$。

### 例题 4（完整五步）

设 $(X, Y)$ 的联合分布律为：

| $X \backslash Y$ | 0      | 1      |
| :--------------: | :----: | :----: |
| 0                | 1/4    | 1/4    |
| 1                | 1/4    | 1/4    |

求 $\rho_{XY}$。

**解**：

步骤 1：$E(X) = \dfrac{1}{2}$，$E(Y) = \dfrac{1}{2}$。

步骤 2：$E(XY) = 1 \times 1 \times \dfrac{1}{4} = \dfrac{1}{4}$。

步骤 3：$\text{Cov}(X, Y) = \dfrac{1}{4} - \dfrac{1}{2} \times \dfrac{1}{2} = 0$。

步骤 4：$D(X) = \dfrac{1}{4}$，$D(Y) = \dfrac{1}{4}$（$B(1, \tfrac12)$ 的方差为 $p(1-p) = \tfrac14$）。

步骤 5：$\rho_{XY} = \dfrac{0}{\sqrt{1/4 \times 1/4}} = 0$。

本例中 $X$ 与 $Y$ 独立（联合分布为乘积形式），故相关系数为 0。

## 6. 相关系数的局限与注意事项

1. **只衡量线性关系**：$|\rho|$ 小不代表"没关系"，可能有强烈的非线性关系（$Y = X^2$ 是 $\rho = 0$ 的极端例）；
2. **对异常值敏感**：一个极端数据点可能把 $\rho$ 从接近 0 拉到接近 1（数据分析中要先画散点图）；
3. **相关不等于因果**：冰淇淋销量与溺水人数高度正相关，但都是"夏天"这个混杂变量驱动的；
4. **$\rho$ 是总体参数**：实际数据分析中我们用样本相关系数 $r$ 估计它（见 051-data-analysis 模块）。

## 7. 其他相关系数（进阶了解）

- **斯皮尔曼秩相关系数**：对数据的排名（秩）算相关系数，衡量单调（不必线性）关系，对异常值稳健；
- **肯德尔 $\tau$**：基于"一致对/不一致对"计数，适用于序数数据；
- **点二列相关**：一个连续变量与一个二分类变量的相关度量。

## 8. 常见错误与对策

| 错误示例 | 错误类型 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 把 $\rho = 0$ 说成"两者无关" | 概念混淆 | 混淆线性关系与一般关系 | $\rho = 0$ 只说明无线性关系；$Y = X^2$ 或圆周关系都是 $\rho=0$ 却有强关系的反例 |
| 用 $\rho \neq 0$ 断言因果关系 | 因果误读 | 相关不等于因果 | 可能有第三个变量（混杂因素）；因果推断需要实验设计，不是相关系数能回答的 |
| 忘记标准化直接比较协方差大小 | 方法错误 | 忽略量纲 | 跨场景比较一律用 $\rho$（无量纲、值域 $[-1,1]$） |
| 用 $E(XY) = E(X)E(Y)$ 反推独立 | 逻辑倒置 | 混淆"不相关"与"独立" | 不相关只是无线性关系；仅正态分布下两者等价 |
| 算 $\rho$ 时漏算 $D(X)$ 或 $D(Y)$ | 计算遗漏 | 五步法不完整 | 严格按五步走，最后用 $|\rho| \le 1$ 自检（算出 $|\rho|>1$ 必错） |
| 对异常值数据直接用 $\rho$ | 前提忽视 | 忽略了 $\rho$ 对异常值的敏感 | 先画散点图；有异常值改用秩相关系数 |

## 9. 实战练习

### 练习 1（定义计算）

设 $(X, Y)$ 的联合分布律为：$P(0,0)=0.2$，$P(0,1)=0.1$，$P(1,0)=0.1$，$P(1,1)=0.6$，求 $\rho_{XY}$。

**提示**：五步法。

**参考答案要点**：$E(X) = 0.7$，$E(Y) = 0.7$，$E(XY) = 0.6$，$\text{Cov} = 0.6 - 0.49 = 0.11$；$D(X) = D(Y) = 0.21$；$\rho = \dfrac{0.11}{0.21} \approx 0.524$。

### 练习 2（线性变换不变性）

已知 $\rho_{XY} = -0.4$，求 $\rho_{-3X, 5Y}$ 与 $\rho_{X, 2Y+7}$。

**提示**：$\rho_{aX+b, cY+d} = \text{sgn}(ac)\rho_{XY}$。

**参考答案要点**：$\rho_{-3X,5Y} = \text{sgn}(-15) \times (-0.4) = 0.4$；$\rho_{X,2Y+7} = \text{sgn}(1\times2) \times (-0.4) = -0.4$。

### 练习 3（连续型相关系数）

设 $(X, Y)$ 的联合密度为 $f(x, y) = \begin{cases} 2, & 0 < y < x < 1 \\ 0, & \text{其他} \end{cases}$，求 $\rho_{XY}$。

**提示**：$E(X) = \dfrac{2}{3}$，$E(Y) = \dfrac{1}{3}$，$E(XY) = \dfrac{1}{4}$，$D(X) = D(Y) = \dfrac{1}{18}$。

**参考答案要点**：$\text{Cov} = \dfrac{1}{36}$；$\rho = \dfrac{1/36}{\sqrt{(1/18)(1/18)}} = \dfrac{1}{2}$。

### 练习 4（已知 $\rho$ 反推方差）

设 $X$、$Y$ 的相关系数 $\rho = 0.5$，$D(X) = D(Y) = 1$，求 $D(X - Y)$。

**提示**：$\text{Cov} = \rho \sqrt{D(X)D(Y)}$。

**参考答案要点**：$\text{Cov} = 0.5$；$D(X-Y) = 1 + 1 - 2 \times 0.5 = 1$。

### 练习 5（概念辨析）

判断对错并说明理由：（1）$\rho = 0$ 则 $X$ 与 $Y$ 独立；（2）$X$ 与 $Y$ 独立则 $\rho = 0$；（3）$\rho = 1$ 则 $Y = aX + b$（$a > 0$）以概率 1 成立。

**提示**：分别对应"不相关→独立"（错）、"独立→不相关"（对）、"完全线性"（对）。

**参考答案要点**：（1）错，$Y = X^2$ 反例；（2）对，独立必不相关；（3）对，$|\rho|=1$ 的充要条件。

## 10. 一句话记忆

相关系数是"标准化的协方差"：$\rho = \dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$，无量纲、$|\rho| \le 1$、度量线性关联；独立必不相关，但不相关未必独立，相关不等于因果。
