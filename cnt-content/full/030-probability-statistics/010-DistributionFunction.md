## 0. 天气累计图与进度条

天气预报 App 里常有一张"降水概率累计曲线"：横轴是降水量，曲线表示"降水量不超过某个值的概率"。这其实就是一个**分布函数**的雏形。

再想一个更日常的例子——**进度条**：

- 游戏下载进度条显示"已下载 40%"——它回答的问题是"**完成了不超过 40% 的概率**"（此刻就是 100%，但换个场景就明白了）；
- 把"进度"换成随机变量 $X$，"进度条刻度 $x$ 处已到达的比例"就是 $F(x) = P(X \leq x)$：从 0 慢慢爬升，最终到达 100%（$F(+\infty) = 1$），而且**只会前进、不会倒退**（单调不减）。

上一讲离散型有"分布律"，连续型有"概率密度"，两套语言。**分布函数 $F(x)$ 是二者的统一工具**：不管是阶梯（离散）还是光滑曲线（连续），都能用一个函数描述全部概率信息。本讲把它当作"万能工具"来学：定义 → 性质 → 判定 → 计算 → 应用。

## 1. 分布函数的定义：一个"累计器"

### 1.1 定义

设 $X$ 是一个随机变量，$x$ 是任意实数，函数

$$F(x) = P(X \leq x)$$

称为 $X$ 的**分布函数**（**累积分布函数**，CDF）。

**读法**：$F(x)$ = "$X$ 不超过 $x$ 的概率"。对任意 $x_1 < x_2$：

$$P(x_1 < X \leq x_2) = F(x_2) - F(x_1)$$

**为什么万能**：只要知道 $F$，随机变量落在**任意区间**的概率都可以用两个 $F$ 值相减得到。分布函数完整描述了随机变量的概率分布。

### 1.2 定义域与值域

$F(x)$ 定义在全体实数上（$-\infty < x < +\infty$），取值在 $[0, 1]$ 之间——它是"全实数轴上的概率累计器"。

## 2. 分布函数的四个性质

1. **单调不减**：若 $x_1 < x_2$，则 $F(x_1) \leq F(x_2)$（累计只会增加）；
2. **有界**：$0 \leq F(x) \leq 1$；
3. **边界值**：

$$F(-\infty) = \lim_{x \to -\infty} F(x) = 0, \qquad F(+\infty) = \lim_{x \to +\infty} F(x) = 1$$

4. **右连续**：$F(x^+) = F(x)$，即 $\lim_{t \to x^+} F(t) = F(x)$。

> 这四个性质也是"判定一个函数能否作为分布函数"的**充要条件**（第 5 节详述）。离散型的阶梯、连续型的光滑曲线，全都满足这四条。

## 3. 由分布函数计算概率：一张换算表

| 目标概率                       | 用 $F$ 表示                            |
| ------------------------------ | -------------------------------------- |
| $P(X \leq x)$                  | $F(x)$                                 |
| $P(X > x)$                     | $1 - F(x)$                             |
| $P(x_1 < X \leq x_2)$          | $F(x_2) - F(x_1)$                      |
| $P(X = x)$                     | $F(x) - F(x^-)$（左极限之差）          |
| $P(X < x)$                     | $F(x^-)$                               |
| $P(x_1 \leq X \leq x_2)$       | $F(x_2) - F(x_1^-)$                    |
| $P(x_1 < X < x_2)$             | $F(x_2^-) - F(x_1)$                    |

**要点**：开口方向决定取左极限还是函数值。"小于"用左极限，"小于等于"用函数值；右端点函数值、左端点取左极限，就不会错。

**跳跃的意义**：$F$ 在 $x_0$ 处跳跃，说明 $P(X = x_0) > 0$，跳跃高度就是该点概率；$F$ 在 $x_0$ 连续，则 $P(X = x_0) = 0$。**连续型随机变量的分布函数处处连续，所以单点概率恒为 0**——这与 009 讲的结论呼应。

## 4. 离散型的分布函数：阶梯函数

### 4.1 构造

分布律 $P(X = x_k) = p_k$（$k = 1, 2, \cdots$）时：

$$F(x) = \sum_{x_k \leq x} p_k$$

## 5. 连续型的分布函数：由密度积分

### 5.1 关系

$X$ 连续型、密度为 $f(x)$ 时：

$$F(x) = \int_{-\infty}^{x} f(t) \, dt$$

在 $f(x)$ 的连续点处：

$$F'(x) = f(x)$$

**双向转化**：$f \to F$ 用积分，$F \to f$ 用求导——两者互逆，是"密度与分布函数"这对搭档的基本操作。

## 6. 分布函数的判定准则

**定理**：实值函数 $F(x)$ 是某个随机变量的分布函数，当且仅当：

1. $F(x)$ 单调不减；
2. $F(-\infty) = 0$，$F(+\infty) = 1$；
3. $F(x)$ 右连续。

**反例训练**（判断下面哪个不是分布函数）：

- $F_1(x) = \begin{cases} 0, & x < 0 \\ 1, & x \geq 0 \end{cases}$ ——是（退化分布：常数 0 的分布函数）；
- $F_2(x) = \begin{cases} 0, & x < 0 \\ x^2, & x \geq 0 \end{cases}$ ——不是：$F(+\infty) = +\infty \neq 1$；
- $F_3(x) = \begin{cases} 0, & x \leq 0 \\ x, & 0 < x \leq 1 \\ 1, & x > 1 \end{cases}$ ——不是：在 $x = 0$ 处左连续而非右连续（$F(0^+) = 0$ 但应等于 $F(0) = 0$？检查：$F(0) = 0$，$F(0^+) = \lim_{x \to 0^+} x = 0$，右连续成立；但在 $x=1$ 处 $F(1) = 1$，$F(1^+) = 1$ 也成立；真正的问题：它在 $x=1$ 处 $F(1^-) = 1$、$F(1) = 1$，但按定义 $x \le 1$ 时 $F = x$ 给出 $F(1^-)=1$，且 $x>1$ 时 $F=1$，此函数单调不减、边界正确、右连续——实际是合法的分布函数（连续型）。**正确的反例**应是左连续而非右连续的函数，例如在跳跃点写错方向）：

**更清晰的反例**：$F_3(x) = \begin{cases} 0, & x < 0 \\ 0.5, & x \leq 1 \\ 1, & x > 1 \end{cases}$ 不是分布函数：它在 $x = 1$ 处左连续而非右连续（$F(1) = 0.5$，但 $F(1^+) = 1 \neq 0.5$）。

**小结**：三条件缺一不可。做题时逐一检查：单调性、两端的 0 和 1、每个跳跃点是否右连续。

## 7. 分布函数的三大应用

### 7.1 分位数（逆问题）

对 $0 < p < 1$，满足 $F(x_p) = p$ 的 $x_p$ 称为 **$p$ 分位数**：

- $x_{0.5}$：中位数；
- $x_{0.25}$ / $x_{0.75}$：下/上四分位数。

分位数是描述数据位置、构造置信区间的核心工具（037 讲会再次用到）。

### 7.2 随机数的逆变换法生成

若 $U \sim U(0, 1)$，则 $X = F^{-1}(U)$ 的分布函数为 $F$：

$$P(X \leq x) = P(F^{-1}(U) \leq x) = P(U \leq F(x)) = F(x)$$

**工程意义**：这是"用均匀随机数生成任意分布随机数"的基本方法，是蒙特卡洛模拟的地基（003 讲提到的蒙特卡洛方法由此落地）。

### 7.3 比较两个随机变量

若对任意 $x$ 都有 $F_X(x) \geq F_Y(x)$，则 $X$ **随机小于** $Y$（$X$ 倾向于取更小值）。分布函数的逐点比较给出了"随机大小"的严格定义。

## 8. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 离散型分布函数端点写错（该含不含） | 计算错误 | 忽略"$\leq$"与"$<$"的区别 | 记住右连续：$F(x_k)$ 必须含 $x_k$，区间左闭右开 |
| 2 | 把 $P(X = x)$ 写成 $F(x)$（连续型） | 概念错误 | 混淆单点概率与累计 | 连续型 $P(X=x) = 0$；离散型 $P(X=x_k) = F(x_k) - F(x_k^-)$ |
| 3 | 判定分布函数时漏查右连续性 | 概念错误 | 只查单调与边界 | 三个条件逐一核对；跳跃点处看 $F(x^+) = F(x)$ |
| 4 | $P(x_1 < X \leq x_2)$ 用错端点 | 公式错误 | 区间换算表不熟 | 记口诀："小等于用函数值、小用左极限"；右端函数值、左端左极限 |
| 5 | 由 $F$ 求 $f$ 时把端点导数也算进去 | 方法错误 | 不理解单点概率 | 端点值不影响概率，分段求导即可，不必纠结端点处导数 |
| 6 | 连续型 $F$ 与离散型 $F$ 的处理方式混用 | 概念错误 | 不区分类型 | 先判断离散（阶梯）还是连续（光滑）；连续用积分求导，离散用累加 |

## 10. 一句话记忆

> **分布函数 $F(x) = P(X \leq x)$ 是全实数轴上的概率累计器：单调不减、从 0 到 1、右连续；区间概率 = 两值相减，跳跃高度 = 单点概率——它是统一离散与连续、连接概率与统计推断的万能工具。**

## 深度专题扩展

### 13.1 分布函数与生存函数

可靠性工程中更常用**生存函数** $S(t) = 1 - F(t) = P(X > t)$（元件存活超过 $t$ 的概率）与**失效率** $\lambda(t) = \dfrac{f(t)}{1 - F(t)}$。指数分布的失效率为常数 $\lambda$（无老化）；威布尔分布等通过调节失效率形状拟合不同失效模式。

### 13.2 经验分布函数（ECDF）

给定样本 $x_1, \cdots, x_n$，**经验分布函数** $\hat{F}_n(x) = \dfrac{\text{样本中} \leq x \text{ 的个数}}{n}$ 是分布函数的非参数估计。格利文科定理保证 $\hat{F}_n$ 一致收敛于 $F$——这就是"用样本分布近似总体分布"（bootstrap 方法）的理论依据。
