## 0. 医生的推理链

一位病人走进诊室，诉说胸痛。医生的脑海里自动跑过一条推理链：

1. **先验**：按人群统计，胸痛病人里患心脏病的比例大约是多少？（比如 5%）
2. **似然**：如果真是心脏病，出现这种胸痛症状的可能性有多大？（很高）
3. **证据**：心电图、血液指标检测——阳性还是阴性？
4. **后验**：综合以上全部信息，这位病人**具体**患心脏病的概率变成了多少？

同样，侦探破案时也会这样推理："案发现场有嫌疑人 A 的指纹（证据），但 A 本来就在这栋楼上班（先验），所以指纹的证明力要打折扣。" **证据只有在"罕见原因"背景下才有价值**——这正是本讲的核心思想。

上一讲我们学会了"已知原因，求结果的概率"（$P(\text{症状} \mid \text{疾病})$，似然）。但现实问题往往反着来：**已知结果（症状、证据、检测阳性），要反推原因（疾病、嫌疑人、真实信号）的概率**，即 $P(\text{疾病} \mid \text{症状})$。完成这一步"由果溯因"的，就是**全概率公式**与**贝叶斯公式**。

## 1. 样本空间的分割：把"原因"分类

### 1.1 分割（完备事件组）的定义

设 $B_1, B_2, \cdots, B_n$ 是一组事件，若满足：

1. **两两互斥**：$B_i B_j = \varnothing$（$i \neq j$）；
2. **并成全体**：$\bigcup_{i=1}^{n} B_i = \Omega$；
3. **概率为正**：$P(B_i) > 0$（$i = 1, \cdots, n$）。

则称 $B_1, B_2, \cdots, B_n$ 为样本空间 $\Omega$ 的一个**分割**（**完备事件组**）。

**直觉**：分割就是把整块蛋糕切成若干不相重叠、但合起来正好是整块的"片"。医学场景中，$\{患病, 未患病\}$ 就是最常用的分割；工厂场景中，$\{甲线产品, 乙线产品, 丙线产品\}$ 也是分割。

### 1.2 为什么需要分割

任何事件 $A$ 都可以"按原因拆开"：

$$A = A\Omega = A\left(\bigcup_{i=1}^{n} B_i\right) = \bigcup_{i=1}^{n} AB_i$$

由于 $B_i$ 两两互斥，$AB_i$ 也两两互斥。"症状 $A$ 发生"被拆成"患心脏病时出现症状 + 未患病时出现症状 + ..."若干互斥的子事件之和。**拆，是为了分而治之。**

## 2. 全概率公式：化整为零

### 2.1 公式

设 $B_1, B_2, \cdots, B_n$ 为样本空间 $\Omega$ 的一个分割，则对任意事件 $A$：

$$P(A) = \sum_{i=1}^{n} P(B_i) P(A \mid B_i)$$

**证明**：

$$P(A) = P\left(\bigcup_{i=1}^{n} AB_i\right) = \sum_{i=1}^{n} P(AB_i) = \sum_{i=1}^{n} P(B_i) P(A \mid B_i)$$

第一步用分割拆事件，第二步用有限可加性，第三步用乘法公式。

### 2.2 直觉：加权平均

$P(A)$ 是"各原因下条件概率的**加权平均**"，权重是各原因本身的概率 $P(B_i)$。原因越常见（权重越大），它对结果概率的贡献越大。

**例题**：某工厂甲、乙、丙三条生产线产量分别占 25%、35%、40%，次品率分别为 5%、4%、2%。从总产品中任取一件，求取到次品的概率。

**解**：设 $A$ = "取到次品"，$B_1, B_2, B_3$ = "取到甲、乙、丙线产品"。则

$$P(A) = 0.25 \times 0.05 + 0.35 \times 0.04 + 0.40 \times 0.02 = 0.0125 + 0.014 + 0.008 = 0.0345$$

次品率 3.45%，介于 2% 与 5% 之间，被产量占比"加权"了——这非常符合直觉。

### 2.3 全概率公式的树状图视角

画一棵树：第一层是"原因"分支（标概率 $P(B_i)$），第二层是"原因下结果"分支（标条件概率 $P(A \mid B_i)$）。从根到"结果 $A$"的每条路径概率 = 路径上概率相乘，$P(A)$ = 所有通向 $A$ 的路径概率之和。**树的每一条根到叶的路径都是乘法公式，同一层求和就是全概率公式。**

## 3. 贝叶斯公式：由果溯因

### 3.1 公式

设 $B_1, B_2, \cdots, B_n$ 为分割，$A$ 为任意事件且 $P(A) > 0$，则对每个 $k$：

$$P(B_k \mid A) = \frac{P(B_k) P(A \mid B_k)}{\sum_{i=1}^{n} P(B_i) P(A \mid B_i)}, \quad k = 1, 2, \cdots, n$$

**证明**：由条件概率定义与乘法公式：

$$P(B_k \mid A) = \frac{P(B_k A)}{P(A)} = \frac{P(B_k) P(A \mid B_k)}{P(A)}$$

分母用全概率公式展开即得。

### 3.2 三个术语

| 术语         | 记号                | 含义                                   |
| ------------ | ------------------- | -------------------------------------- |
| 先验概率     | $P(B_k)$            | 看到结果 $A$ 之前，对原因 $B_k$ 的信念 |
| 似然         | $P(A \mid B_k)$     | 原因 $B_k$ 下，结果 $A$ 出现的可能性   |
| 后验概率     | $P(B_k \mid A)$     | 看到结果 $A$ 之后，原因 $B_k$ 的概率   |

$$\text{后验} = \frac{\text{先验} \times \text{似然}}{\text{归一化常数}}$$

分母 $\sum_i P(B_i) P(A \mid B_i) = P(A)$ 是归一化常数，保证所有后验概率之和为 1。

### 3.3 两事件的贝叶斯公式

当 $n = 2$ 时（$B$ 与 $\bar{B}$ 分割样本空间）：

$$P(B \mid A) = \frac{P(B) P(A \mid B)}{P(B) P(A \mid B) + P(\bar{B}) P(A \mid \bar{B})}$$

## 4. 经典案例：医学检验（基础概率谬误）

**问题**：某种疾病的患病率（先验）为 0.1%；检测方法的灵敏度为 99%（患病者 99% 检出阳性），特异度为 95%（未患病者 95% 检出阴性）。现某人检测为阳性，求其真正患病的概率。

**解**：设 $D$ = "患病"，$+$ = "检测阳性"。已知 $P(D) = 0.001$，$P(+ \mid D) = 0.99$，$P(- \mid \bar{D}) = 0.95$，故 $P(+ \mid \bar{D}) = 1 - 0.95 = 0.05$。

$$P(D \mid +) = \frac{P(D)P(+ \mid D)}{P(D)P(+ \mid D) + P(\bar{D})P(+ \mid \bar{D})}$$

$$= \frac{0.001 \times 0.99}{0.001 \times 0.99 + 0.999 \times 0.05} = \frac{0.00099}{0.00099 + 0.04995} = \frac{0.00099}{0.05094} \approx 0.0194$$

**结论**：即便检测方法的灵敏度、特异度都很高，阳性者真正患病的概率也仅约 **1.94%**。

**为什么如此反直觉？** 用"人数分解法"看：假设 10 万人中 100 人患病，其中 99 人检出阳性；99900 人未患病，其中约 4995 人（5%）被误报为阳性。阳性总人数约 5094 人，其中真正患病只有 99 人：

$$P(D \mid +) = \frac{99}{5094} \approx 0.0194$$

**阳性的"质量"被大量假阳性稀释了**——这就是著名的**基础概率谬误（Base Rate Fallacy）**：人们往往只盯着"灵敏度 99%"这种亮眼数字，却忽视了疾病本身的罕见性。这也是为什么医生在低患病率人群里看到阳性结果时不会直接下结论，而会建议复查或做更特异的检查。

**Python 计算**：

```python
p_d = 0.001                 # 先验（患病率）
sens = 0.99                 # 灵敏度 P(+|D)
spec = 0.95                 # 特异度 P(-|非D)
p_pos = p_d * sens + (1 - p_d) * (1 - spec)   # 全概率公式求 P(+)
p_d_given_pos = p_d * sens / p_pos            # 贝叶斯公式
print(f"P(D|+) = {p_d_given_pos:.4f}")        # 输出约 0.0194
```

## 5. 经典案例：信号检测与产品追溯

### 5.1 信号检测

**问题**：发送端以概率 0.6 发信号 0、0.4 发信号 1。信道噪声导致：发 0 收 1 的概率 0.2，发 1 收 0 的概率 0.1。若接收端收到 1，求发送端确实发了 1 的概率。

**解**：设 $S_0, S_1$ 为发送，$R_0, R_1$ 为接收。$P(R_1 \mid S_1) = 0.9$，$P(R_1 \mid S_0) = 0.2$。

$$P(S_1 \mid R_1) = \frac{0.4 \times 0.9}{0.6 \times 0.2 + 0.4 \times 0.9} = \frac{0.36}{0.48} = 0.75$$

即使信道有噪声，收到 1 时仍有 75% 的概率真的发了 1——因为发送 1 的先验（0.4）不算太低。

### 5.2 产品来源追溯

**问题**：商店从甲厂进货占 60%、乙厂占 40%，甲厂次品率 2%、乙厂次品率 1%。发现一件次品，求它来自甲厂的概率。

**解**：

$$P(\text{甲} \mid \text{次品}) = \frac{0.6 \times 0.02}{0.6 \times 0.02 + 0.4 \times 0.01} = \frac{0.012}{0.016} = 0.75$$

次品更可能来自产量更大、次品率更高的甲厂（先验 0.6 × 似然 0.02 的分子主导）。

## 6. 序贯更新与贝叶斯学派

### 6.1 序贯贝叶斯更新

若连续获得多个观察 $A_1, A_2, \cdots, A_m$，后验可逐次更新——**上一次的后验就是下一次的先验**：

$$P(B_k \mid A_1 A_2 \cdots A_m) = \frac{P(B_k) P(A_1 A_2 \cdots A_m \mid B_k)}{\sum_{i=1}^{n} P(B_i) P(A_1 A_2 \cdots A_m \mid B_i)}$$

医学上"先筛查、再复查、最后确诊"的流程就是序贯更新；机器学习中的在线学习（每来一条数据就更新一次模型信念）同理。

### 6.2 频率学派与贝叶斯学派

- **频率学派**：概率是长期频率的极限，参数是固定但未知的常数，用数据估计它；
- **贝叶斯学派**：概率是信念程度的度量，参数是随机变量，有先验分布，用数据把它更新为后验分布。

贝叶斯公式是贝叶斯统计的核心工具，也是垃圾邮件过滤（朴素贝叶斯分类器）、推荐系统、A/B 测试等领域的基础算法。

### 6.3 贝叶斯决策

在决策论中，选择使"后验期望损失"最小的行动。例如诊断决策中，权衡"漏诊"与"误诊"两种错误的代价，选择最优的检查与治疗路径。

## 7. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 把 $P(A \mid B)$ 与 $P(B \mid A)$ 混为一谈 | 概念错误 | 忽略条件方向 | 竖线左边是"被求的事件"；用贝叶斯公式转换，方向不可互换 |
| 2 | 忘了在分母中用全概率公式展开 $P(A)$ | 公式错误 | 只记得分子 | 分母 = 所有"先验 × 似然"之和（归一化常数） |
| 3 | 忽视先验（基础概率谬误）：灵敏度高就以为阳性基本确诊 | 概念错误 | 只看似然，不看先验 | 始终计算"阳性总数中真阳性的占比"；低患病率时阳性预测值很低 |
| 4 | 分割选错：原因类之间相交或漏掉一类 | 建模错误 | 分类不互斥/不完整 | 检查：互斥性（无重叠）+ 完备性（并集为 $\Omega$） |
| 5 | 特异度与灵敏度混淆：$P(-\mid\bar{D}) = 0.95$ 写成 $P(+\mid\bar{D}) = 0.95$ | 计算错误 | 条件方向与正负号对应错 | 灵敏度 = 患者中阳性比例；特异度 = 非患者中阴性比例；$P(+\mid\bar{D}) = 1 - \text{特异度}$ |
| 6 | 每次更新后忘记"后验变先验" | 方法错误 | 把多次观察当一次性处理 | 序贯更新：逐条数据依次代入，用上一轮后验作本轮先验 |

## 9. 一句话记忆

> **先验告诉我们"原因本来多常见"，似然告诉我们"这个证据在原因下多典型"，贝叶斯公式把两者相乘并归一化，得到"看见证据后的原因概率"——先验 × 似然 = 后验。**
