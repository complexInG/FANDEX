## 0. 地图的"投影"：只看一个维度

打开一张等高线地图，你可以做两件事：

- **看全图**：关注 $(x, y)$ 两个坐标决定的完整地形——这是**联合分布**（014 讲）；
- **只看投影**：沿经线方向"压扁"地图，只看"纬度方向"的地势起伏；或沿纬线方向压扁，只看"经度方向"的起伏——这就是**边缘分布**。

"压扁"的本质是**把另一个维度的一切可能性加起来（或积掉）**。举个更直白的例子：统计"全班同学的身高与体重"的联合数据表，如果你只关心"身高分布"，就把每个身高值对应的所有体重概率**按行相加**——得到的就是身高的边缘分布。

**核心关系（务必牢记）**：

- 联合分布 $\Rightarrow$ 边缘分布：**唯一确定**（压扁只看一边）；
- 边缘分布 $\not\Rightarrow$ 联合分布：**不唯一确定**（不同的"立体地形"可以有相同的"平面投影"）。

本讲用"投影/只看一面"的视角，把边缘分布函数、边缘分布律、边缘概率密度的定义与计算逐一讲透，并指出"由边缘推联合"为何行不通。

## 1. 边缘分布函数：把另一个变量"推远"

### 1.1 定义

设 $(X, Y)$ 的联合分布函数为 $F(x, y)$，则

$$F_X(x) = P(X \leq x) = P(X \leq x, Y < +\infty) = F(x, +\infty) = \lim_{y \to +\infty} F(x, y)$$

$$F_Y(y) = P(Y \leq y) = P(X < +\infty, Y \leq y) = F(+\infty, y) = \lim_{x \to +\infty} F(x, y)$$

分别称为 $(X, Y)$ 关于 $X$ 和关于 $Y$ 的**边缘分布函数**。

**大白话**："只看 $X$，不管 $Y$ 取什么值"——把 $Y$ 的可能取值全部"累加"（离散）或"积掉"（连续）后，$X$ 的分布就是 $F_X$。

### 1.2 示例：由联合分布函数求边缘

设 $F(x, y) = \begin{cases} (1 - e^{-x})(1 - e^{-2y}), & x > 0, y > 0 \\ 0, & \text{其他} \end{cases}$

令 $y \to +\infty$：

$$F_X(x) = F(x, +\infty) = 1 - e^{-x}, \quad x > 0$$

即 $X \sim \text{Exp}(1)$。同理 $F_Y(y) = 1 - e^{-2y}$，$Y \sim \text{Exp}(2)$。本例的联合分布函数恰好等于两个边缘的乘积——意味着 $X, Y$ 独立（017 讲将严格定义）。

## 2. 离散型的边缘分布：按行、按列求和

### 2.1 定义

联合分布律 $p_{ij} = P(X = x_i, Y = y_j)$ 时：

$$P(X = x_i) = \sum_{j=1}^{\infty} p_{ij} = p_{i\cdot}, \quad i = 1, 2, \cdots$$

$$P(Y = y_j) = \sum_{i=1}^{\infty} p_{ij} = p_{\cdot j}, \quad j = 1, 2, \cdots$$

分别称为关于 $X$ 和关于 $Y$ 的**边缘分布律**。

### 2.2 计算方法：表上作业

在联合分布律表中：

- $X$ 的边缘分布律 = **每行求和**，写在表的右边；
- $Y$ 的边缘分布律 = **每列求和**，写在表的下边。

**行和、列和，就是"压扁"的方向。**

## 3. 连续型的边缘分布：把另一个变量"积掉"

### 3.1 定义

联合密度 $f(x, y)$ 时：

$$f_X(x) = \int_{-\infty}^{+\infty} f(x, y) \, dy$$

$$f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) \, dx$$

分别称为关于 $X$ 和关于 $Y$ 的**边缘概率密度**。

**大白话**："只看 $x$ 方向的密度"= 把 $y$ 方向全部积分掉（把密度曲面的"体积"沿 $y$ 轴压扁成"面积"）。

### 3.2 计算要点（两大坑）

1. **先确定 $f(x, y)$ 的非零区域**；
2. 求 $f_X(x)$ 时，$y$ 的积分限**可能依赖于 $x$**；求 $f_Y(y)$ 时，$x$ 的积分限**可能依赖于 $y$**。

> 积分限不依赖被积变量是不对的：例如密度非零区域是 $0 < x < y < 1$，求 $f_X(x)$ 时 $y$ 的积分范围是 $(x, 1)$（下限依赖 $x$），写 $\int_{-\infty}^{+\infty}$ 之前必须先代成实际限。

## 4. 边缘与联合的关系：投影的不可逆性

### 4.1 联合确定边缘（可逆方向）

由联合分布函数/律/密度求边缘，方法唯一且确定——"压扁"操作是确定的。

### 4.2 边缘不能确定联合（不可逆方向）

**这是本节最重要的结论**：两张不同的"地形图"可以投影出完全相同的两条"剖面线"。换言之，**已知 $f_X$ 与 $f_Y$，联合密度 $f(x, y)$ 有无限多种可能**。

**标准反例**：设

$$f_1(x, y) = \begin{cases} 4xy, & 0 < x < 1, 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

$$f_2(x, y) = \begin{cases} 8xy, & 0 < x < y < 1 \\ 0, & \text{其他} \end{cases}$$

$f_1$ 关于 $X$ 的边缘：$\int_0^1 4xy \, dy = 2x$；$f_2$ 关于 $X$ 的边缘：$\int_x^1 8xy \, dy = 4x(1 - x^2)$。两者边缘不同，还不是理想反例。**更精巧的经典反例**来自混合分布：取 $f_1$ 与 $f_1' = \begin{cases} 4y(1-x), & 0<x<1, 0<y<1\end{cases}$ 的任意凸组合，可以得到相同的边缘（$f_X(x) = 2x$ 与 $f_Y(y) = 2y$ 保持不变）而联合分布不同。这说明：

> **边缘分布相同，联合分布可以千差万别——"投影"丢掉了变量之间的关联信息（如相关、依赖结构）。**

**工程含义**：数据分析中只汇报"每个变量的单独分布"是不够的，必须同时报告变量间的联合结构（如协方差、条件关系），否则会漏掉关键信息（例如"身高中等但体重偏高"这类联合模式）。

### 4.3 独立时的特殊情况

当 $X$ 与 $Y$ 独立时（017 讲定义），联合分布**由边缘分布唯一确定**：

$$F(x, y) = F_X(x) \cdot F_Y(y), \qquad f(x, y) = f_X(x) \cdot f_Y(y), \qquad p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$$

**反过来**：联合分布能分解为两个边缘的乘积 $\iff$ $X$ 与 $Y$ 独立。因此"边缘乘积"是独立性的试金石，也是由边缘重建联合的唯一合法途径。

## 5. 二维正态分布的边缘分布

设 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，则

$$X \sim N(\mu_1, \sigma_1^2), \qquad Y \sim N(\mu_2, \sigma_2^2)$$

**关键观察**：边缘分布与参数 $\rho$ **无关**。也就是说，不同的 $\rho$（不同的联合分布）给出相同的边缘分布——这是"边缘不能确定联合"在正态家族中的生动实例：$N(0, 0, 1, 1, 0)$ 与 $N(0, 0, 1, 1, 0.9)$ 的 $X$、$Y$ 边缘完全相同，但前者的 $X, Y$ 独立、后者强相关。

## 6. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 由边缘分布直接推断联合分布 | 概念错误 | 误解"投影不可逆" | 记住：边缘相同、联合可不同；只有独立时联合 = 边缘乘积 |
| 2 | 求 $f_X(x)$ 时 $y$ 的积分限写成 $(-\infty, +\infty)$ 未代区域 | 计算错误 | 忽略非零区域形状 | 先画非零区域，按"固定 $x$ 看 $y$ 的范围"定限 |
| 3 | 离散边缘分布律不验证和为 1 | 概念错误 | 漏行/漏列 | 行和、列和分别验证为 1；行和总和 = 列和总和 |
| 4 | 把 $p_{i\cdot}$ 写成"列和"、$p_{\cdot j}$ 写成"行和" | 记号混淆 | 下标含义不清 | $p_{i\cdot}$（点在下）= 对 $j$ 求和（行和）；$p_{\cdot j}$ = 对 $i$ 求和（列和） |
| 5 | 误以为"边缘密度相等则联合密度相等" | 概念错误 | 忽略 $\rho$ 等信息 | 二维正态中 $\rho$ 不影响边缘；联合信息包含 $\rho$ |
| 6 | 独立判定与边缘乘积混为一谈（先假设独立） | 概念错误 | 未验证就相乘 | 先验证 $f(x,y) = f_X(x)f_Y(y)$ 是否成立，成立才独立 |

## 8. 一句话记忆

> **边缘分布是联合分布的"投影"：离散按行/列求和、连续把另一变量积掉；联合唯一决定边缘，边缘却推不出联合（独立时除外，此时联合 = 边缘乘积）。**
