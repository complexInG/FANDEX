## 0. 从一个生活场景说起：两件事"互不影响"

抛一枚硬币两次：第一次抛出正面，会影响第二次吗？当然不会。掷骰子、抛硬币这类重复试验之所以"独立"，是因为**一个试验的结果不会携带另一个试验的任何信息**。反过来，如果连续两天下雨，第一天的雨量就可能影响第二天的雨量——它们不独立。

把"事件独立"升级到"随机变量独立"，直觉是一样的：**知道 $Y$ 取什么值，不会改变我们对 $X$ 的判断**。但直觉只是起点，实际做题时我们需要的是"判定方法"。

本文采用"**判定驱动**"的叙事结构：不先堆定义，而是直接问——拿到一个二维随机变量，我该用什么方法判断 $X$ 与 $Y$ 是否独立？由此引出四种判定武器（分布函数法、离散乘积法、连续密度法、条件分布法），再讲独立性的性质与常见陷阱。

## 1. 判定总览：四种"武器"一张表

| 判定方法 | 适用类型 | 核心条件 | 备注 |
| --- | --- | --- | --- |
| 分布函数法 | 一切类型 | $F(x, y) = F_X(x) F_Y(y)$，对所有 $x, y$ | 最根本的定义 |
| 离散乘积法 | 离散型 | $p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$，对所有 $i, j$ | 联合分布表每一格都满足 |
| 连续密度法 | 连续型 | $f(x, y) = f_X(x) f_Y(y)$ | 等价于联合密度可分离 |
| 条件分布法 | 一切类型 | $f_{X \mid Y}(x \mid y) = f_X(x)$ | 条件分布等于边缘分布 |

核心定义（分布函数法）：设 $(X, Y)$ 是二维随机变量，若对任意实数 $x, y$，都有

$$F(x, y) = F_X(x) \cdot F_Y(y)$$

即 $P(X \leq x,\ Y \leq y) = P(X \leq x) \cdot P(Y \leq y)$，则称 $X$ 与 $Y$ **相互独立**。

> 直观解读：左边是"两个事件同时发生"的概率，右边是"各自发生概率的乘积"。事件 $A = \{X \leq x\}$ 与 $B = \{Y \leq y\}$ 对所有 $x, y$ 都独立，随机变量就独立。

## 2. 判定方法一：离散乘积法

### 2.1 判定式

$X$ 与 $Y$ 独立 $\iff$ 对所有 $i, j$，有

$$P(X = x_i,\ Y = y_j) = P(X = x_i) \cdot P(Y = y_j)$$

简记 $p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$。**必须对全部 $i, j$ 成立**，只要有一格不满足，就不独立。

### 2.2 例题 1（逐格验证）

设 $(X, Y)$ 的联合分布律为：

| $X \backslash Y$ | -1     | 0      | 1      | $p_{i\cdot}$ |
| :--------------: | :----: | :----: | :----: | :----------: |
| -1               | 1/8    | 1/8    | 1/8    | 3/8          |
| 0                | 1/8    | 0      | 1/8    | 2/8          |
| 1                | 1/8    | 1/8    | 1/8    | 3/8          |
| $p_{\cdot j}$    | 3/8    | 2/8    | 3/8    | 1            |

判断 $X$ 与 $Y$ 是否独立。

**解**：先算边缘：$P(X = 0) = \dfrac{2}{8}$，$P(Y = 0) = \dfrac{2}{8}$。

若独立，则应有 $P(X = 0, Y = 0) = \dfrac{2}{8} \times \dfrac{2}{8} = \dfrac{1}{16}$，但表中 $P(X = 0, Y = 0) = 0 \neq \dfrac{1}{16}$。

**结论：不独立**。只需找到**一个反例格**即可否定独立性，无需验证全部 9 格。

> 技巧：验证时优先挑 $p_{ij} = 0$ 的格子——若两个边缘概率都为正但联合概率为 0，乘积必大于 0，立即可判不独立。

## 3. 判定方法二：连续密度法

### 3.1 判定式

$X$ 与 $Y$ 独立 $\iff$ 在 $f(x, y)$ 的连续点处有

$$f(x, y) = f_X(x) \cdot f_Y(y)$$

### 3.2 快速判据：支撑集必须为矩形

一个经常被忽略但极其高效的事实：**若 $f(x, y)$ 的非零区域不是矩形**（$x$ 与 $y$ 的取值范围相互牵制，如三角形、圆形、带状），则 $X$ 与 $Y$ 一定不独立。

原因：矩形区域才能保证 $f_X(x) > 0$ 与 $f_Y(y) > 0$ 的区间对每一对 $(x, y)$ 同时成立；非矩形区域里总存在某些 $(x, y)$，其中一个边缘密度为正而联合密度为 0，乘积不可能等于 0。

### 3.3 例题 2（矩形区域，密度可分离）

设 $(X, Y)$ 的联合密度为

$$f(x, y) = \begin{cases} 4xy, & 0 < x < 1,\ 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

判断独立性。

**解**：

$$f_X(x) = \int_0^1 4xy \, dy = 2x, \quad 0 < x < 1$$

$$f_Y(y) = \int_0^1 4xy \, dx = 2y, \quad 0 < y < 1$$

$$f_X(x) \cdot f_Y(y) = 2x \cdot 2y = 4xy = f(x, y)$$

且非零区域为矩形 $0 < x < 1, 0 < y < 1$，故 $X$ 与 $Y$ **独立**。

### 3.4 例题 3（三角形区域，必不独立）

设 $(X, Y)$ 的联合密度为

$$f(x, y) = \begin{cases} 2, & 0 < x < y < 1 \\ 0, & \text{其他} \end{cases}$$

判断独立性。

**解**：非零区域是三角形 $\{(x, y): 0 < x < y < 1\}$，$x$ 的范围 $(0, 1)$ 与 $y$ 的范围 $(0, 1)$ 相互牵制（$x$ 必须小于 $y$），**不是矩形**，故 $X$ 与 $Y$ **不独立**。

也可以直接验证：

$$f_X(x) = \int_x^1 2 \, dy = 2(1 - x), \quad f_Y(y) = \int_0^y 2 \, dx = 2y$$

$$f_X(x) \cdot f_Y(y) = 4y(1 - x) \neq 2 = f(x, y)$$

## 4. 判定方法三：分解法（不求边缘密度）

若联合密度能写成 $f(x, y) = g(x) \cdot h(y)$，其中 $g(x)$ 只含 $x$，$h(y)$ 只含 $y$，**且非零区域为矩形**，则 $X$ 与 $Y$ 独立（常数因子可以归入任一侧）。

$$\frac{f(x, y)}{h(y)} \Big|_x = g(x) \iff \text{可分离}$$

**反例提醒**：区域不是矩形时，密度再"好看"也不独立。例如 $f(x, y) = 2$（$0 < x < y < 1$）完全可写成 $g(x) h(y) = 1 \cdot 2$，但区域是三角形，所以不独立。**"可分离"与"独立"之间还差一个"矩形区域"条件**。

## 5. 判定方法四：条件分布法

由上一篇《条件分布》可知：

- $X$ 与 $Y$ 独立 $\iff$ $P(X = x_i \mid Y = y_j) = P(X = x_i)$（离散型，所有 $i, j$）；
- $X$ 与 $Y$ 独立 $\iff$ $f_{X \mid Y}(x \mid y) = f_X(x)$（连续型）。

直觉：知道 $Y$ 之后，对 $X$ 的认知不改变，就是独立。这也是唯一能从"数据语义"上直接判断独立性的方法。

## 6. 独立性的重要性质

### 6.1 独立变量的函数仍独立

若 $X$ 与 $Y$ 独立，$g$、$h$ 是（Borel 可测）函数，则 $g(X)$ 与 $h(Y)$ 也独立。例如 $X$ 与 $Y$ 独立，则 $X^2$ 与 $e^Y$ 独立。

### 6.2 概率乘积性质

若 $X$ 与 $Y$ 独立，则对任意集合 $A, B$：

$$P(X \in A,\ Y \in B) = P(X \in A) \cdot P(Y \in B)$$

### 6.3 期望与方差

- 若 $X$ 与 $Y$ 独立且期望存在，则 $E(XY) = E(X) \cdot E(Y)$；
- 若 $X$ 与 $Y$ 独立且方差存在，则 $D(X \pm Y) = D(X) + D(Y)$。

> 注意方向：独立 $\Rightarrow$ $E(XY) = E(X)E(Y)$ 成立；但反过来 $E(XY) = E(X)E(Y)$（即不相关）**不能推出独立**。这一点在《协方差》《相关系数》两篇中会反复强调。

### 6.4 例题 4（用性质巧算）

设 $X \sim B(10, 0.4)$，$Y \sim B(10, 0.4)$，且 $X$ 与 $Y$ 独立，求 $D(2X - 3Y + 1)$。

**解**：

$$D(2X - 3Y + 1) = 4D(X) + 9D(Y) = 4 \times 10 \times 0.4 \times 0.6 + 9 \times 10 \times 0.4 \times 0.6 = 9.6 + 21.6 = 31.2$$

交叉项 $2\text{Cov}(2X, -3Y)$ 因独立而消失（协方差为 0）。

## 7. 多个随机变量的独立性

### 7.1 定义

设 $X_1, X_2, \cdots, X_n$ 是 $n$ 个随机变量，若对任意实数 $x_1, x_2, \cdots, x_n$ 有

$$F(x_1, x_2, \cdots, x_n) = F_{X_1}(x_1) \cdot F_{X_2}(x_2) \cdots F_{X_n}(x_n)$$

则称 $X_1, X_2, \cdots, X_n$ **相互独立**。

### 7.2 相互独立与两两独立

- 相互独立 $\Rightarrow$ 两两独立（每两个变量独立）；
- 两两独立 $\not\Rightarrow$ 相互独立（存在反例）。

### 7.3 独立随机变量和的性质

若 $X_1, X_2, \cdots, X_n$ 相互独立，则

1. $D\left(\sum_{i=1}^n X_i\right) = \sum_{i=1}^n D(X_i)$；
2. $D\left(\sum_{i=1}^n a_i X_i\right) = \sum_{i=1}^n a_i^2 D(X_i)$；
3. 独立正态变量的线性组合仍为正态变量（详见《和的分布与极值分布》）。

## 8. 一个重要的特例：二维正态分布

设 $(X, Y) \sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$，其中 $\rho$ 为相关系数。可以证明：

$$X \text{ 与 } Y \text{ 独立} \iff \rho = 0$$

**证明思路**：当 $\rho = 0$ 时，联合密度中的指数部分可拆为两项之和：

$$f(x, y) = \frac{1}{2\pi\sigma_1\sigma_2} \exp\left\{-\frac{(x-\mu_1)^2}{2\sigma_1^2} - \frac{(y-\mu_2)^2}{2\sigma_2^2}\right\} = f_X(x) \cdot f_Y(y)$$

且非零区域为全平面（矩形），故独立。反向由独立性定义比较密度式可得 $\rho = 0$。

> 注意：**只有正态分布**才有"不相关 $\iff$ 独立"；一般分布不满足（反例见《相关系数》）。

## 9. 常见错误与对策

| 错误示例 | 错误类型 | 原因分析 | 纠正方法 |
| --- | --- | --- | --- |
| 只验证部分格子就下"独立"结论 | 以偏概全 | 离散乘积法要求所有 $i, j$ 都满足 | 验证时先找零概率格：若 $p_{ij}=0$ 而 $p_{i\cdot} p_{\cdot j}>0$，立即判不独立 |
| 看到 $f(x,y)=g(x)h(y)$ 就断言独立 | 条件遗漏 | 忘记"非零区域为矩形"这个前提 | 分解法三要件：可分离 + 矩形区域 + 区域可分解为 $x$ 范围与 $y$ 范围之积 |
| 用 $E(XY)=E(X)E(Y)$ 反推独立 | 逻辑倒置 | 把"独立 ⇒ 不相关"当成充要条件 | 记住：不相关只是"无线性关系"，与独立相差甚远；只有正态分布下两者等价 |
| 把事件独立与变量独立混用 | 概念混淆 | 变量独立要求所有 $\{X \le x\}$ 与 $\{Y \le y\}$ 型事件独立，比个别事件独立强得多 | 变量独立是"无限多个事件对"独立；若 $X$ 与 $Y$ 独立，则 $\{X \in A\}$ 与 $\{Y \in B\}$ 对任意 $A,B$ 独立 |
| 判断独立时把边缘密度算错 | 计算错误 | 积分上下限错误导致边缘密度错误，进而误判 | 先画非零区域图，正确确定积分限；算完用 $\int f_X = 1$ 检验 |
| 认为独立变量就没有任何联系 | 以偏概全 | 忽略了 $D(X\pm Y)$ 中协方差为 0 但函数仍可能相关 | 独立只意味着无任何依赖关系；但"不相关"只排除线性依赖，非线性依赖（如 $Y=X^2$）仍可能存在 |

## 10. 实战练习

### 练习 1（离散型判定）

设 $(X, Y)$ 的联合分布律为：$P(0,0)=\dfrac{1}{4}$，$P(0,1)=\dfrac{1}{4}$，$P(1,0)=\dfrac{1}{4}$，$P(1,1)=\dfrac{1}{4}$。判断 $X$ 与 $Y$ 是否独立。

**提示**：逐格验证 $p_{ij} = p_{i\cdot} p_{\cdot j}$。

**参考答案要点**：$p_{i\cdot} = p_{\cdot j} = \dfrac{1}{2}$；每格 $p_{ij} = \dfrac{1}{4} = \dfrac{1}{2} \times \dfrac{1}{2}$，独立。

### 练习 2（矩形区域判定）

设 $f(x, y) = \begin{cases} 6xy^2, & 0 < x < 1,\ 0 < y < 1 \\ 0, & \text{其他} \end{cases}$，判断独立性并求 $f_X(x)$、$f_Y(y)$。

**提示**：密度可分离且区域为矩形。

**参考答案要点**：$f_X(x) = 2x$（$0<x<1$），$f_Y(y) = 3y^2$（$0<y<1$），乘积恰为 $6xy^2$，独立。

### 练习 3（非矩形区域判定）

设 $f(x, y) = \begin{cases} 1, & 0 < y < x,\ 0 < x < 1 \\ 0, & \text{其他} \end{cases}$，判断独立性。

**提示**：只看支撑集形状即可下结论。

**参考答案要点**：区域为三角形（$y$ 与 $x$ 相互牵制），不是矩形，不独立。

### 练习 4（利用性质求方差）

设 $X \sim P(3)$，$Y \sim P(4)$，$X$ 与 $Y$ 独立，求 $D(2X - Y + 3)$。

**提示**：泊松分布 $D(X) = \lambda$。

**参考答案要点**：$D = 4 \times 3 + 1 \times 4 = 16$。

### 练习 5（综合：分解法+区域）

设 $f(x, y) = \begin{cases} c\, e^{-(2x+3y)}, & x > 0,\ y > 0 \\ 0, & \text{其他} \end{cases}$。（1）求常数 $c$；（2）判断 $X$ 与 $Y$ 是否独立。

**提示**：利用规范性求 $c$；分解密度并观察区域。

**参考答案要点**：$\int_0^\infty\int_0^\infty c e^{-2x}e^{-3y} dx\,dy = c \cdot \dfrac{1}{2} \cdot \dfrac{1}{3} = 1 \Rightarrow c = 6$；$f(x,y) = (2e^{-2x})(3e^{-3y})$ 且区域为第一象限矩形，故独立；事实上 $X \sim \text{Exp}(2)$，$Y \sim \text{Exp}(3)$。

## 11. 一句话记忆

随机变量独立 = "知道 $Y$ 不改变对 $X$ 的判断"：离散看 $p_{ij} = p_{i\cdot} p_{\cdot j}$，连续看 $f(x,y) = f_X(x) f_Y(y)$ 且区域为矩形；独立必不相关，但反推只对正态分布成立。
