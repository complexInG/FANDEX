## 1. 从"人际关系网"说起

### 1.1 图是什么

想象你的微信好友关系：每个人是一个"点"（顶点），两个好友之间有一条"线"（边）。这就是一个**图**——用点和线描述"元素之间是否有关系"。

**图论（Graph Theory）研究的就是这种"点和线"的数学结构**。它是离散数学的核心分支，也是计算机网络、社交网络、地图导航、算法设计的基础。

**图的定义**：**图** $G = (V, E)$ 由顶点集 $V$ 和边集 $E$ 组成。

- **无向图**：$E$ 中元素为无序对 $\{u, v\}$（好友关系，双向）
- **有向图**：$E$ 中元素为有序对 $(u, v)$（关注关系，单向）
- **多重图**：允许平行边（同一对顶点间有多条边）
- **简单图**：无平行边、无自环

### 1.2 特殊图

| 图 | 定义 |
| :--- | :--- |
| 完全图 $K_n$ | $n$ 个顶点，每对顶点间有一条边，$|E| = \binom{n}{2}$ |
| 零图 | 无边图 |
| 平凡图 | 只有一个顶点的图 |
| 正则图 | 每个顶点的度都相同的图（$k$-正则图：每个顶点度为 $k$） |

### 1.3 子图

- **子图**：$H = (V', E')$，$V' \subseteq V$，$E' \subseteq E$
- **生成子图**：$V' = V$ 的子图（顶点一样，边是子集）
- **导出子图**：由顶点子集 $V'$ 导出，包含 $V'$ 之间**所有**边

## 2. 度与握手定理

### 2.1 度

顶点 $v$ 的**度** $\deg(v)$ 是与 $v$ 关联的边数（自环算 2 度）。

- **孤立点**：$\deg(v) = 0$（没有朋友）
- **悬挂点**：$\deg(v) = 1$（只有一个朋友）

### 2.2 握手定理（最重要定理之一）

**定理**：在任何无向图中，所有顶点的度数之和等于边数的两倍：

$$\sum_{v \in V} \deg(v) = 2|E|$$

**证明（一句话）**：每条边贡献 2 个度（连接两个端点）。

**推论**：任何图中度数为奇数的顶点个数必为偶数。

**理解**：就像握手——每握一次手，两个人的"握手次数"各加 1，所以所有人的握手次数总和一定是偶数。

**有向图版本**：

$$\sum_{v \in V} \deg^+(v) = \sum_{v \in V} \deg^-(v) = |E|$$

（出度总和 = 入度总和 = 边数）

**例**：一个图有 5 个顶点，度数分别为 3, 3, 4, 4, 4，求边数。

> $\sum \deg = 3+3+4+4+4 = 18 = 2|E|$，$|E| = 9$。

## 3. 路径与回路

### 3.1 四个概念（易混淆）

| 概念 | 定义 | 限制 |
| :--- | :--- | :--- |
| 通路（walk） | 顶点与边交替的序列 | 无限制 |
| 迹（trail） | 边不重复的通路 | 边不重复 |
| 路径（path） | 顶点不重复的通路 | 顶点不重复 |
| 回路（circuit） | 起终点相同的迹 | 边不重复 |
| 圈（cycle） | 起终点相同且其余顶点不重复 | 长度 ≥ 3 |

**记忆**：walk 最宽松 → trail 边不重 → path 点不重（除起终点）→ cycle 是闭合的 path。

### 3.2 路径长度

- 无权图中路径长度为**边数**
- 带权图中路径长度为**边权之和**（地图导航的距离）

## 4. 连通性

### 4.1 无向图的连通性

- **连通**：顶点 $u$ 和 $v$ 之间存在路径
- **连通图**：任意两个顶点都连通
- **连通分量**：极大连通子图（"一片"连着的顶点群）

### 4.2 有向图的连通性

| 类型 | 定义 |
| :--- | :--- |
| 强连通 | 任意两个顶点互相可达（双向都能到） |
| 弱连通 | 忽略方向后连通 |
| 单向连通 | 任意两个顶点至少一个方向可达 |

**理解**：微博关注关系——"互相粉丝"才强连通；只看"认识"（忽略方向）就是弱连通。

### 4.3 连通度（衡量"多难拆散"）

- **点连通度** $\kappa(G)$：使 $G$ 不连通需删除的最少顶点数
- **边连通度** $\lambda(G)$：使 $G$ 不连通需删除的最少边数

**Whitney 不等式**：$\kappa(G) \leq \lambda(G) \leq \delta(G)$（$\delta(G)$ 为最小度）

**理解**：想拆散网络，删点比删边更"划算"；而最少的边数不会超过最小度。

### 4.4 割点与桥

- **割点**：删除该顶点后连通分量数增加（网络的"咽喉"）
- **桥**：删除该边后连通分量数增加（网络的"独木桥"）

## 5. 欧拉图与哈密顿图（两大经典问题）

### 5.1 欧拉图："一笔画"问题

**背景**：哥尼斯堡七桥问题——能否不重复地走过所有桥再回到起点？欧拉证明了：不能。

**欧拉回路**：经过每条边**恰好一次**的回路。
**欧拉通路**：经过每条边恰好一次的**通路**（不必回到起点）。

**判定定理（核心）**：

- 无向连通图有**欧拉回路** $\iff$ **每个顶点的度数为偶数**
- 无向连通图有**欧拉通路** $\iff$ **恰有 0 个或 2 个奇度顶点**
  - 0 个奇度顶点：欧拉回路
  - 2 个奇度顶点：欧拉通路从一奇度顶点到另一奇度顶点

**理解**：进入一个顶点必须能出去，所以"进门-出门"成对，度数必须成双。

**Fleury 算法**（求欧拉回路）：

1. 从任意顶点出发
2. 每步选择一条未走过的边，**除非该边是当前顶点唯一的桥**
3. 直到所有边走完

**例**：判断 $K_5$ 是否有欧拉回路。

> $K_5$ 中每个顶点度为 4（偶数），连通，故有欧拉回路。

### 5.2 哈密顿图："旅行商"问题

**哈密顿回路**：经过每个顶点**恰好一次**的回路（不必经过每条边）。

**背景**：旅行商问题（TSP）——走遍所有城市再返回，找最短路线。

**判定**：哈密顿图的判定是 **NP 完全问题**，没有简单的充要条件（这是它与欧拉图的最大区别）。

**充分条件**：

- **Dirac 定理**：$n$ 阶简单图（$n \geq 3$）且 $\delta(G) \geq n/2$ → 是哈密顿图
- **Ore 定理**：$n$ 阶简单图（$n \geq 3$）且任意不相邻顶点 $u, v$ 有 $\deg(u) + \deg(v) \geq n$ → 是哈密顿图

**必要条件**：若 $G$ 是哈密顿图，则对 $V$ 的任意非空真子集 $S$，$G - S$ 的连通分量数 $c(G-S) \leq |S|$。

**欧拉 vs 哈密顿（易混淆）**：

| | 欧拉图 | 哈密顿图 |
| :--- | :--- | :--- |
| 关注 | 每条**边**恰好一次 | 每个**顶点**恰好一次 |
| 判定 | 有简单充要条件 | NP 完全，无简单条件 |
| 实际 | 一笔画 | 旅行商 |

## 6. 二部图

### 6.1 定义

若 $V$ 可划分为 $V_1$ 和 $V_2$（$V_1 \cap V_2 = \emptyset$），使得每条边连接 $V_1$ 和 $V_2$ 中的顶点，则 $G$ 为**二部图**（偶图）。

**完全二部图** $K_{m,n}$：$|V_1| = m$，$|V_2| = n$，$V_1$ 中每个顶点与 $V_2$ 中每个顶点相连。

**理解**：二部图就是"两类人之间的配对关系"——男生-女生、工人-工作、课程-教室。

### 6.2 判定定理（重要）

**定理**：无向图是二部图 $\iff$ **图中无奇圈**（圈的长度都是偶数）。

> **证明思路**：
> $\Rightarrow$：若 $G$ 是二部图且有奇圈，则圈上顶点交替属于 $V_1, V_2$，奇圈导致首尾顶点同属一个集合，矛盾。
> $\Leftarrow$：对每个连通分量，从任一顶点出发 BFS，交替分配到 $V_1, V_2$。无奇圈保证不矛盾。

**实践**：判断一个图是否二部图，用"着色法"——从任一点开始染红/蓝交替，如果出现"相邻同色"就不是二部图。

### 6.3 匹配与 Hall 定理

**匹配**：边集 $M \subseteq E$，$M$ 中任意两条边不共享端点。
**最大匹配**：边数最多的匹配。
**完美匹配**：覆盖所有顶点的匹配。

**Hall 婚姻定理**：二部图 $G = (V_1, V_2, E)$ 中存在 $V_1$ 到 $V_2$ 的完美匹配 $\iff$ 对任意 $S \subseteq V_1$，$|N(S)| \geq |S|$。

（$N(S)$ 为 $S$ 的邻域——$S$ 中所有顶点能到达的 $V_2$ 中的顶点集合）

**理解**：就像相亲——任意一组男生（$S$）认识的女生的总数（$N(S)$），不能少于男生人数。否则有人找不到对象。

## 7. 树与生成树

### 7.1 树的定义与等价条件

**树**是连通无圈图。对 $n$ 阶图 $G$，以下说法**等价**：

1. $G$ 连通且无圈
2. $G$ 连通且 $|E| = n - 1$
3. $G$ 无圈且 $|E| = n - 1$
4. $G$ 中任意两个顶点间有**唯一路径**
5. $G$ 连通且删除任一边后不连通

**记忆**：树 = 连通 + 无圈 + 恰好 $n-1$ 条边——三个条件互相等价，任选其一。

### 7.2 树的性质

- 树中至少有两个叶子（度为 1 的顶点）（$n \geq 2$ 时）
- 树中任意两个顶点间有唯一路径
- 树添加任一边产生唯一圈
- 树删除任一边产生两个连通分量

### 7.3 生成树

**生成树**：连通图 $G$ 的生成子图且为树。

**存在性**：连通图必有生成树。

**生成树个数**：$n$ 个顶点的完全图 $K_n$ 的生成树个数为 $n^{n-2}$（**Cayley 公式**）。

### 7.4 最小生成树（MST）

**Kruskal 算法**（按边排序，从小到大贪心）：

1. 将边按权从小到大排序
2. 依次取边，若**不形成圈**则加入
3. 直到 $n-1$ 条边

**Prim 算法**（从点出发，逐步生长）：

1. 从任一顶点开始
2. 每步选择连接"已选顶点集"与"未选顶点集"的**最小权边**
3. 直到所有顶点入选

复杂度：Kruskal $O(|E|\log|E|)$，Prim $O(|E|\log|V|)$。

**理解**：最小生成树 = 用最少的"总成本"把网络所有节点连通——比如铺光缆、建电网。

## 8. 常见误区

**误区一：欧拉图和哈密顿图分不清。** → 欧拉看"边"（一笔画，度数成偶），哈密顿看"点"（走遍所有点，NP 完全）。

**误区二：所有连通图都有欧拉回路。** → 必须**所有顶点度数为偶数**才有欧拉回路；有 2 个奇度顶点只有欧拉通路。

**误区三：树可以有圈。** → 树**严格无圈**。一旦加一条边就产生圈（不再是树）。

**误区四：二部图一定没有三角形。** → 正确！三角形是 3 圈（奇圈），二部图无奇圈，所以二部图不可能有三角形。
