## 0. 飞镖盘上的概率

想象一块圆形的飞镖盘，外圈写着"一等奖"，内圈写着"特等奖"。你随手掷出一镖（假设技术差到"每个位置都可能中"，且落在盘上任意位置的可能性一样大）：

- 落在内圈（特等奖）的概率是多少？
- 落在外圈（一等奖）的概率是多少？

直观上，你会用**面积**来回答：特等奖的概率 = 内圈面积 ÷ 整盘面积。这里没有"有限个等可能结果"可以一个个数——盘上有**无穷多个点**——但"面积越大，概率越大"的直觉依然成立。

这就是本讲的主角——**几何概型**：当试验结果对应一个可度量的几何区域（线段、平面、立体）时，概率 = "事件区域的大小 ÷ 整个区域的大小"。它与古典概型的关系就像"从数豆子到称大米"：古典概型一个一个数，几何概型一秤一秤量。

## 1. 从"数"到"量"：几何概型的定义

### 1.1 几何概型的两个条件

设随机试验的样本空间 $\Omega$ 是某个可度量的几何区域，若：

1. **无限性**：$\Omega$ 是线段、平面区域或空间区域等（含无穷多个样本点）；
2. **等可能性**：结果落在 $\Omega$ 内任一**可度量子区域** $A$ 的概率，只与 $A$ 的**度量**（长度、面积、体积）成正比，与 $A$ 的形状和位置无关。

则称该试验为**几何概型**。

### 1.2 几何概率公式

$$P(A) = \frac{A \text{ 的度量}}{\Omega \text{ 的度量}}$$

具体按维度展开：

- 一维（线段）：$P(A) = \dfrac{L(A)}{L(\Omega)}$（长度比）
- 二维（平面区域）：$P(A) = \dfrac{S(A)}{S(\Omega)}$（面积比）
- 三维（空间区域）：$P(A) = \dfrac{V(A)}{V(\Omega)}$（体积比）

> **关键提醒**："等可能"在几何概型中指的是**均匀**——点落在等大小的任意两个子区域里的概率相等。这与古典概型"每个基本结果等可能"精神一致，只是把"结果"从离散点换成了连续点。

### 1.3 几何概率的三个性质

1. 非负性：$P(A) \geq 0$；
2. 规范性：$P(\Omega) = 1$；
3. 可列可加性：$A_1, A_2, \cdots$ 两两互斥时，

$$P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$$

## 2. 三种"度量"模型：线、面、体

几何概型按样本空间的维度分成三类，解题的第一步永远是**判断这是"线、面还是体"**。

### 2.1 长度模型（一维）

**例题（电台报时）**：某人午觉醒来，发觉表停了，打开收音机听整点报时，求他等待时间少于 10 分钟的概率。

**解**：从 13:00 到 14:00 任一时刻醒来都是等可能的（均匀），样本空间是长度为 60 分钟的区间。等待少于 10 分钟 $\iff$ 醒来的时刻落在 13:50 之后，长度为 10 分钟。

$$P = \frac{10}{60} = \frac{1}{6}$$

### 2.2 面积模型（二维）——最重要

**例题（会面问题）**：甲乙约定在 8:00—9:00 之间某地会面，先到者等候另一人 15 分钟即离去，求两人能会面的概率。

**解**：设甲到达时刻为 $x$（分钟），乙为 $y$（分钟），则样本空间是边长为 60 的正方形：

$$\Omega = \{(x, y) \mid 0 \leq x \leq 60, 0 \leq y \leq 60\}, \quad S(\Omega) = 3600$$

两人能会面 $\iff$ 到达时间差不超过 15 分钟：$|x - y| \leq 15$。事件区域为正方形内夹在两直线 $y = x \pm 15$ 之间的条带：

$$S(A) = 3600 - 2 \times \frac{1}{2} \times 45 \times 45 = 3600 - 2025 = 1575$$

（两个角上的直角等腰三角形各是"等待超过 15 分钟"的区域）

$$P(A) = \frac{1575}{3600} = \frac{7}{16} \approx 0.4375$$

**画图是几何概型的灵魂**：把"文字条件"翻译成"图形区域"，面积之比即概率。这个例子请务必亲手画一遍：正方形、两条对角带、两个角三角形，一目了然。

**Python 模拟验证**：

```python
import random

def meet_prob(wait=15, trials=100000):
    hit = 0
    for _ in range(trials):
        x, y = random.uniform(0, 60), random.uniform(0, 60)
        if abs(x - y) <= wait:
            hit += 1
    return hit / trials

print(f"模拟会面概率: {meet_prob():.4f}")   # 理论值 7/16 = 0.4375
```

### 2.3 体积模型（三维）

**例题**：在一个棱长为 1 的正方体内随机取一点，求该点到原点的距离小于 1 的概率。

**解**：样本空间是单位立方体，$V(\Omega) = 1$；事件是"第一卦限内半径为 1 的八分之一球"，$V(A) = \dfrac{1}{8} \cdot \dfrac{4}{3}\pi \cdot 1^3 = \dfrac{\pi}{6}$。

$$P = \frac{V(A)}{V(\Omega)} = \frac{\pi}{6} \approx 0.5236$$

## 4. 历史名题：蒲丰投针与蒙特卡洛方法

**问题（蒲丰投针，1777 年）**：平面上画满间距为 $a$ 的平行线，向平面任意投掷一枚长度为 $l$（$l < a$）的针，求针与某条平行线相交的概率。

**解**：针的位置由两个量决定：针的中点 $M$ 到最近平行线的距离 $x \in \left[0, \dfrac{a}{2}\right]$，以及针与平行线的夹角 $\theta \in [0, \pi]$。样本空间为矩形：

$$\Omega = \left\{(x, \theta) \mid 0 \leq x \leq \frac{a}{2}, 0 \leq \theta \leq \pi\right\}, \quad S(\Omega) = \frac{a\pi}{2}$$

针与平行线相交 $\iff$ $x \leq \dfrac{l}{2}\sin\theta$（针在垂直方向上的投影一半大于等于距离 $x$）。事件区域面积：

$$S(A) = \int_0^{\pi} \frac{l}{2}\sin\theta \, d\theta = \frac{l}{2} \cdot [-\cos\theta]_0^{\pi} = l$$

故

$$P(A) = \frac{S(A)}{S(\Omega)} = \frac{l}{a\pi/2} = \frac{2l}{a\pi}$$

**妙用**：若统计大量投针实验的相交频率 $\hat{P}$，可反解 $\pi$：

$$\pi \approx \frac{2l}{a \cdot \hat{P}}$$

这就是**蒙特卡洛（Monte Carlo）方法**的早期雏形——用随机试验的频率来估计确定性的常数。今天，蒙特卡洛方法被广泛用于金融风险定价、物理模拟、机器学习中的随机采样。

**Python 模拟蒲丰投针估计 π**：

```python
import random, math

def buffon_pi(l=1.0, a=2.0, trials=100000):
    hit = 0
    for _ in range(trials):
        x = random.uniform(0, a / 2)          # 中点到最近线的距离
        theta = random.uniform(0, math.pi)    # 针与平行线的夹角
        if x <= (l / 2) * math.sin(theta):
            hit += 1
    p = hit / trials
    return 2 * l / (a * p)                    # 反解 pi

print(f"蒲丰投针估计 pi: {buffon_pi():.4f}")   # 约 3.1416
```

## 5. 线段截取问题：三维坐标的经典

**问题**：将长度为 $a$ 的线段任意折成三段，求三段能构成三角形的概率。

**解**：设三段长度为 $x, y, z$，则 $x + y + z = a$，$x, y, z > 0$。样本空间为平面 $x + y + z = a$ 在第一卦限内的三角形区域（边长为 $a$ 的正三角形），面积为 $S(\Omega) = \dfrac{\sqrt{3}}{4}a^2$。

能构成三角形 $\iff$ 任意两边之和大于第三边。由 $x + y + z = a$，条件等价于

$$x < \frac{a}{2}, \quad y < \frac{a}{2}, \quad z < \frac{a}{2}$$

即样本三角形"挖掉三个角上的小正三角形"（每个小三角形边长 $\dfrac{a}{2}$，共 3 个）：

$$S(A) = \frac{\sqrt{3}}{4}a^2 - 3 \cdot \frac{\sqrt{3}}{4}\left(\frac{a}{2}\right)^2 = \frac{\sqrt{3}}{4}a^2 \left(1 - \frac{3}{4}\right) = \frac{\sqrt{3}}{4}a^2 \cdot \frac{1}{4}$$

$$P = \frac{1}{4}$$

> 这类"三段成三角形"问题的关键在于：把**三角形不等式**翻译成"每段小于总长一半"，再用面积相减。类似的翻译技巧在几何概型中无处不在。

## 6. 几何概型的三个"陷阱"

### 6.1 零概率事件 ≠ 不可能事件

在几何概型中，单点区域的度量为 0：

$$P(\{x_0\}) = \frac{L(\{x_0\})}{L((0,1))} = 0$$

但"取到 $x_0$"是**可能**发生的。同理，概率为 1 的事件也不一定必然发生。这与古典概型"概率 0 即不可能"的直觉完全不同，是进入连续世界的第一个认知升级。

### 6.2 贝特朗悖论："随机"的定义不唯一

**问题**：在单位圆内随机取一条弦，求弦长大于 $\sqrt{3}$（即大于内接正三角形边长）的概率。

三种看似都"自然"的取法给出不同答案：

| 取法         | 做法                                             | 结果  |
| ------------ | ------------------------------------------------ | ----- |
| 随机端点     | 在圆周上随机取两个端点                           | $1/3$ |
| 随机半径上的点 | 固定方向，在半径上随机取弦的中点                 | $1/2$ |
| 随机中点     | 在圆内均匀随机取弦的中点                         | $1/4$ |

三种方法都自洽，结果却不同——说明**几何概型的"等可能"必须先明确落在哪个空间上等可能**。这不是数学错误，而是提醒我们：建模时"随机"二字必须定义清楚。

### 6.3 度量不可度量的区域

若事件区域无法度量（如贝特朗悖论中的第三种取法直接用圆面积），公式 $P(A) = \dfrac{\text{度量}(A)}{\text{度量}(\Omega)}$ 就失去意义。**先确认 $\Omega$ 与 $A$ 都可度量，再算比值。**

## 7. 常见错误与对策

| 序号 | 常见错误 | 错误类型 | 原因分析 | 纠正方法 |
| ---- | -------- | -------- | -------- | -------- |
| 1 | 把古典概型的 $m/n$ 硬套到连续区域（如"在区间取点"还去数点） | 概念错误 | 分不清离散与连续 | 看到"区间/区域/任意时刻"等连续字样，改用度量比 |
| 2 | 会面问题忘记 $|x-y| \leq 15$ 要用"差"而不是"和" | 审题错误 | 把"先到等后到"误读成"同时到" | 翻译条件：能会面 $\iff$ 时间差不超过等待时长 |
| 3 | 样本空间维度选错（如两船问题只用一维） | 建模错误 | 没有识别出"两个随机量" | 有几个独立的随机量，样本空间就是几维 |
| 4 | 事件区域边界算错：把"小于"写成"小于等于"或漏掉一个角 | 计算错误 | 不等号方向搞反 | 取边界点代入检验；用"对角三角形"技巧求面积 |
| 5 | 认为概率为 0 的事件不可能发生 | 概念错误 | 用离散直觉理解连续 | 记住：连续型单点概率为 0 但事件可能发生 |
| 6 | 忽略"等可能"的空间定义（贝特朗悖论） | 概念错误 | 以为"随机"只有一种含义 | 明确"在哪一个空间上均匀"，不同空间结果可能不同 |

## 9. 一句话记忆

> **几何概型把"数豆子"变成"称大米"：样本空间是一个可度量的几何区域，概率 = 事件区域大小 ÷ 总区域大小；画图定区域、分类看维度，是它的全部诀窍。**
