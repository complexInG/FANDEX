## 1. 从"运算的规律"说起

### 1.1 代数系统研究什么

你从小学就接触代数：整数、加减乘除、交换律结合律。**代数系统（Algebraic System）就是把"某个集合 + 某种运算"抽象成一般规律来研究**——不关心具体是"整数"还是"矩阵"，只关心"这个运算满足什么性质"。

**代数系统** $(S, *)$：非空集合 $S$ + 二元运算 $*$。

**为什么要抽象**：一旦发现"整数加法"和"矩阵乘法"满足同样的规律（结合律、有单位元、有逆元），就能用同一套理论处理它们——这就是"群论"的力量。

**一个惊人的事实**：整数加法 $(\mathbb{Z}, +)$、非零有理数乘法 $(\mathbb{Q}^*, \times)$、可逆矩阵乘法、模运算 $(\mathbb{Z}_n, +_n)$——它们看似无关，却都满足同样的四条规律（封闭、结合、单位元、逆元），都是"群"。**群论可以统一处理它们**，这就是代数系统研究的意义。

### 1.2 代数系统四要素

一个代数系统需要明确四件事：

1. **集合**：$S$
2. **运算**：$*$（如 $+$、$\times$、$\circ$）
3. **公理**：运算满足的性质（结合、交换等）
4. **特殊元素**：单位元、零元、逆元

## 2. 代数运算与性质

### 2.1 代数运算

设 $S$ 是非空集合。映射 $f: S^n \to S$ 称为 $S$ 上的 **$n$ 元运算**。最常用的是**二元运算** $*: S \times S \to S$，记作 $a * b$。

### 2.2 运算的性质

**封闭性**：$\forall a, b \in S, a * b \in S$（运算结果还在集合里）

**交换律**：$a * b = b * a$

**结合律**：$(a * b) * c = a * (b * c)$

**分配律**（两个运算间）：$a * (b \circ c) = (a * b) \circ (a * c)$（左分配）

**吸收律**：$a * (a \circ b) = a$

**幂等律**：$a * a = a$

### 2.3 特殊元素

**单位元（幺元）**：$e * a = a * e = a$（$\forall a \in S$）。若存在则唯一。

> 证明：设 $e_1, e_2$ 都是单位元，则 $e_1 = e_1 * e_2 = e_2$。

**零元**：$\theta * a = a * \theta = \theta$（$\forall a \in S$）

**逆元**：若 $a * b = b * a = e$，则 $b$ 是 $a$ 的逆元，记作 $a^{-1}$。在有单位元且满足结合律的系统中，逆元若存在则唯一。

**例**：$(\mathbb{Z}, +)$ 的单位元为 $0$，$a$ 的逆元为 $-a$，无零元。

**例**：$(\mathbb{Z}, \times)$ 的单位元为 $1$，零元为 $0$，只有 $\pm 1$ 有逆元。

## 3. 半群与群

### 3.1 半群

**半群**：$(S, *)$ 满足封闭性和结合律。

**独异点（含幺半群）**：有单位元的半群。

**例**：

- $(\mathbb{N}, +)$：半群（$\mathbb{N}$ 含 0 时是独异点）
- $(\mathbb{Z}, +)$：独异点（单位元 0）
- 字符串集合在连接运算下：独异点（单位元为空串）

### 3.2 群

**群** $(G, *)$ 满足四条公理：

1. 封闭性
2. 结合律
3. 有单位元
4. 每个元素有逆元

**Abel 群（交换群）**：满足交换律的群。

**群的性质**：

- 消去律：$a * b = a * c \Rightarrow b = c$
- 方程有解：$a * x = b$ 有唯一解 $x = a^{-1} * b$
- $(a^{-1})^{-1} = a$
- $(a * b)^{-1} = b^{-1} * a^{-1}$（**顺序反转**）

**例**：

- $(\mathbb{Z}, +)$：Abel 群
- $(\mathbb{Q}^*, \times)$：Abel 群（$\mathbb{Q}^* = \mathbb{Q} \setminus \{0\}$）
- $n$ 阶可逆矩阵在乘法下：群（非 Abel）
- $(\mathbb{Z}_n, +_n)$：Abel 群（模 $n$ 加法）

### 3.3 群的阶

- **群的阶** $|G|$：群中元素个数
- **元素的阶**：使 $a^n = e$ 的最小正整数 $n$，记作 $o(a)$

**例**：$\mathbb{Z}_6 = \{0,1,2,3,4,5\}$ 在模 6 加法下：

- $o(0) = 1$，$o(1) = 6$，$o(2) = 3$，$o(3) = 2$，$o(4) = 3$，$o(5) = 6$

**理解**：元素的阶 = "加多少次回到单位元 0"。$2+2+2 = 6 \equiv 0 \pmod 6$，所以 $o(2) = 3$。

### 3.4 置换群

**$n$ 元置换**：$\{1, 2, \ldots, n\}$ 到自身的双射。所有 $n$ 元置换在复合运算下构成**对称群** $S_n$，$|S_n| = n!$。

**轮换表示**：$(1\,3\,5)$ 表示 $1 \to 3 \to 5 \to 1$。

**对换**：长度为 2 的轮换，如 $(1\,3)$。

**定理**：每个置换可分解为不相交轮换的复合，也可分解为对换的复合。

**理解**：$S_3$ 有 6 个元素，是所有"洗牌方式"的集合——置换群是密码学（RSA）和对称性的基础。

### 3.5 循环群

若群 $G$ 中存在元素 $a$ 使得 $G = \{a^n \mid n \in \mathbb{Z}\}$，则 $G$ 为**循环群**，$a$ 为**生成元**。

**定理**：循环群都是 Abel 群。

## 4. 子群与陪集

### 4.1 子群

若 $H \subseteq G$ 且 $(H, *)$ 本身是群，则 $H$ 是 $G$ 的**子群**。

**判定（两步检验）**：$H$ 是子群 $\iff$ ①$H \neq \emptyset$ ②$\forall a, b \in H$，$a * b^{-1} \in H$。

**例**：$(\mathbb{Z}, +)$ 中，偶数集 $\{2k\}$ 是子群；奇数集不是（无单位元、不封闭）。

### 4.2 陪集

设 $H$ 是 $G$ 的子群，$a \in G$：

- **左陪集**：$aH = \{a * h \mid h \in H\}$
- **右陪集**：$Ha = \{h * a \mid h \in H\}$

**例**：$G = \mathbb{Z}_6$（模6加法），$H = \{0, 3\}$（子群）。

> 左陪集：$0 + H = \{0,3\}$，$1 + H = \{1,4\}$，$2 + H = \{2,5\}$——三个陪集，把 $G$ 分成 3 类。

### 4.3 陪集的性质（重要）

- 两个陪集要么相等，要么不相交（$aH = bH$ 或 $aH \cap bH = \emptyset$）
- 所有陪集大小相同（$|aH| = |H|$）
- 陪集把 $G$ **划分**成若干"等大的块"

**理解**：像等价类——陪集就是"按子群 $H$ 分类"的等价类。

## 5. Lagrange 定理（核心定理）

### 5.1 定理

设 $G$ 为有限群，$H$ 为 $G$ 的子群，则

$$|H| \mid |G|$$

（$H$ 的阶整除 $G$ 的阶）

**推论**：

1. 素阶群无真子群
2. $G$ 的每个元素的阶整除 $|G|$
3. 素阶群都是循环群

**例**：$G = \mathbb{Z}_6$（$|G| = 6$），子群 $H = \{0,3\}$（$|H| = 2$），$2 \mid 6$ 成立。

**例**：5 阶群只有 5 阶循环群（$5$ 是素数，子群只有 $\{e\}$ 和 $G$ 本身）。

**理解**：Lagrange 定理是"大群被子群均分"的守恒律——子群像"一包平均分的饼干"，$|G|$ 必然被 $|H|$ 整除。

## 6. 环与域

### 6.1 环

**环** $(R, +, \times)$：集合 $R$ 上两个运算（加法和乘法）满足：

1. $(R, +)$ 是 Abel 群（加法群）
2. $(R, \times)$ 是半群（乘法封闭且结合）
3. 乘法对加法满足分配律：$a \times (b + c) = a \times b + a \times c$

**有单位元的环**：乘法有单位元 1。
**交换环**：乘法满足交换律。
**整环**：有单位元、交换、无零因子（$ab = 0 \Rightarrow a = 0$ 或 $b = 0$）。

**例**：$(\mathbb{Z}, +, \times)$ 是整环。

### 6.2 域

**域** $(F, +, \times)$：$F$ 是整环，且每个非零元素在乘法下都有逆元。

**理解**：域 = "能加减乘除"的集合——加减乘封闭、除法（除 0 外）也有。

**例**：

- $(\mathbb{Q}, +, \times)$：域（有理数）
- $(\mathbb{R}, +, \times)$：域（实数）
- $(\mathbb{Z}_p, +_p, \times_p)$：域，当且仅当 $p$ 是素数（**有限域**，密码学基础）

**例**：$(\mathbb{Z}_5, +, \times)$ 是域：$2^{-1} = 3$（因为 $2 \times 3 = 6 \equiv 1$）。$(\mathbb{Z}_6, +, \times)$ 不是域：$2$ 无乘法逆元。

### 6.3 有限域与密码学

有限域 $\mathbb{Z}_p$（$p$ 素数）是 **RSA、ECC、AES** 等密码算法的数学基础——"在模 $p$ 下做运算"是现代加密的基石。

## 7. 同态与同构

### 7.1 同态

**同态映射** $\phi: G \to G'$（$G, G'$ 同类型代数系统）：

$$\phi(a * b) = \phi(a) *' \phi(b)$$

**理解**：同态是"保持运算结构"的映射——"先运算再映射"等于"先映射再运算"，两种方式结果一样。

**例**：$\phi: (\mathbb{Z}, +) \to (\mathbb{Z}_n, +_n)$，$\phi(x) = x \bmod n$ 是满同态。

**同态核**：$\ker \phi = \{a \in G \mid \phi(a) = e'\}$（映射到单位元的元素）

### 7.2 同构

**同构映射**：双射的同态。若 $G \cong G'$（存在同构），则两个系统**在结构上完全一样**（只是元素名称不同）。

**理解**：同构 = "换了个马甲但本质相同"。比如 $(\{0,1\}, \oplus)$（异或）和 $(\{\text{F}, \text{T}\}, \leftrightarrow)$（逻辑等价）同构——它们都有"两个元素、对合运算"的结构。

### 7.3 同态基本定理

$$G / \ker \phi \cong \text{Im}(\phi)$$

（商群同构于像——"除掉核，剩下的是同构于像的部分"）

### 7.4 判断同构的要点

同构要求结构一致，检查三个"结构量"：

1. **阶相同**（元素个数一样）
2. **元素阶分布相同**（各种阶的元素个数一样）
3. 关系表（Cayley 表）结构一致

**例**：$(\mathbb{Z}_4, +_4)$ 和 $(\mathbb{Z}_2 \times \mathbb{Z}_2, +)$ 不同构——前者有 4 阶元素（如 1），后者所有非零元素都是 2 阶。

## 8. 常见误区

**误区一：所有群都是交换的。** → 错！矩阵乘法构成非 Abel 群。交换群（Abel 群）是特殊子类。

**误区二：$(\mathbb{Z}_n, \times_n)$ 总是域。** → 只有当 $n$ 是**素数**时才是域。$\mathbb{Z}_6$ 中 2 无乘法逆元，不是域。

**误区三：子群大小可以不整除群大小。** → Lagrange 定理保证**必须整除**。$|H|$ 不整除 $|G|$ 时 $H$ 不可能是子群。

**误区四：同态和同构没区别。** → 同构是"结构完全一样"（双射），同态只要求"保持运算"（可能多个映一个）。同构是同态的特例。
